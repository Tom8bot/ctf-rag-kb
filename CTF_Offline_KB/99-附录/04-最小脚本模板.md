# 最小脚本模板

## 1. 逐行读文件并统计
```python
from collections import Counter
with open('file','r',errors='ignore') as f:
    data = f.read()
print(len(data))
print(Counter(data).most_common(20))
```

## 2. 十六进制 / 字节互转
```python
s = '414243'
b = bytes.fromhex(s)
print(b)
print(b.hex())
```

## 3. 爆破模板
```python
for x in range(256):
    # 条件
    if x % 17 == 0:
        print(x)
```

## 5. HTTP 枚举模板
```python
import requests
for p in ['admin', 'debug', 'test', '.git/config']:
    url = 'http://target/' + p
    r = requests.get(url, timeout=3)
    print(p, r.status_code, len(r.text))
```

## 6. 二分模板
```python
l, r = 0, 10**9
while l < r:
    m = (l + r) // 2
    if check(m):
        r = m
    else:
        l = m + 1
print(l)
```

## 7. DFS / BFS 模板
```python
from collections import deque
q = deque([start])
vis = {start}
while q:
    u = q.popleft()
    for v in graph[u]:
        if v not in vis:
            vis.add(v)
            q.append(v)
```
