# 古典密码与编码

## 1. 概述

古典密码是 CTF 密码学方向的入门基础。虽然现代密码学已经淘汰了这些算法，但在 CTF 竞赛中，古典密码常作为 Misc 题目或 Crypto 入门题出现。核心解题思路是：**识别密码类型 -> 寻找密钥或模式 -> 解密**。

古典密码可分为两大类：
- **置换密码（Transposition）**：改变明文顺序，如栅栏密码、列置换
- **替换密码（Substitution）**：将明文字母替换为其他字母，如凯撒密码、维吉尼亚密码

编码类（Base64、Base32、Hex 等）虽然不属于密码，但常与密码混合考察，也纳入本章。

## 2. 核心原理（含数学推导）

### 2.1 凯撒密码（Caesar Cipher）

凯撒密码是最简单的替换密码：将字母表中每个字母向后偏移固定位置 k。

加密公式：`E(x) = (x + k) mod 26`
解密公式：`D(y) = (y - k) mod 26`

其中 x 为明文字母序号（A=0，B=1，...，Z=25），k 为密钥（偏移量）。

**安全性分析**：密钥空间仅 25 种可能（排除 k=0），暴力枚举即可破解。

### 2.2 维吉尼亚密码（Vigenère Cipher）

维吉尼亚密码使用一个关键词作为密钥，对每个明文字母应用不同的凯撒偏移。

加密公式：`E(x_i) = (x_i + k_i) mod 26`
其中 `k_i = key[i mod len(key)]`

数学意义上，维吉尼亚密码可以表示为：
`C_i = (P_i + K_{i mod m}) mod 26`
其中 m 是密钥长度。

**破解关键**：寻找密钥长度（Kasiski 检验或重合指数法），然后分组做频率分析。

### 2.3 栅栏密码（Rail Fence Cipher）

将明文按锯齿形写入 N 行，再按行读取得到密文。
这是一种纯置换密码。

### 2.4 培根密码（Bacon's Cipher）

使用 A/B 两种字符的 5 位二进制序列编码 26 个字母。
I/J 和 U/V 各共享一个编码，共 2^5 = 32 种编码，恰好覆盖 24 组字母。

### 2.5 Base 家族编码

Base 编码的原理是将字节序列按不同位数重新分组：

- **Base64**：每 6 bit 一组，查表映射到 64 个可打印字符
- **Base32**：每 5 bit 一组，查表映射到 32 个字符
- **Base58**：用于比特币地址，去掉易混淆字符（0OIl）
- **Base85/Ascii85**：每 32 bit 映射为 5 个 ASCII 字符，效率更高

数学上，Base64 编码实现：
```
n 字节序列 = n*8 bit
分组为 ceil(n*8/6) 组，每组 6 bit（不足补 0）
每组对应一个 Base64 字符
输出长度 = ceil(n*8/6) = ceil(4n/3)
填充 '=' 使总长度为 4 的倍数
```

### 2.6 转轮密码（Enigma 风格）

Enigma 密码机使用多个转轮实现多表替换。核心包括：
- **转轮（Rotor）**：内部连线实现字母替换
- **反射器（Reflector）**：将信号反射回去
- **插线板（Plugboard）**：额外交换字母对

数学上，每个转轮可表示为 S_26（26 个字母的置换群）中的一个置换。
整个加密过程是：`E(rotors, plugboard) = PB * R1 * R2 * R3 * REF * R3^-1 * R2^-1 * R1^-1 * PB`

## 3. 关键技巧/攻击方法（含 Python 代码）

### 3.1 凯撒密码爆破

```python
def caesar_bruteforce(ciphertext: str) -> list:
    """爆破凯撒密码，返回所有可能的明文"""
    results = []
    for shift in range(26):
        plain = ""
        for ch in ciphertext:
            if ch.isalpha():
                base = ord('A') if ch.isupper() else ord('a')
                plain += chr((ord(ch) - base - shift) % 26 + base)
            else:
                plain += ch
        results.append((shift, plain))
    return results

# 示例
ct = "Khoor, Zruog!"
for shift, plain in caesar_bruteforce(ct):
    if "Hello" in plain or "hello" in plain:
        print(f"[+] Shift={shift}: {plain}")
```

### 3.2 维吉尼亚密码自动破解

```python
import re
from collections import Counter

def friedman_test(ciphertext: str, max_len: int = 20) -> list:
    """
    Friedman 重合指数法估算维吉尼亚密钥长度
    返回最可能的密钥长度列表
    """
    ct = re.sub(r'[^A-Za-z]', '', ciphertext).upper()
    n = len(ct)
    scores = []

    for m in range(1, min(max_len + 1, n // 2)):
        # 计算重合指数 IC
        ics = []
        for i in range(m):
            group = ct[i::m]
            freq = Counter(group)
            ic = sum(f * (f - 1) for f in freq.values()) / (len(group) * (len(group) - 1)) if len(group) > 1 else 0
            ics.append(ic)
        avg_ic = sum(ics) / len(ics)
        scores.append((m, avg_ic))

    # 英语文本 IC 约 0.065-0.067，找出接近此值的密钥长度
    scores.sort(key=lambda x: abs(x[1] - 0.065))
    return scores[:5]

def crack_vigenere(ciphertext: str) -> tuple:
    """维吉尼亚密码自动破解"""
    ct = re.sub(r'[^A-Za-z]', '', ciphertext).upper()
    n = len(ct)

    # 1. 估算密钥长度
    key_candidates = friedman_test(ct, max_len=15)
    best_key_len = key_candidates[0][0]

    # 2. 逐位破解密钥
    english_freq = 'ETAOINSHRDLCUMWFGYPBVKJXQZ'
    key = ""
    for i in range(best_key_len):
        group = ct[i::best_key_len]
        scores = []
        for shift in range(26):
            decrypted = ''.join(chr((ord(c) - 65 - shift) % 26 + 65) for c in group)
            freq = Counter(decrypted)
            # 计算与英语频率的相似度
            score = sum(freq.get(c, 0) for c in english_freq[:6])
            scores.append((shift, score))
        best_shift = max(scores, key=lambda x: x[1])[0]
        key += chr(best_shift + 65)

    # 3. 解密
    plain = ""
    for i, ch in enumerate(ct):
        shift = ord(key[i % len(key)]) - 65
        plain += chr((ord(ch) - shift - 65) % 26 + 65)

    return key, plain

# 示例
cipher = "LXFOPVEFRNHR"
key, plain = crack_vigenere(cipher)
print(f"[+] Key: {key}")
print(f"[+] Plain: {plain}")
```

### 3.3 栅栏密码破解

```python
def rail_fence_decrypt(ciphertext: str, rails: int) -> str:
    """栅栏密码解密"""
    n = len(ciphertext)
    # 构建栅栏模式
    rail = [['\n' for _ in range(n)] for _ in range(rails)]
    dir_down = None
    row, col = 0, 0

    # 标记位置
    for i in range(n):
        if row == 0:
            dir_down = True
        if row == rails - 1:
            dir_down = False
        rail[row][col] = '*'
        col += 1
        row = 1 if dir_down else row - 1

    # 填充密文
    index = 0
    for i in range(rails):
        for j in range(n):
            if rail[i][j] == '*' and index < n:
                rail[i][j] = ciphertext[index]
                index += 1

    # 读取明文
    result = []
    row, col = 0, 0
    for i in range(n):
        if row == 0:
            dir_down = True
        if row == rails - 1:
            dir_down = False
        if rail[row][col] != '*':
            result.append(rail[row][col])
            col += 1
        row = 1 if dir_down else row - 1

    return ''.join(result)

# 爆破栅栏数
def rail_fence_bruteforce(ciphertext: str, max_rails: int = 20) -> list:
    """爆破所有可能的栅栏数"""
    results = []
    for rails in range(2, min(max_rails + 1, len(ciphertext))):
        plain = rail_fence_decrypt(ciphertext, rails)
        results.append((rails, plain))
    return results
```

### 3.4 培根密码加解密

```python
BACON_TABLE = {
    'A': 'AAAAA', 'B': 'AAAAB', 'C': 'AAABA', 'D': 'AAABB',
    'E': 'AABAA', 'F': 'AABAB', 'G': 'AABBA', 'H': 'AABBB',
    'I': 'ABAAA', 'J': 'ABAAA', 'K': 'ABAAB', 'L': 'ABABA',
    'M': 'ABABB', 'N': 'ABBAA', 'O': 'ABBAB', 'P': 'ABBBA',
    'Q': 'ABBBB', 'R': 'BAAAA', 'S': 'BAAAB', 'T': 'BAABA',
    'U': 'BAABB', 'V': 'BAABB', 'W': 'BABAA', 'X': 'BABAB',
    'Y': 'BABBA', 'Z': 'BABBB'
}

def bacon_encode(plaintext: str) -> str:
    return ''.join(BACON_TABLE.get(ch.upper(), '') for ch in plaintext if ch.isalpha())

def bacon_decode(bacon_str: str) -> str:
    rev_table = {v: k for k, v in BACON_TABLE.items() if k not in ('J', 'V')}
    result = []
    for i in range(0, len(bacon_str), 5):
        chunk = bacon_str[i:i+5]
        if len(chunk) == 5:
            result.append(rev_table.get(chunk.upper(), '?'))
    return ''.join(result)
```

### 3.5 综合编码识别与转换工具

```python
import base64
import binascii

def auto_decode(data: str) -> list:
    """自动尝试常见编码解码，返回所有可能结果"""
    results = []

    # Base64
    try:
        decoded = base64.b64decode(data.encode())
        results.append(('Base64', decoded))
    except Exception:
        pass

    # Base32
    try:
        decoded = base64.b32decode(data.encode().upper())
        results.append(('Base32', decoded))
    except Exception:
        pass

    # Base16 (Hex)
    try:
        decoded = binascii.unhexlify(data)
        results.append(('Hex', decoded))
    except Exception:
        pass

    # Base85
    try:
        decoded = base64.b85decode(data.encode())
        results.append(('Base85', decoded))
    except Exception:
        pass

    # ASCII85
    try:
        decoded = base64.a85decode(data.encode())
        results.append(('Ascii85', decoded))
    except Exception:
        pass

    # Base58
    try:
        ALPHABET = '123456789ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz'
        n = 0
        for c in data:
            n = n * 58 + ALPHABET.index(c)
        result = n.to_bytes((n.bit_length() + 7) // 8, 'big')
        results.append(('Base58', result))
    except Exception:
        pass

    return results

# 使用示例
encoded = "SGVsbG8sIFdvcmxkIQ=="
for fmt, result in auto_decode(encoded):
    print(f"[+] {fmt}: {result.decode('utf-8', errors='replace')}")
```

### 3.6 CTF 中自动化的古典密码检测

```python
import re

def detect_crypto_type(ct: str) -> list:
    """基于密文特征自动判断密码/编码类型"""
    hints = []
    n = len(ct)

    # 纯大写字母，无明显模式 -> 可能是凯撒/维吉尼亚/简单替换
    if re.fullmatch(r'[A-Z]+', ct):
        hints.append("凯撒密码 / 简单替换 / 维吉尼亚密码（纯大写）")
        # IC 检测
        freq = Counter(ct)
        ic = sum(f*(f-1) for f in freq.values()) / (n*(n-1)) if n > 1 else 0
        if 0.06 < ic < 0.07:
            hints.append("  -> 重合指数接近英语文本，可能是置换密码")
        elif ic < 0.05:
            hints.append("  -> 重合指数偏低，可能是多表替换（维吉尼亚等）")

    # Base64 特征
    if re.fullmatch(r'[A-Za-z0-9+/]+=*', ct) and len(ct) % 4 == 0:
        hints.append("Base64（含+/=且长度为4的倍数）")

    # Hex 特征
    if re.fullmatch(r'[0-9A-Fa-f]+', ct) and len(ct) % 2 == 0:
        hints.append("Hex 编码（纯十六进制字符）")

    # Base32 特征
    if re.fullmatch(r'[A-Z2-7]+=*', ct):
        hints.append("Base32（A-Z2-7 + 等号填充）")

    # 大小写混合短字符串 -> 可能是培根密码
    if re.fullmatch(r'[A-Za-z]{5,}', ct):
        hints.append("可能是培根密码（5位一组）")

    return hints
```

## 4. 常见误区与注意事项

1. **大小写问题**：古典密码常忽略大小写，但编码类（Base64）大小写敏感，必须区分。
2. **空格与标点**：古典密码可能保留或丢弃标点，需根据题意判断。
3. **编码"迭代"陷阱**：题目可能 Base64 编码多次（多层套娃），需反复检测。
4. **变种密码**：凯撒密码可能有变体（如 ROT13 是移位 13 的特殊凯撒），Affine 密码（`E(x) = (ax+b) mod 26`）是凯撒的推广。
5. **密钥长度估计**：Friedman 检验在密文较短时可能不准确，需结合 Kasiski 检验交叉验证。
6. **未知密码类型时**：先尝试常见的——换位密码先爆破栅栏数和列数；替换密码先频率分析。
7. **编码伪装**：有些题目会把古典密码结果再编码（如 Hex -> Base64 -> 凯撒），需要分层剥离。

## 5. 实战示例

**场景**：收到一段密文 `Q0FGQ0FFQ0hBVkdCQUFHQVlZSEFCQVdBQVhXQUtBQ0FBQ0FBQkFWQVlHQUhBV0FCSEFBQUFDQUFZR0FIQVdBQ0FBQ0EmIzgyMTI7`

步骤：
1. 结尾 `&#8212;` 是 HTML 实体，先去掉
2. 字符集 `[A-Z0-9]` ，无小写和特殊字符，疑似 Base32
3. Base32 解码得到 Base64 字符串
4. Base64 解码得到仅大写字母字符串
5. 凯撒爆破得到可读文本

```python
import base64, html

def solve_puzzle(raw: str) -> str:
    # 1. HTML 实体解码
    step1 = html.unescape(raw)
    # 2. Base32 解码
    step2 = base64.b32decode(step1)
    # 3. Base64 解码
    step3 = base64.b64decode(step2).decode()
    # 4. 凯撒爆破
    for shift in range(26):
        plain = ''.join(chr((ord(c)-65-shift)%26+65) for c in step3)
        if 'FLAG' in plain or 'CTF' in plain:
            return f"Shift={shift}: {plain}"
    return "Not found"

print(solve_puzzle("Q0FGQ0FFQ0hBVkdCQUFHQVlZSEFCQVdBQVhXQUtBQ0FBQ0FBQkFWQVlHQUhBV0FCSEFBQUFDQUFZR0FIQVdBQ0FBQ0AmIzgyMTI7"))
```

## 6. 相关知识点

- **仿射密码 (Affine Cipher)**：`E(x) = (ax + b) mod 26`，需 gcd(a, 26)=1
- **Playfair 密码**：5x5 矩阵，两两字母加密
- **ADFGVX 密码**：一战德军使用的 6x6 矩阵密码
- **换位密码（Columnar Transposition）**：按列重新排列
- **Hill Cipher**：矩阵乘法加密，需矩阵可逆 mod 26
- **Enigma 密码机**：多转子替换密码机
- **频率分析在线工具**：quipqiup、dCode
- **CTF 常用工具**：CyberChef（瑞士军刀）、Ciphey（自动解密）
- **Base 编码家族**：Base16、Base32、Base36、Base45、Base58、Base62、Base64、Base85、Base91、Base92
- **UUencode/XXencode**：历史邮件编码
- **Morse 电码**：点划编码，常见于 Misc 题
