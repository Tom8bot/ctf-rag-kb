# 离散对数与椭圆曲线密码 (ECC)

## 1. 概述

椭圆曲线密码学 (Elliptic Curve Cryptography, ECC) 是现代密码学中最重要的公钥密码体系之一。与 RSA 相比，ECC 使用更短的密钥达到相同的安全强度。

ECC 的安全性基于**椭圆曲线离散对数问题 (ECDLP)**：给定 P 和 Q = d*P，求 d 是计算上不可行的。

CTF 中 ECC 题目常考察：
- Pohlig-Hellman 攻击（当曲线阶是光滑数时）
- ECDSA nonce 重用
- 无效曲线攻击 (Invalid Curve Attack)
- Smart 攻击（迹为 1 的异常曲线）
- MOV 攻击（利用 Weil/Tate 配对）
- 离散对数的 BSGS 和 Pollard's Rho

## 2. 核心原理（含数学推导）

### 2.1 椭圆曲线定义

Weierstrass 形式：`y^2 = x^3 + ax + b` (mod p)
要求判别式 `Δ = -16(4a^3 + 27b^2) ≠ 0 (mod p)`（非奇异）。

点加运算：
- P + (-P) = O（无穷远点）
- P + P = 2P：λ = (3x_P^2 + a) / (2y_P) mod p
- P + Q (P≠Q)：λ = (y_Q - y_P) / (x_Q - x_P) mod p
- x_R = λ^2 - x_P - x_Q
- y_R = λ(x_P - x_R) - y_P

### 2.2 有限域上的椭圆曲线

E(GF(p)) 构成有限阿贝尔群，根据 Hasse 定理：
`|#E - (p + 1)| ≤ 2√p`

对于标准曲线（secp256k1 等），群的阶通常是素数。

### 2.3 离散对数问题 (DLP)

给定有限群 G，生成元 g 和元素 h = g^x，求 x ∈ {0, ..., ord(g)-1}。

通用攻击算法（时间复杂度均为 O(√n)）：
- **Baby-step Giant-step (BSGS)**：时空权衡
- **Pollard's Rho**：随机游走
- **Pohlig-Hellman**：利用阶的因子分解

### 2.4 Pohlig-Hellman 攻击的数学推导

设 n = ord(G) = ∏ p_i^{e_i}，对每个质因子 p_i^{e_i}：
1. `n_i = n / p_i^{e_i}`
2. `G_i = n_i * G`（阶为 p_i^{e_i}）
3. `H_i = n_i * H`
4. 在子群 <G_i> 中解 DLP，得 x_i ≡ x (mod p_i^{e_i})
5. 用 CRT 组合所有 p_i^{e_i} 恢复完整 x

### 2.5 ECDSA 签名原理

密钥生成：随机私钥 d ← [1, n-1]，公钥 Q = d*G

签名：
1. 随机 nonce k ← [1, n-1]
2. R = k*G，r = R.x mod n
3. s = k^{-1}(h(m) + r*d) mod n
4. 签名为 (r, s)

验证：
1. w = s^{-1} mod n
2. u1 = h(m)*w mod n, u2 = r*w mod n
3. P = u1*G + u2*Q，验证 P.x ≡ r (mod n)

### 2.6 安全分析

若 nonce k 重用，可从两个签名中提取私钥：
已知 k*s1 = h1 + r1*d 和 k*s2 = h2 + r2*d：
`d = (s1*h2 - s2*h1) / (r2*s2 - r1*s1) mod n`

## 3. 关键技巧/攻击方法（含 Python 代码）

### 3.1 Pohlig-Hellman 攻击（SageMath）

```python
# SageMath 代码
def pohlig_hellman_ec(E, G, Q):
    """
    当 E.order() 是光滑数时，Pohlig-Hellman 攻击
    返回私钥 d 满足 Q = d*G
    """
    n = G.order()
    factors = list(factor(n))  # [(p1, e1), (p2, e2), ...]

    residues = []
    moduli = []

    for p, e in factors:
        pe = p**e
        ni = n // pe

        # 映射到子群
        Gi = ni * G
        Qi = ni * Q

        # 在阶为 pe 的子群中解 DLP
        # 可以用 BSGS (当 pe 小时) 或逐个 p 进制位求解
        xi = 0
        for j in range(e):
            factor_pj = p**j
            # 计算当前位的系数
            Gi_part = pe // p**(j+1) * Gi
            Qi_part = pe // p**(j+1) * (Qi - xi * G)
            # BSGS 暴力搜索 p 种可能
            for k in range(p):
                if k * Gi_part == Qi_part:
                    xi += k * factor_pj  # 注意这里应该是 xi += k * p^j
                    break

        residues.append(xi)
        moduli.append(pe)

    # CRT 组合
    d = crt(residues, moduli)
    return d

# 使用示例
# p = 0xfffffffffffffffffffffffffffffffffffffffffffffffffffffffefffffc2f  # secp256k1 太强，换成小参数曲线
# E = EllipticCurve(GF(p), [0, 7])
# G = E(...)
# Q = E(...)
# d = pohlig_hellman_ec(E, G, Q)
```

### 3.2 BSGS（Baby-step Giant-step）

```python
import gmpy2
from math import ceil, sqrt

def bsgs_ec(G, Q, order):
    """
    Baby-step Giant-step for ECC
    时间/空间 O(sqrt(order))
    """
    m = ceil(sqrt(order))
    print(f"[*] BSGS with m={m}")

    # Baby steps: compute {j*G : 0 <= j < m}
    baby_steps = {}
    current = G.curve()(0)  # 无穷远点
    for j in range(m):
        if j % 1000000 == 0:
            print(f"[*] Baby step {j}/{m}")
        baby_steps[(int(current.xy()[0]), int(current.xy()[1]))] = j
        current = current + G

    # Giant steps: compute Q - i*m*G for 0 <= i <= m
    mG = m * G
    neg_mG = -mG
    current = Q
    for i in range(m + 1):
        if i % 100000 == 0:
            print(f"[*] Giant step {i}/{m}")
        xy = (int(current.xy()[0]), int(current.xy()[1]))
        if xy in baby_steps:
            d = i * m + baby_steps[xy]
            return d
        current = current + neg_mG

    return None
```

### 3.3 ECDSA nonce 重用攻击

```python
def ecdsa_nonce_reuse(r1, s1, h1, r2, s2, h2, n):
    """
    ECDSA nonce 重用攻击
    已知两个签名使用相同的 k（r 值相同）
    返回私钥 d
    """
    # d = (s1*h2 - s2*h1) * inv(r*(s1 - s2), n) mod n
    numerator = (s1 * h2 - s2 * h1) % n
    denominator = (r1 * s2 - r1 * s1) % n  # r1 = r2 = r
    denom_inv = gmpy2.invert(denominator, n)
    d = (numerator * denom_inv) % n
    return d

# 已知 k 的部分信息 (k 的低位或高位)
def ecdsa_biased_nonce(r_list, s_list, h_list, n, known_msb, msb_value):
    """
    当 nonce 有偏差时的格攻击
    如 k 的高位已知
    """
    # 构建 HNP (Hidden Number Problem) 格
    # s = k^{-1}(h + r*d) mod n
    # => d*r ≡ s*k - h (mod n)
    # 若 k 的高位已知，可转化为 CVP/SVP 问题
    t = len(r_list)
    B = Matrix(ZZ, t + 2, t + 2)

    for i in range(t):
        B[i, i] = n
        B[t, i] = r_list[i]
        B[t+1, i] = (s_list[i] * msb_value - h_list[i]) % n

    B[t, t] = 1
    B[t+1, t+1] = 2**(known_msb)

    B = B.LLL()

    for row in B:
        if row[t] == 1:
            d = int(row[t+1] * 2**(known_msb)) % n
            return d
        elif row[t] == -1:
            d = int(-row[t+1] * 2**(known_msb)) % n
            return d
    return None
```

```python
from sage.all import *

def find_smooth_order_curve(p, bit_range=(64, 128)):
    '''
    寻找 GF(p) 上阶为光滑数的椭圆曲线（用于构造 CTF 题目）
    '''
    for _ in range(100):
        a = randint(1, p-1)
        b = randint(1, p-1)
        try:
            E = EllipticCurve(GF(p), [a, b])
            n = E.order()
            if n < 2**bit_range[1]:
                max_factor = max(f[0]**f[1] for f in factor(n))
                if max_factor < 2**40:
                    return E, n
        except:
            continue
    return None

def find_generator(E):
    '''
    找到椭圆曲线的生成元
    '''
    n = E.order()
    factors = list(factor(n))
    # 寻找不是任何 (n/pi)*G = O 的点
    for _ in range(100):
        x = randint(0, E.base_field().characteristic()-1)
        try:
            G = E.lift_x(x)
            good = True
            for p, _ in factors:
                if (n // p) * G == E(0):
                    good = False
                    break
            if good:
```

## 4. 常见误区与注意事项

1. **ECDLP vs DLP**：ECC 上没有亚指数时间算法（一般曲线），因此 256-bit ECC 约等于 3072-bit RSA。
2. **迹为 1 的异常曲线**：若 `#E(GF(p)) = p`，则 Smart 攻击可行，必须在多项式时间内解 DLP。
3. **曲线的安全性验证**：生产环境必须在生成曲线上验证点（check `y^2 = x^3 + ax + b mod p`），否则存在无效曲线攻击。
4. **nonce (k) 的随机性**：ECDSA 的 nonce 必须均匀随机且保密，任何偏差都可能通过 HNP（隐藏数问题）格攻击利用。
5. **嵌入度**：配对友好曲线（BN254、BLS12-381）必须选择合适的嵌入度 k，需权衡安全性和效率。
6. **曲线参数标准化**：CTF 常用自定义曲线而非标准曲线（NIST/secp256k1），需检查参数是否有意留下后门。
7. **点的大小**：ECC 计算耗时随曲线阶的位数的平方增长，101-bit 以上曲线的 BSGS 需要大量存储。

## 5. 实战示例

**场景**：题目给出一个小参数 ECC 加密，p 为 64 位素数，曲线的阶是光滑数。

```python
#!/usr/bin/env sage
# Small ECC CTF Challenge
p = 0xabcdef123456789
a = 0x12345
b = 0x67890

E = EllipticCurve(GF(p), [a, b])
print(f"[*] Curve: {E}")
print(f"[*] Order: {E.order()}")
print(f"[*] Factorization: {factor(E.order())}")

# 接收题目参数
flag_enc = (E(x1, y1), E(x2, y2))  # 假设加密结果

# Pohlig-Hellman 攻击
def solve_ecdlp_pohlig_hellman(G, Q, n, factors):
    residues = []
    moduli = []
    for pi, ei in factors:
        pe = pi**ei
        ni = n // pe
        Gi = ni * G
        Qi = ni * Q
        xi = discrete_log(Qi, Gi, ord=pe, operation='+')
        residues.append(xi)
        moduli.append(pe)
    return crt(residues, moduli)

# 执行
d = solve_ecdlp_pohlig_hellman(G, Q, n, list(factor(n)))
print(f"[+] Private key: {d}")
```

## 6. 相关知识点

- **Weierstrass 曲线**：y^2=x^3+ax+b（最常见形式）
- **Montgomery 曲线**：By^2=x^3+Ax^2+x（Curve25519）
- **Edwards 曲线**：x^2+y^2=1+dx^2y^2（Ed25519，高效且安全的签名方案）
- **配对 (Pairings)**：Weil/Tate/Ate 配对（用于 BLS 签名、IBE）
- **ECDH**：椭圆曲线 Diffie-Hellman 密钥交换
- **ECIES**：椭圆曲线集成加密方案
- **ElGamal on ECC**：ECC 上的 ElGamal 加密
- **Schnorr 签名**：基于离散对数的简洁签名方案
- **BLS 签名**：基于配对的聚合签名
- **Sato's HNP**：使用 Sato 算法解决隐藏数问题，恢复部分泄露的 ECDSA nonce
- **Twist Security**：曲线的二次 twist 的安全性
- **NUMS (Nothing Up My Sleeve)**：确定性曲线参数生成
