# 多方计算与同态加密入门

## 1. 概述

安全多方计算 (Secure Multi-Party Computation, MPC) 和同态加密 (Homomorphic Encryption, HE) 是密码学前沿方向，近年来在 CTF 中出现的频率逐渐增加。

**安全多方计算 (MPC)**：n 方各自持有私有输入 x_i，共同计算函数 f(x_1, ..., x_n)，且任何一方不能获知其他方的输入（除函数输出透露的信息外）。

**同态加密 (HE)**：在密文上直接执行运算，解密结果等于对明文执行相同运算的结果。

CTF 考察重点：
- **Shamir 秘密分享**的构造与恢复
- **加法/乘法秘密分享**的协议
- **不经意传输 (OT)** 的实现与攻击
- **混淆电路 (Garbled Circuit)** 的基本原理
- **半同态加密 (PHE)** 的基本攻击
- **OT 的 cut-and-choose 验证**

## 2. 核心原理（含数学推导）

### 2.1 Shamir 秘密分享 (t-out-of-n)

基于多项式插值：将秘密 s 作为常数项，构造 t-1 次多项式：
`f(x) = s + a_1*x + a_2*x^2 + ... + a_{t-1}*x^{t-1}`
其中 a_i 是随机系数。

份额：`s_i = f(i), i = 1, 2, ..., n`

恢复：任意 t 个份额通过拉格朗日插值恢复 f(0) = s。

**拉格朗日插值公式**：
`f(0) = Σ s_i * λ_i`，其中 `λ_i = Π_{j!=i} (0 - j)/(i - j)`

**加法同态性**（在有限域内）：
`share_i(a) + share_i(b) = share_i(a + b)`

**乘法**需要交互协议（Gennaro、Rabin、Rabin 协议或 Beaver 三元组）。

### 2.2 不经意传输 (Oblivious Transfer, OT)

**1-out-of-2 OT**：
- 发送方有 m_0, m_1
- 接收方有选择比特 b
- 接收方获得 m_b，且不知 m_{1-b}
- 发送方不知 b

基于 RSA 实现：
1. 发送方生成 RSA 密钥 (N, e)，选随机数 x_0, x_1
2. 接收方选随机数 k，计算 v = (k^e + x_b) mod N 发给发送方
3. 发送方计算 k_0' = (v - x_0)^{1/e} mod N, k_1' = (v - x_1)^{1/e} mod N
4. 发送方发 m_0 ⊕ k_0' 和 m_1 ⊕ k_1'
5. 接收方用 k 解密 m_b

### 2.3 同态加密类型

- **部分同态加密 (PHE)**：仅支持加法或乘法其中之一
  - 加法：Paillier
  - 乘法：RSA（无填充）、ElGamal
- **层级同态加密 (SHE)**：支持有限深度的加法和乘法
  - BGV、BFV、CKKS
- **全同态加密 (FHE)**：支持任意深度的运算
  - Gentry 2009（基于理想格）、TFHE、HEAAN

**Paillier 加密的加法同态性**：
`E(m1) * E(m2) = g^{m1}r1^N * g^{m2}r2^N = g^{m1+m2}(r1*r2)^N = E(m1 + m2)`

### 2.4 混淆电路 (Garbled Circuit)

Yao 协议 (1986)：

1. **混淆器 (Garbler)**：为电路的每条线（wire）生成两个随机标签（0 和 1）
2. **加密门真值表**：对每个门，用输入线标签作为密钥加密对应的输出线标签
3. **乱序**：将所有加密后的门真值表随机排列
4. **求值器 (Evaluator)**：使用自己输入的标签按拓扑序"解锁"每个门的输出
5. 收到最终输出标签，通过映射表恢复明文结果

每道门的加密（以 AND 门为例）：
- 输入线 A（标签 A_0, A_1），输入线 B（标签 B_0, B_1）
- 输出线 C（标签 C_0, C_1）
- 4 个双重加密密文：
  - Enc_{A_0}(Enc_{B_0}(C_{0}))
  - Enc_{A_0}(Enc_{B_1}(C_{0}))
  - Enc_{A_1}(Enc_{B_0}(C_{0}))
  - Enc_{A_1}(Enc_{B_1}(C_{1}))

## 3. 关键技巧/攻击方法（含 Python 代码）

### 3.1 Shamir 秘密分享实现

```python
from functools import reduce
import operator
import secrets

class ShamirSecretSharing:
    """Shamir (t, n) 秘密分享"""

    def __init__(self, prime=2**127 - 1):
        """
        使用梅森素数 2^127 - 1 作为有限域的阶
        """
        self.prime = prime

    def split(self, secret: int, t: int, n: int) -> list:
        """
        将秘密 s 分割为 n 份，任意 t 份可恢复

        参数:
            secret: 要分享的秘密（< prime）
            t: 阈值（重建需要的最少份额数）
            n: 总份额数
        返回:
            [(1, s1), (2, s2), ..., (n, sn)]
        """
        assert 0 <= secret < self.prime
        assert 1 <= t <= n

        # 生成随机多项式系数
        coeffs = [secret] + [secrets.randbelow(self.prime) for _ in range(t - 1)]

        shares = []
        for x in range(1, n + 1):
            y = self._eval_poly(coeffs, x)
            shares.append((x, y))

        return shares

    def reconstruct(self, shares: list) -> int:
        """
        使用拉格朗日插值从 t 份份额恢复秘密

        参数:
            shares: [(x1, y1), (x2, y2), ...] 至少 t 个
        返回:
            恢复的秘密
        """
        secret = 0
        for i, (xi, yi) in enumerate(shares):
            # 计算拉格朗日基多项式在 x=0 的值
            num = den = 1
            for j, (xj, _) in enumerate(shares):
                if i != j:
                    num = (num * (-xj)) % self.prime
                    den = (den * (xi - xj)) % self.prime
            lagrange_coeff = (num * pow(den, -1, self.prime)) % self.prime
            secret = (secret + yi * lagrange_coeff) % self.prime

        return secret

    def _eval_poly(self, coeffs: list, x: int) -> int:
        """在点 x 求值多项式"""
        result = 0
        x_pow = 1
        for coeff in coeffs:
            result = (result + coeff * x_pow) % self.prime
            x_pow = (x_pow * x) % self.prime
        return result

    def add_shares(self, share_a, share_b):
        """
        秘密分享的加法同态性（本地操作）
        两个份额的加法 = 秘密和的份额
        """
        (x1, y1) = share_a
        (x2, y2) = share_b
        assert x1 == x2, "Shares must have the same x coordinate"
        return (x1, (y1 + y2) % self.prime)

# 使用示例
sss = ShamirSecretSharing()
secret = 12345678901234567890
shares = sss.split(secret, t=3, n=5)
print(f"Shares: {shares}")
recovered = sss.reconstruct(shares[:3])
print(f"Recovered: {recovered}, match: {recovered == secret}")
```

### 3.2 基于 RSA 的 1-out-of-2 OT 实现

```python
import gmpy2
import secrets
from hashlib import sha256

def rsa_ot_sender(m0: bytes, m1: bytes, N, e, d, x0, x1):
    """
    OT 发送方（Alice）

    参数:
        m0, m1: 两条消息
        N, e, d: RSA 密钥（发送方持有私钥 d）
        x0, x1: 发送方选的两个随机数（公开给接收方）
    """
    # 接收方发送 v = (k^e + x_b) mod N
    v = yield  # 接收 v

    # 计算 k0' 和 k1'
    k0_prime = pow(v - x0, d, N)
    k1_prime = pow(v - x1, d, N)

    # 将 k0', k1' 扩展到与消息相同长度
    k0_hash = sha256(str(k0_prime).encode()).digest()
    k1_hash = sha256(str(k1_prime).encode()).digest()

    # 加密消息
    enc_m0 = bytes(a ^ b for a, b in zip(m0.ljust(32, b'\x00'), k0_hash))
    enc_m1 = bytes(a ^ b for a, b in zip(m1.ljust(32, b'\x00'), k1_hash))

    return enc_m0, enc_m1

def rsa_ot_receiver(b: int, N, e, x0, x1):
    """
    OT 接收方（Bob）

    参数:
        b: 选择比特 (0 或 1)
        N, e: RSA 公钥
        x0, x1: 发送方的随机数
    """
    k = secrets.randbelow(N)
    x_b = x0 if b == 0 else x1
    v = (pow(k, e, N) + x_b) % N

    # 发送 v 给发送方
    enc_m0, enc_m1 = yield v  # 收到加密的 m0, m1

    # 解密选择的消息
    k_hash = sha256(str(k).encode()).digest()
    if b == 0:
        m = bytes(a ^ b for a, b in zip(enc_m0, k_hash))
    else:
        m = bytes(a ^ b for a, b in zip(enc_m1, k_hash))
    return m.rstrip(b'\x00')
```

### 3.3 Paillier 同态加密与攻击

```python
import gmpy2
import secrets

class Paillier:
    """Paillier 加法同态加密实现"""

    def __init__(self, key_size=512):
        """生成密钥"""
        self.key_size = key_size

    def keygen(self):
        """密钥生成"""
        p = gmpy2.next_prime(secrets.randbits(self.key_size // 2))
        q = gmpy2.next_prime(secrets.randbits(self.key_size // 2))

        self.n = p * q
        self.n_sq = self.n * self.n
        self.lmbda = int(gmpy2.lcm(p - 1, q - 1))

        # 选择 g = n + 1
        self.g = self.n + 1

        # 预计算 mu
        self.mu = int(gmpy2.invert(
            (pow(self.g, self.lmbda, self.n_sq) - 1) // self.n,
            self.n
        ))

        self.public_key = (self.n, self.g)
        self.private_key = (self.lmbda, self.mu)

    def encrypt(self, m: int) -> int:
        """加密明文 m（0 <= m < n）"""
        r = secrets.randbelow(self.n - 1) + 1
        # c = g^m * r^n mod n^2
        c = (pow(self.g, m, self.n_sq) * pow(r, self.n, self.n_sq)) % self.n_sq
        return int(c)

    def decrypt(self, c: int) -> int:
        """解密密文 c"""
        x = pow(c, self.lmbda, self.n_sq) - 1
        m = (x // self.n) * self.mu % self.n
        return int(m)

    def add_encrypted(self, c1: int, c2: int) -> int:
        """
        同态加法：E(m1) * E(m2) = E(m1 + m2) mod n^2
        """
        return (c1 * c2) % self.n_sq

    def scalar_mult(self, c: int, k: int) -> int:
        """
        同态标量乘法：E(m)^k = E(k * m) mod n^2
        """
        return pow(c, k, self.n_sq)

    def add_plain(self, c: int, plain: int) -> int:
        """
        密文加明文：E(m) * g^plain = E(m + plain)
        """
        return (c * pow(self.g, plain, self.n_sq)) % self.n_sq

# Paillier 安全注意事项与攻击
def paillier_security_notes():
    """Paillier 的实现安全注意事项（CTF 可能考察的漏洞）"""
    notes = {
        "r不能为0": "如果 r=0，c = g^m mod n^2，泄露信息",
        "r必须与n互素": "gcd(r, n) != 1 时可分解 n",
        "g的选择": "g = n+1 简化计算且安全",
        "m的范围": "必须 0 <= m < n，超出会取模导致解密错误",
        "IND-CPA": "Paillier 是概率公钥加密，IND-CPA 安全",
        "同态性利用": "E(m1)^m2 = E(m1*m2) 会导致指数级增长",
    }
    return notes
```

### 3.4 混淆电路 (Garbled Circuit) 简化实现

```python
import hashlib
import os
import secrets

def garble_and_gate():
    """
    Yao 混淆电路的简化实现：AND 门
    """
    # 每条线有两个标签（0 和 1）
    key_size = 16  # 128-bit keys

    # 输入线 A 和 B，输出线 C
    A0 = os.urandom(key_size)
    A1 = os.urandom(key_size)
    B0 = os.urandom(key_size)
    B1 = os.urandom(key_size)
    C0 = os.urandom(key_size)
    C1 = os.urandom(key_size)

    # AND 门真值表：(A=0, B=0) -> C=0, (0,1)->0, (1,0)->0, (1,1)->1
    table = [
        (A0, B0, C0),
        (A0, B1, C0),
        (A1, B0, C0),
        (A1, B1, C1),
    ]

    # 加密真值表：使用 AES 或 HMAC 作为加密原语
    def encrypt_rows(table):
        result = []
        for a_key, b_key, c_key in table:
            # 用 A_key 和 B_key 派生加密密钥
            derived = hashlib.sha256(a_key + b_key).digest()
            # XOR 加密输出标签
            encrypted = bytes(x ^ y for x, y in zip(c_key.ljust(32, b'\x00'), derived))
            result.append(encrypted)
        # 乱序
        secrets.SystemRandom().shuffle(result)
        return result

    garbled_table = encrypt_rows(table)

    # 求值者只知道自己的输入标签（不知道是 0 还是 1）
    # 通过遗忘传输获得对方的输入标签
    # 尝试所有可能的加密行来解密
    def evaluate(A_label, B_label, garbled_table_):
        derived = hashlib.sha256(A_label + B_label).digest()
        for encrypted_row in garbled_table_:
            decrypted = bytes(x ^ y for x, y in zip(encrypted_row[:key_size], derived[:key_size]))
            # 输出标签的前缀用于验证正确性
            if decrypted[:4] == C0[:4] or decrypted[:4] == C1[:4]:
                return decrypted
        return None

    # 测试
    result = evaluate(A1, B1, garbled_table)
    assert result == C1, "Garbled circuit evaluation failed"
    print("[+] Garbled AND gate: OK")
```

### 3.5 Beaver 乘法三元组生成

```python
def beaver_triple_generation(N, e, d, prime):
    """
    使用 Paillier 同态加密生成 Beaver 乘法三元组
    (a, b, c) 其中 c = a*b mod prime

    这是 MPC 离线阶段的核心操作
    """
    paillier = Paillier()
    paillier.n = N
    paillier.public_key = (N, N + 1)

    # 替代方案：使用简单的 OT 生成 Beaver 三元组
    # 简化版：使用 Shamir 秘密分享 + 交互协议

    def generate_beaver():
        """多方共同生成 Beaver 三元组"""
        # 方1：生成随机 a1, b1
        a1 = secrets.randbelow(prime)
        b1 = secrets.randbelow(prime)

        # 方2：生成随机 a2, b2
        a2 = secrets.randbelow(prime)
        b2 = secrets.randbelow(prime)

        # a = a1 + a2 mod prime（秘密分享形式）
        # b = b1 + b2 mod prime（秘密分享形式）

        # 需要计算 c = a*b = (a1+a2)(b1+b2)
        # c = a1*b1 + a1*b2 + a2*b1 + a2*b2
        # 方1计算 c1 = a1*b1（本地）
        # 交叉项通过 OT 或同态加密计算

        # 简化：直接生成（模拟 trust setup）
        a = secrets.randbelow(prime)
        b = secrets.randbelow(prime)
        c = (a * b) % prime

        # 分割为份额
        a1 = secrets.randbelow(prime)
        a2 = (a - a1) % prime
        b1 = secrets.randbelow(prime)
        b2 = (b - b1) % prime
        c1 = secrets.randbelow(prime)
        c2 = (c - c1) % prime

        return ((a1, b1, c1), (a2, b2, c2))

    return generate_beaver()

def mpc_multiplication(x_share, y_share, beaver_triple, prime):
    """
    使用 Beaver 三元组进行 MPC 乘法（在线阶段）
    x_share, y_share: 各方的 x 和 y 份额
    beaver_triple: (a_i, b_i, c_i)
    """
    a_i, b_i, c_i = beaver_triple

    # 公开 d = x - a, e = y - b
    d_i = (x_share - a_i) % prime
    e_i = (y_share - b_i) % prime

    # 重建 d 和 e（各方 share d_i, e_i）
    # d = d_1 + d_2 mod prime
    # e = e_1 + e_2 mod prime

    # 计算 z = c + e*a + d*b + d*e
    z_share = (c_i + e_i * a_i + d_i * b_i + d_i * e_i) % prime
    return z_share
```

## 4. 常见误区与注意事项

1. **Shamir vs 加性秘密分享**：Shamir 分享在 Lagrance 插值域中恢复（需要有限域运算），加性分享直接相加（简单但无阈值特性）。
2. **OT 的底层假设**：基于 RSA 的 OT 需要 RSA 假设；非基于密码假设的 OT 可在量子计算模型下通过物理不可克隆函数实现。
3. **混淆电路的开销**：每道门约需 4 次加密操作 + 4 次数据传输，对于复杂函数（如 AES 电路包含约数万个门），开销可观。
4. **Garbled Circuit 的 cut-and-choose**：混淆器可能作弊（生成错误的电路），需 cut-and-choose 验证（混淆器生成多个电路副本，求值者随机打开部分验证）。
5. **同态加密的密文膨胀**：Paillier 密文是 N^2 的大小（512-bit 密钥 -> 1024-bit 密文），FHE 密文更大（几 MB 到几十 MB）。
6. **FHE 的噪声管理**：每次乘法导致噪声翻倍，必须周期性地"自举"(bootstrapping) 刷新噪声。
7. **Beaver 三元组的离线特性**：在线阶段仅需本地操作，非常高效；离线阶段的辅助协议可在提前进行。

## 6. 相关知识点

- **GMW 协议**：基于 OT 的布尔电路 MPC (Goldreich-Micali-Wigderson, 1987)
- **BGW 协议**：基于 Shamir 分享的算术电路 MPC (Ben-Or-Goldwasser-Wigderson, 1988)
- **SPDZ / MASCOT**：实用恶意安全 MPC 协议，基于同态 MAC
- **Garbled Circuit 优化**：Free-XOR、Half-Gate 技术（显著降低混淆电路开销）
- **OT Extension**：从少量的 base-OT 扩展到大量的 OT（Ishai-Kilian-Nissim-Petrank 协议）
- **BGV / BFV**：基于 RLWE 的层级同态加密方案
- **CKKS**：支持近似实数运算的同态加密（机器学习友好）
- **TFHE**：超快速自举的 FHE 方案（门计时约 13ms）
- **PSI (Private Set Intersection)**：隐私集合求交（OT 的重要应用）
- **PIR (Private Information Retrieval)**：隐私信息检索
- **Secret Sharing Schemes**：Blakley 方案、Asmuth-Bloom 方案
- **Threshold Signatures**：基于秘密分享的分布式签名
- **Oblivious RAM (ORAM)**：隐藏访问模式的隐私保护数据存取
