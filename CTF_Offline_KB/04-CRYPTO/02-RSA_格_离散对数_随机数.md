# RSA / 格 / 离散对数 / 随机数

---

## 1. RSA 开局总表

给出 `n,e,c` 时先检查：
1. `n` 能否分解？
2. `e` 是否过小？
3. 是否多组 `(n,e,c)` 存在共模/共因子/广播？
4. 是否给了 `dp,dq,phi,p+q,p-q,highbits,leak`？
5. 是否是签名/解密 oracle？

---

## 2. 基础公式

- `n = p * q`
- `phi = (p-1)(q-1)`
- `d = e^{-1} mod phi`
- `m = c^d mod n`

### Python 最小模板
```python
from Crypto.Util.number import *
phi = (p-1)*(q-1)
d = inverse(e, phi)
m = pow(c, d, n)
print(long_to_bytes(m))
```

## 3. 常见 RSA 弱点

## 3.1 直接分解 n
### 场景
- p/q 太小
- p,q 太近
- 已知一部分位
- 给了 hint 足以恢复

### p,q 很近
若 `p ≈ q`，可用费马分解：
```text
a = ceil(sqrt(n)), 找 a^2-n 是否为平方
```

## 3.2 共因子 gcd
### 场景
多组 n 中有重复素因子：
```python
g = gcd(n1, n2)
```
- 若 `g > 1`，立即分解两者

## 3.3 共模攻击
### 条件
- 同一 n
- 不同互素公钥 `e1,e2`
- 同一明文得到 `c1,c2`

### 思路
扩展欧几里得求 `a,b` 使 `a*e1+b*e2=1`
然后：
```text
m = c1^a * c2^b mod n
```
负指数要转逆元。

## 3.4 小 e / 低明文 / 无填充
### 场景
- `e=3`
- `m^e < n`

### 结论
这时 `c = m^e`，直接开 e 次根即可。

## 3.5 广播攻击（Håstad）
### 条件
- 同一明文
- 不同模数 n1,n2,...
- 同样小 e
- 模数两两互素

### 思路
CRT 合并出 `m^e`，再开根。

## 3.6 已知 dp/dq
### 条件
给出 `dp = d mod (p-1)` 或 `dq`

### 思路
常可结合：
```text
e*dp - 1 = k*(p-1)
```
枚举小 k 恢复 p。

## 3.7 已知 phi / p+q
- 若已知 `phi`，可直接解二元方程恢复 p,q
- 若已知 `s=p+q`：
```text
x^2 - s*x + n = 0
```

## 4. 格攻击 / Coppersmith 思维

> 不要求离线小模型完整手推格算法，但必须知道“什么时候该想到它”。

## 4.1 适用信号
- 泄露了 p/q/d/m 的高位或低位
- 明文部分已知，剩余部分较短
- 小根问题、近似问题
- 题目明显给了多项式关系

## 4.2 小模型应输出
- 这是“部分泄露 + 小根”类型
- 常考虑 Coppersmith / LLL / 格基约化
- 若本地无现成脚本，先尝试是否能用更简单方式（gcd / 方程 / 枚举）解掉

### 原则
只有当“泄露足够多，未知部分足够小”时，格方法才值得优先考虑。

## 5. 离散对数 / DH / ElGamal

## 5.1 信号
- 模素数 p
- 生成元 g
- `y = g^x mod p`
- 求 x 或共享密钥

## 5.2 常见弱点
- p 很小，可 BSGS
- 随机数复用
- 私钥范围小
- 参数不安全

## 5.3 BSGS 思维
适合中等规模离散对数：
```text
g^x = y mod p
x = i*m - j
```
分 baby-step / giant-step 哈希查找。

## 6. 随机数题

## 6.1 高频来源
- `rand()` / `srand(time(0))`
- Python random(MT19937)
- Java Random
- LCG 线性同余
- nonce/IV/seed 可预测

## 6.2 识别思路
- 输出序列线性相关
- 多次输出来自同一状态机
- seed 来自时间、PID、短 key

## 6.3 LCG
形式：
```text
x_{n+1} = (a*x_n + c) mod m
```
### 做法
- 从连续输出恢复参数/状态
- 再预测后续值

## 6.4 MT19937
### 场景
- 给足够多的连续输出，可恢复内部状态
- 题目可能用它生成 key/nonce/token

### 思维
- 收集足够输出
- untemper
- 克隆状态

## 6.5 nonce 重用
### 影响
- 流密码 keystream 重用
- 签名算法（DSA/ECDSA）泄露私钥

### 小模型要记
**随机数复用往往比算法本身更致命。**

## 7. 签名题

## 7.1 RSA 签名
- 签名验证是 `sig^e mod n`
- 看是否 padding 校验不严
- 看是否存在乘法同态滥用

## 7.2 DSA / ECDSA
### 高频弱点
- nonce `k` 重复
- nonce 可预测 / 部分泄露

### 结论
重复 k 会直接恢复私钥。

---

## 8. Oracle 题思维

### 8.1 RSA LSB Oracle / Padding Oracle
- 你不能直接解密，但能询问“某性质是否成立”
- 通过多次交互逐步缩小明文范围

### 小模型要点
- 先判断 oracle 返回的是哪类信息：奇偶、padding 是否正确、比较大小、错误类型
- 再把它转成“区间缩小”问题

---

## 9. 最短作战模板

```text
RSA：先 gcd/分解/小e/共模/广播/泄露参数
格：只有部分泄露且未知量足够小时考虑
离散对数：先看参数是否小或随机数是否复用
随机数：优先想 seed 可预测、状态可恢复、nonce 重用
签名题：优先查重复 nonce
```
