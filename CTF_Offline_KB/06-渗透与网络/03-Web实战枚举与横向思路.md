# Web 实战枚举与横向思路

---

## 1. 枚举顺序
1. 首页、robots、sitemap
2. JS、source map、接口路径
3. 常见备份与隐藏文件
4. 登录注册上传下载导入导出
5. 子域/API/管理面板
6. 用户角色差异

---

## 2. 重点对象
- 源码备份：`.git`, `.svn`, `.swp`, `.bak`, `~`
- 配置：`.env`, `config.*`, `application.properties`
- 调试：`/debug`, `/actuator`, `/swagger`, `/graphql`
- 接口：移动端、管理端、内网端点残留

---

## 3. 横向思维
- 一个接口拿到用户名 -> 爆另一个登录点
- 一个配置拿到 DB/API 凭据 -> 调内部接口
- 一个子域上传 -> 另一个子域解析
- 一个用户越权 -> 拿管理员操作 -> 查看更隐蔽数据

---

## 4. 最短作战模板

```text
先枚举所有入口，再把获得的“用户名/密码/路径/key/源码”当成其他入口的燃料继续横向。
```
