# 网络协议基础与抓包分析

## 1. 概述

网络协议分析和抓包是CTF中Web、Misc、Network类题目的核心技能。无论是分析Misc题目中的pcap文件，还是在Web题目中构造特殊的HTTP请求，都需要扎实的协议基础和抓包分析能力。断网环境下，Wireshark和tshark是主要的分析工具。

### CTF中的网络分析场景

| 场景 | 工具 | 题目类型 |
|------|------|----------|
| PCAP文件分析 | Wireshark/tshark | Misc/Network |
| HTTP请求构造/分析 | curl/Burp/Wireshark | Web |
| 网络协议逆向 | Wireshark/Scapy | Misc/Reverse |
| 数据包重组/提取 | tshark/Scapy | Misc/Forensics |
| SSL/TLS解密 | Wireshark(需要密钥) | Web/Misc |
| 流量特征分析 | Wireshark/自定义脚本 | Misc |

## 2. 核心原理

### 2.1 TCP/IP协议栈

```
┌──────────────────────┐
│    应用层 (L7)        │  HTTP, HTTPS, DNS, FTP, SSH, SMTP
├──────────────────────┤
│    传输层 (L4)        │  TCP (可靠), UDP (不可靠)
├──────────────────────┤
│    网络层 (L3)        │  IP (IPv4/IPv6), ICMP, ARP
├──────────────────────┤
│    链路层 (L2)        │  Ethernet, WiFi (802.11)
└──────────────────────┘
```

### 2.2 TCP三次握手与四次挥手

```
三次握手:                          四次挥手:
Client          Server            Client          Server
  |---SYN------->|                  |---FIN------->|
  |<--SYN+ACK----|                  |<--ACK--------|
  |---ACK------->|                  |<--FIN--------|
  |               |                  |---ACK------->|
[连接建立]                          [连接关闭]
```

### 2.3 HTTP请求结构

```
GET /index.html HTTP/1.1          ← 请求行（方法 URI 协议版本）
Host: example.com                 ← 请求头（Header）
User-Agent: Mozilla/5.0
Accept: text/html
Cookie: session=abc123
                                  ← 空行（CRLF分隔）
[可选的请求体]                     ← Body（POST/PUT等）
```

### 3.2 tshark命令行分析

```bash
# ===== 基础分析 =====
# 统计协议层次
tshark -r capture.pcap -q -z io,phs

# 显示所有HTTP请求
tshark -r capture.pcap -Y 'http.request' -T fields \
    -e http.request.method -e http.request.uri -e http.host

# 提取HTTP请求的完整URI
tshark -r capture.pcap -Y 'http.request' -T fields \
    -e http.request.full_uri

# 提取HTTP POST数据
tshark -r capture.pcap -Y 'http.request.method == POST' -T fields \
    -e http.file_data

# ===== 数据导出 =====
# 导出HTTP对象（文件）
tshark -r capture.pcap --export-objects "http,export_dir"

# 导出为JSON
tshark -r capture.pcap -T json > capture.json

# 导出指定字段为CSV
tshark -r capture.pcap -T fields -E separator=, -E quote=d \
    -e frame.number -e ip.src -e ip.dst -e tcp.port > output.csv

# ===== TCP流提取 =====
# 提取特定TCP流
tshark -r capture.pcap -q -z follow,tcp,ascii,0

# 提取所有TCP流中的数据
tshark -r capture.pcap -Y 'tcp.payload' -T fields -e tcp.payload

# ===== DNS分析 =====
# 提取所有DNS查询
tshark -r capture.pcap -Y 'dns.flags.response == 0' -T fields \
    -e dns.qry.name

# 提取DNS查询和响应
tshark -r capture.pcap -Y 'dns' -T fields \
    -e frame.number -e dns.qry.name -e dns.resp.addr

# ===== 统计 =====
# 端点统计
tshark -r capture.pcap -q -z endpoints,ip

# 会话统计
tshark -r capture.pcap -q -z conv,tcp

# HTTP统计
tshark -r capture.pcap -q -z http,stat,

# HTTP请求树
tshark -r capture.pcap -q -z http,tree
```

### 3.3 Scapy数据包分析脚本

```python
#!/usr/bin/env python3
"""
pcap_analyzer.py - PCAP文件综合分析脚本
"""

from scapy.all import *
from collections import Counter, defaultdict
import re
import json
from typing import List, Dict, Set, Tuple

class PcapAnalyzer:
    """PCAP文件分析器"""
    
    def __init__(self, pcap_file: str):
        self.file = pcap_file
        self.packets = rdpcap(pcap_file)
        print(f'[*] 加载 {len(self.packets)} 个数据包')
    
    def get_summary(self) -> dict:
        """获取基本概况"""
        summary = {
            'total_packets': len(self.packets),
            'protocols': Counter(),
            'endpoints': set(),
            'tcp_ports': set(),
            'udp_ports': set(),
        }
        
        for pkt in self.packets:
            summary['protocols'][pkt.sprintf('%IP.proto%')] += 1
            if IP in pkt:
                summary['endpoints'].add(pkt[IP].src)
                summary['endpoints'].add(pkt[IP].dst)
            if TCP in pkt:
                summary['tcp_ports'].add(pkt[TCP].sport)
                summary['tcp_ports'].add(pkt[TCP].dport)
            if UDP in pkt:
                summary['udp_ports'].add(pkt[UDP].sport)
                summary['udp_ports'].add(pkt[UDP].dport)
        
        return summary
    
    def extract_http_objects(self, output_dir: str = './http_objects'):
        """提取HTTP传输的文件"""
        import os
        os.makedirs(output_dir, exist_ok=True)
        
        # 使用Scapy重组HTTP流
        http_payloads = defaultdict(bytes)
        
        for pkt in self.packets:
            if TCP in pkt and Raw in pkt:
                # 简单按流(key)重组数据
                key = f'{pkt[IP].src}:{pkt[TCP].sport}-{pkt[IP].dst}:{pkt[TCP].dport}'
                http_payloads[key] += pkt[Raw].load
        
        # 从重组数据中提取HTTP对象
        for key, data in http_payloads.items():
            if b'HTTP/' in data:
                # 尝试提取文件
                header_end = data.find(b'\r\n\r\n')
                if header_end != -1:
                    body = data[header_end+4:]
                    if body:
                        filename = f'{output_dir}/stream_{key.replace(":", "_").replace("-", "_")}.bin'
                        with open(filename, 'wb') as f:
                            f.write(body)
                        print(f'[+] 提取: {filename} ({len(body)} bytes)')
    
    def find_flags(self) -> List[str]:
        """搜索flag（多种策略）"""
        flags = []
        patterns = [
            rb'flag\{[^}]+\}',
            rb'ctf\{[^}]+\}',
            rb'FLAG\{[^}]+\}',
        ]
        
        # 策略1: 直接搜索所有数据包内容
        for pkt in self.packets:
            if Raw in pkt:
                for pattern in patterns:
                    matches = re.findall(pattern, pkt[Raw].load)
                    flags.extend(m.decode() for m in matches)
        
        # 策略2: 搜索重组后的TCP流
        tcp_streams = defaultdict(bytes)
        for pkt in self.packets:
            if TCP in pkt and Raw in pkt:
                key = f'{pkt[IP].src}:{pkt[TCP].sport}-{pkt[IP].dst}:{pkt[TCP].dport}'
                tcp_streams[key] += pkt[Raw].load
        
        for key, data in tcp_streams.items():
            for pattern in patterns:
                matches = re.findall(pattern, data)
                flags.extend(m.decode() for m in matches)
        
        # 策略3: 搜索DNS隧道数据
        for pkt in self.packets:
            if DNS in pkt and pkt[DNS].qr == 0:
                qname = pkt[DNS].qd.qname.decode()
                for pattern in [r'flag\{[^}]+\}', r'[0-9a-f]{32}']:
                    text_matches = re.findall(pattern, qname)
                    flags.extend(text_matches)
        
        return list(set(flags))  # 去重
    
    def extract_reassembled_tcp_streams(self) -> Dict[int, bytes]:
        """提取重组后的TCP流"""
        sessions = self.packets.sessions()
        streams = {}
        
        for session_id, packets in sessions.items():
            data = b''
            for pkt in packets:
                if Raw in pkt:
                    data += pkt[Raw].load
            streams[session_id] = data
        
        return streams
    
    def analyze_dns_exfiltration(self) -> List[str]:
        """分析DNS隧道/外传数据"""
        suspicious = []
        
        for pkt in self.packets:
            if DNS in pkt and pkt[DNS].qr == 0:
                qname = pkt[DNS].qd.qname.decode()
                
                # 检查异常长的子域名（DNS隧道特征）
                if len(qname) > 50:
                    suspicious.append(qname)
                
                # 检查是否有Hex编码的子域名
                subdomain = qname.split('.')[0]
                if len(subdomain) > 16 and re.match(r'^[0-9a-fA-F]+$', subdomain):
                    suspicious.append(f"Hex subdomain: {qname}")
                
                # 检查是否有Base64编码的子域名
                if len(subdomain) > 16 and re.match(r'^[A-Za-z0-9+/=]+$', subdomain):
                    suspicious.append(f"Base64 subdomain: {qname}")
        
        return suspicious
    
    def analyze_icmp_tunnel(self) -> Optional[bytes]:
        """分析ICMP隧道数据"""
        icmp_data = b''
        
        for pkt in self.packets:
            if ICMP in pkt and Raw in pkt:
                icmp_data += pkt[Raw].load
        
        if len(icmp_data) > 100:
            return icmp_data
        return None
    
    def extract_ftp_data(self) -> Dict[str, bytes]:
        """提取FTP传输的文件"""
        ftp_files = {}
        
        current_file = None
        current_data = b''
        
        for pkt in self.packets:
            if TCP in pkt and Raw in pkt:
                data = pkt[Raw].load
                if data.startswith(b'RETR '):
                    current_file = data[5:].strip().decode()
                    current_data = b''
                elif data.startswith(b'STOR '):
                    current_file = data[5:].strip().decode()
                    current_data = b''
                elif current_file and pkt[TCP].sport == 20:  # FTP数据端口
                    current_data += data
                elif current_file and data.startswith(b'226 '):
                    # 传输完成
                    if current_data:
                        ftp_files[current_file] = current_data
                    current_file = None
                    current_data = b''
        
        return ftp_files

if __name__ == '__main__':
    import sys
    
    if len(sys.argv) < 2:
        print('用法: python3 pcap_analyzer.py <file.pcap>')
        sys.exit(1)
    
    analyzer = PcapAnalyzer(sys.argv[1])
    
    # 基本信息
    summary = analyzer.get_summary()
    print(f'\n[*] 协议分布:')
    for proto, count in summary['protocols'].most_common(10):
        print(f'    {proto}: {count}')
    
    print(f'\n[*] 发现 {len(summary["endpoints"])} 个通信端点')
    print(f'[*] TCP端口: {sorted(summary["tcp_ports"])[:20]}')
    print(f'[*] UDP端口: {sorted(summary["udp_ports"])[:20]}')
    
    # 搜索flag
    print(f'\n[*] 搜索Flag...')
    flags = analyzer.find_flags()
    if flags:
        for flag in flags:
            print(f'[+] Flag Found: {flag}')
    else:
        print('[-] 未直接发现Flag')
    
    # 检查DNS隧道
    dns_suspicious = analyzer.analyze_dns_exfiltration()
    if dns_suspicious:
        print(f'\n[*] 可疑DNS查询:')
        for s in dns_suspicious[:10]:
            print(f'    {s}')
    
    # 检查ICMP隧道
    icmp_data = analyzer.analyze_icmp_tunnel()
    if icmp_data:
        print(f'\n[*] 发现ICMP隧道数据: {len(icmp_data)} bytes')
        print(f'    前100字节: {icmp_data[:100]}')
```

### 3.4 常见协议结构速查

```python
#!/usr/bin/env python3
"""
protocol_parser.py - 常见协议的手动解析
用于在没有Wireshark的环境下解析二进制协议数据
"""

import struct

class EthernetFrame:
    """以太网帧解析"""
    # 结构: 目标MAC(6) + 源MAC(6) + 类型(2) + 数据 + FCS(4)
    
    ETHERTYPE = {0x0800: 'IPv4', 0x0806: 'ARP', 0x86DD: 'IPv6'}
    
    @staticmethod
    def parse(data: bytes) -> dict:
        if len(data) < 14:
            return {'error': '帧太短'}
        dst_mac = ':'.join(f'{b:02x}' for b in data[:6])
        src_mac = ':'.join(f'{b:02x}' for b in data[6:12])
        eth_type = struct.unpack('!H', data[12:14])[0]
        
        return {
            'dst_mac': dst_mac,
            'src_mac': src_mac,
            'ethertype': f'0x{eth_type:04x} ({EthernetFrame.ETHERTYPE.get(eth_type, "Unknown")})',
            'payload': data[14:],
        }

class IPv4Packet:
    """IPv4数据包解析"""
    
    PROTOCOLS = {1: 'ICMP', 6: 'TCP', 17: 'UDP'}
    
    @staticmethod
    def parse(data: bytes) -> dict:
        if len(data) < 20:
            return {'error': 'IPv4头部太短'}
        
        version_ihl = data[0]
        version = version_ihl >> 4
        ihl = version_ihl & 0x0F
        header_len = ihl * 4
        
        total_length = struct.unpack('!H', data[2:4])[0]
        protocol = data[9]
        src_ip = '.'.join(str(b) for b in data[12:16])
        dst_ip = '.'.join(str(b) for b in data[16:20])
        
        return {
            'version': version,
            'header_length': header_len,
            'total_length': total_length,
            'protocol': IPv4Packet.PROTOCOLS.get(protocol, str(protocol)),
            'src_ip': src_ip,
            'dst_ip': dst_ip,
            'ttl': data[8],
            'payload': data[header_len:total_length],
        }

class DNSPacket:
    """DNS数据包解析"""
    
    @staticmethod
    def parse(data: bytes) -> dict:
        """简单的DNS解析器（不处理压缩指针）"""
        if len(data) < 12:
            return {'error': 'DNS头部太短'}
        
        transaction_id = struct.unpack('!H', data[:2])[0]
        flags = struct.unpack('!H', data[2:4])[0]
        qdcount = struct.unpack('!H', data[4:6])[0]
        
        is_response = (flags >> 15) & 1
        opcode = (flags >> 11) & 0xF
        
        # 简单解析查询名（不处理压缩）
        offset = 12
        qname_parts = []
        while offset < len(data):
            length = data[offset]
            if length == 0:
                offset += 1
                break
            qname_parts.append(data[offset+1:offset+1+length].decode('ascii', errors='replace'))
            offset += length + 1
        
        qname = '.'.join(qname_parts)
        
        if offset + 4 <= len(data):
            qtype = struct.unpack('!H', data[offset:offset+2])[0]
            qclass = struct.unpack('!H', data[offset+2:offset+4])[0]
        else:
            qtype = qclass = 0
        
        return {
            'transaction_id': transaction_id,
            'is_response': bool(is_response),
            'opcode': opcode,
            'qname': qname,
            'qtype': qtype,
            'qclass': qclass,
        }

# 使用示例
if __name__ == '__main__':
    # 手工构造一个DNS查询包
    # 以太网头 + IP头 + UDP头 + DNS查询
    eth = b'\x00' * 6 + b'\x11' * 6 + b'\x08\x00'
    # (简化的IP头)
    
    # 解析DNS数据（仅DNS部分）
    dns_query = (b'\x12\x34\x01\x00\x00\x01\x00\x00\x00\x00\x00\x00' +
                 b'\x06google\x03com\x00\x00\x01\x00\x01')
    
    result = DNSPacket.parse(dns_query)
    for k, v in result.items():
        print(f'  {k}: {v}')
```

## 4. 常见误区与注意事项

### 4.1 抓包分析误区

| 误区 | 正确做法 |
|------|----------|
| 只看自己关心的协议 | 扫描所有协议，很多CTF都是非常规协议 |
| 忽略ICMP/DNS流量 | 这是数据隧道和外传的常见载体 |
| 只看明文忽略二进制 | 二进制数据可能嵌入了flag |
| 使用工具导出的文件不验证 | tshark导出的对象可能不完整 |
| 过滤条件太严格 | 先从宽松条件开始，逐步精确 |
| 不检查时间线 | 按时间线分析可以还原攻击过程 |

## 5. 实战示例

### 示例1：从PCAP中提取通过HTTP传输的文件

```python
#!/usr/bin/env python3
"""从PCAP中提取HTTP传输的文件"""

from scapy.all import *
import os

def extract_http_files(pcap_file: str, output_dir: str = './extracted'):
    os.makedirs(output_dir, exist_ok=True)
    
    packets = rdpcap(pcap_file)
    
    # 按TCP流重组
    sessions = packets.sessions()
    
    file_count = 0
    
    for session_id, pkts in sessions.items():
        data = b''
        for pkt in pkts:
            if Raw in pkt:
                data += pkt[Raw].load
        
        # 查找HTTP响应
        if b'HTTP/1.' in data and b'Content-Type:' in data:
            # 提取响应头
            header_end = data.find(b'\r\n\r\n')
            if header_end == -1:
                continue
            
            headers = data[:header_end]
            body = data[header_end + 4:]
            
            # 检查Content-Type
            ct_match = re.search(rb'Content-Type:\s*([^\r\n]+)', headers)
            content_type = ct_match.group(1).decode() if ct_match else 'unknown'
            
            # 提取文件名
            cd_match = re.search(rb'filename="([^"]+)"', headers)
            if cd_match:
                filename = cd_match.group(1).decode()
            elif b'Content-Disposition: attachment' in headers:
                ext = content_type.split('/')[-1]
                filename = f'file_{file_count}.{ext}'
            else:
                # 查找flag在响应中
                if b'flag{' in body or b'ctf{' in body:
                    filename = f'flag_response_{file_count}.txt'
                else:
                    continue
            
            filepath = os.path.join(output_dir, filename)
            with open(filepath, 'wb') as f:
                f.write(body)
            
            print(f'[+] 提取文件: {filepath} ({len(body)} bytes, {content_type})')
            file_count += 1
    
    print(f'\n[*] 共提取 {file_count} 个文件')

if __name__ == '__main__':
    import sys
    if len(sys.argv) > 1:
        extract_http_files(sys.argv[1])
    else:
```

### 示例2：分析USB键盘流量提取按键记录

```python
#!/usr/bin/env python3
"""
Wireshark导出的USB键盘数据分析
用于CTF中的USB键盘流量取证题目
"""

# USB HID键盘键码映射（部分）
USB_KEYMAP = {
    0x04: ('a', 'A'), 0x05: ('b', 'B'), 0x06: ('c', 'C'),
    0x07: ('d', 'D'), 0x08: ('e', 'E'), 0x09: ('f', 'F'),
    0x0A: ('g', 'G'), 0x0B: ('h', 'H'), 0x0C: ('i', 'I'),
    0x0D: ('j', 'J'), 0x0E: ('k', 'K'), 0x0F: ('l', 'L'),
    0x10: ('m', 'M'), 0x11: ('n', 'N'), 0x12: ('o', 'O'),
    0x13: ('p', 'P'), 0x14: ('q', 'Q'), 0x15: ('r', 'R'),
    0x16: ('s', 'S'), 0x17: ('t', 'T'), 0x18: ('u', 'U'),
    0x19: ('v', 'V'), 0x1A: ('w', 'W'), 0x1B: ('x', 'X'),
    0x1C: ('y', 'Y'), 0x1D: ('z', 'Z'),
    0x1E: ('1', '!'), 0x1F: ('2', '@'), 0x20: ('3', '#'),
    0x21: ('4', '$'), 0x22: ('5', '%'), 0x23: ('6', '^'),
    0x24: ('7', '&'), 0x25: ('8', '*'), 0x26: ('9', '('),
    0x27: ('0', ')'),
    0x28: ('\n', '\n'), 0x29: ('[ESC]', '[ESC]'),
    0x2A: ('[BACKSPACE]', '[BACKSPACE]'),
    0x2B: ('\t', '\t'), 0x2C: (' ', ' '),
    0x2D: ('-', '_'), 0x2E: ('=', '+'),
    0x2F: ('[', '{'), 0x30: (']', '}'),
    0x31: ('\\', '|'), 0x33: (';', ':'),
    0x34: ("'", '"'), 0x35: ('`', '~'),
    0x36: (',', '<'), 0x37: ('.', '>'),
    0x38: ('/', '?'),
}

# 修饰键
# 0x01: LeftCtrl, 0x02: LeftShift, 0x04: LeftAlt
# 0x10: RightCtrl, 0x20: RightShift, 0x40: RightAlt

def parse_usb_keyboard_data(hex_data: list) -> str:
    """
    解析USB键盘数据
    
    hex_data: 从tshark导出的HID数据，每个元素是十六进制字符串
    tshark导出命令:
    tshark -r capture.pcap -Y 'usb.capdata' -T fields -e usb.capdata
    """
    
    result = []
    shift_pressed = False
    
    for line in hex_data:
        if not line or len(line) < 16:
            continue
        
        # USB HID键盘报告的字节布局:
        # Byte 0: 修饰键
        # Byte 1: 保留
        # Byte 2-7: 按键 (最多6个同按)
        
        parts = line.replace(':', '').strip()
        if len(parts) < 16:
            continue
        
        modifier = int(parts[:2], 16)
        keycode = int(parts[4:6], 16)
        
        # 跳过没有按键的数据
        if keycode == 0:
            continue
        
        shift = bool(modifier & 0x02) or bool(modifier & 0x20)
        
        if keycode in USB_KEYMAP:
            char = USB_KEYMAP[keycode][1 if shift else 0]
            if char == '[BACKSPACE]':
                if result:
                    result.pop()
            elif char == '[ESC]':
                pass  # 忽略ESC
            else:
                result.append(char)
        else:
            result.append(f'[0x{keycode:02X}]')
    
    return ''.join(result)

# 使用示例
if __name__ == '__main__':
    import sys
    
    if len(sys.argv) > 1:
        with open(sys.argv[1], 'r') as f:
            data = f.readlines()
        text = parse_usb_keyboard_data(data)
        print('按键记录:')
        print(text)
    else:
        print('用法: python3 usb_keyboard.py <usb_capdata.txt>')
        print('')
        print('先使用tshark导出数据:')
        print('tshark -r capture.pcap -Y "usb.capdata" -T fields -e usb.capdata > usb_data.txt')
```
