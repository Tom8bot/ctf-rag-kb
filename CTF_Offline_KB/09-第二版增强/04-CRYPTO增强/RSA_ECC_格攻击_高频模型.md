# RSA / ECC / 格攻击 高频模型

> 目标：把常见 Crypto 题从“见题不会分型”变成“先判断是哪类数学结构，再选攻击方向”。

---

## 1. RSA 先分型

遇到 RSA，不要立刻写脚本。先看：

1. `n` 是否可分解
2. `e` 是否异常小/大
3. 是否多组 `(n, e, c)`
4. 是否有部分明文、部分私钥、dp/dq、phi 泄露
5. 是否是 related message / common modulus / broadcast
6. 是否带高位/低位已知、padding 结构、格攻击提示

## 1.1 高频模型

### A. 共模攻击
- 同一个 `n`，不同 `e`，相同消息
- 关键：扩展欧几里得

### B. 低加密指数广播
- 相同消息发给多个接收者，`e` 小
- 关键：中国剩余定理 + 开方

### C. 明文过小
- `m^e < n`
- 直接开 e 次方

### D. `dp/dq` 泄露
- CRT 参数泄露可还原私钥

### E. 部分已知明文 / 部分已知私钥
- 往 Coppersmith / 格攻击想
- 尤其是高位已知、低位未知、prefix/suffix 已知

### F. 伪随机质数 / 相关质数
- p、q 生成过程有模式
- 共享高位、低位、间距小、来源弱 RNG

---

## 2. Coppersmith / LLL 什么时候想

如果题目符合以下任一特征，就该往格方向想：

- 有多项式关系
- 有“部分未知但范围小”的秘密
- 高位已知 / 低位已知
- RSA 私钥参数不完整
- nonce / key / seed 只有少量未知位

### 小模型记忆法
**“已知大部分，只差一小块”**，优先往 Coppersmith / LLL 想。

---

## 3. ECC 题怎么分

## 3.1 高频方向
- 曲线参数异常
- 基点阶异常 / 小子群
- twist 攻击
- ECDSA nonce 重用 / 偏置 / 泄露部分位
- Smart attack / MOV attack / anomalous curve

## 3.2 ECDSA 高频模型
### A. nonce 重用
- 两个签名用同一 k
- 最经典，直接恢复私钥

### B. nonce 偏置 / 部分泄露
- 若 k 的若干位可知，转格攻击

### C. 签名实现错误
- hash 截断、模运算错误、参数验证缺失

---

## 4. 格攻击最实用的判断标准

不用先想定理，先看是否满足：

1. 有多个方程
2. 未知量范围较小
3. 未知量之间有线性/近线性关系
4. 直接暴力不行但不是完全随机

满足这些，优先考虑构造 lattice。

---

## 5. 比赛中的优先级

### RSA
1. 先因式分解和 gcd 检查
2. 再看共模/广播/低指数
3. 再看部分泄露与格攻击
4. 最后看更偏门的构造

### ECC / ECDSA
1. 先看 nonce 问题
2. 再看曲线/子群/参数异常
3. 再看格攻击和离散对数特殊情形

---

## 6. 常见误区
- 看见 RSA 就只会分解 n
- 看见 ECDSA 不先检查 nonce 重用
- 遇到“已知高位/低位”却没想到格攻击
- 不先做题面建模，只堆工具
