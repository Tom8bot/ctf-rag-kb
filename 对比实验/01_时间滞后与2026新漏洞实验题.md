# 时间滞后与2026新漏洞实验题

## 实验目的

本组问题专门用于验证小参数模型的训练时间滞后问题。题目选取2026年公开披露或更新的漏洞、安全公告和补丁信息，未挂载知识库时，小模型很可能无法回答、错误识别、编造CVE细节或把旧漏洞信息混入答案；挂载包含新漏洞文档的知识库后，应能明显改善。

## 实验问题

1. 截至2026年5月，请说明Ivanti Endpoint Manager Mobile在2026年1月披露的两个关键漏洞CVE-2026-1281和CVE-2026-1340分别是什么类型的问题，并说明为什么它们适合用来测试小模型的时间滞后性。

2. 如果CTF靶场给出“Ivanti EPMM 12.6.1.0，疑似存在2026年初披露的代码注入漏洞”这一提示，请你判断应该查询哪些字段才能把漏洞整理成知识库文档。

3. 请说明CVE-2026-20131与Cisco Secure Firewall Management Center之间的关系，并判断该漏洞为什么容易被小模型误答为普通Web漏洞或旧版Cisco ASA漏洞。

4. 针对Cisco在2026年发布的FMC远程代码执行漏洞公告，请列出在知识库文档中必须记录的关键信息项，不要把它和2025年或更早的Cisco漏洞混淆。

5. Android 2026年3月安全公告中提到CVE-2026-21385可能存在有限定向利用。请围绕这个信息设计一段用于漏洞知识库的提问，要求模型区分“公告提及”“已公开PoC”“已大规模利用”三种不同状态。

6. Android 2026年5月安全公告中出现CVE-2026-0073。请判断这类移动端系统组件漏洞在CTF知识库中应该归入“漏洞信息”“移动安全”还是“取证分析”，并说明理由。

7. 现在给你一个漏洞标题：“Cisco Identity Services Engine Remote Code Execution and Path Traversal Vulnerabilities，2026年4月公告”。请提取漏洞产品、漏洞类型、攻击前提、影响版本和修复版本；如果无法确认某字段，必须明确标注“资料不足”。

8. 如果问题中只给出“Copy Fail，CVE-2026-31431，Linux kernel，本地提权”，请判断它是不是远程RCE，并说明回答中哪些说法可能属于幻觉。

9. 请比较CVE-2026-1281、CVE-2026-1340和CVE-2026-20131在产品、利用前提、漏洞类型和知识库模板字段上的差异。

10. 请解释为什么“CVE编号存在”不等于“PoC公开可用”，并结合2026年新漏洞说明知识库文档中如何避免把推测内容写成确定结论。

11. 假设线下比赛断网环境中只能使用本地Qwen-2.5-7B，请说明如何回答一个训练后才出现的2026年漏洞问题；要求必须说明自己无法从训练参数中知道的信息，以及RAG知识库能补充什么。

12. 在回答2026年漏洞问题时，请按“信息来源、发布日期、影响版本、利用条件、修复建议”五个字段组织答案；如果某个字段无法确认，请明确说明，不能编造版本号。
