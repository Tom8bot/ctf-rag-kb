# 哈希攻击

## 1. 概述

密码学哈希函数将任意长度输入映射为固定长度输出，需满足三个核心安全性：
1. **抗原像性 (Preimage Resistance)**：给定 h，无法找到 m 使 H(m) = h
2. **抗第二原像性 (Second Preimage Resistance)**：给定 m1，无法找到 m2 != m1 使 H(m1) = H(m2)
3. **抗碰撞性 (Collision Resistance)**：无法找到任意 m1 != m2 使 H(m1) = H(m2)

CTF 中哈希攻击常围绕以下主题：
- **长度扩展攻击 (Length Extension Attack)**：利用 Merkle-Damgard 结构
- **哈希碰撞**：MD5/SHA1 的实际碰撞构造
- **弱哈希类型的绕过**：PHP `==` 松散比较（Magic Hash）
- **生日攻击**：O(√n) 复杂度找碰撞
- **HMAC 的时间攻击与 oracle 泄漏**

## 2. 核心原理（含数学推导）

### 2.1 Merkle-Damgard 结构

MD5、SHA1、SHA256 都基于此结构：
1. 对消息填充 (padding)，使长度 ≡ 0 (mod block_size)
2. 将填充满的消息分块 M_1, M_2, ..., M_n
3. 迭代压缩函数：`H_i = f(H_{i-1}, M_i)`，其中 `H_0 = IV`
4. `HASH(m) = H_n`

长度扩展攻击正是利用这一设计特性。

### 2.2 长度扩展攻击原理

已知 `H = SHA1(key || message)` （即 HMAC 的简化），攻击者可在不知 `key` 的情况下计算 `SHA1(key || message || padding || append_data)`。

原因：
- SHA1 的状态 `(A, B, C, D, E)` 就是哈希值 H
- 攻击者可将 H 作为初始状态，从 `append_data` 继续哈希
- 只需知道原始消息的长度（用于构造正确的 padding）

数学形式：
原始计算：`HASH(key || msg) = compress(H0, msg || pad1)` 的最终状态
攻击者构造：`HASH_EXT = compress(HASH(key || msg), append || pad2)`
结果等价于 `HASH(key || msg || pad1 || append)` 的哈希值！

### 2.3 生日攻击（Birthday Attack）

生日悖论：在 N 种可能中，只需约 √N 次采样，碰撞概率即 > 50%。
对 n-bit 哈希，找到碰撞的工作量为 O(2^{n/2})。

算法（低内存变体 - Pollard's Rho）：
1. 从 m_0 开始，定义 `x_i = H(x_{i-1})`
2. 同时维护两组值，按 1 和 2 倍速前进
3. 当 x_i = x_{2i} 时，即找到碰撞

### 2.4 哈希函数的代数结构

对于 SHA256，每轮操作为：
```
Ch(x,y,z) = (x ∧ y) ⊕ (¬x ∧ z)
Maj(x,y,z) = (x ∧ y) ⊕ (x ∧ z) ⊕ (y ∧ z)
Σ0(x) = ROTR(x, 2) ⊕ ROTR(x, 13) ⊕ ROTR(x, 22)
Σ1(x) = ROTR(x, 6) ⊕ ROTR(x, 11) ⊕ ROTR(x, 25)
σ0(x) = ROTR(x, 7) ⊕ ROTR(x, 18) ⊕ SHR(x, 3)
σ1(x) = ROTR(x, 17) ⊕ ROTR(x, 19) ⊕ SHR(x, 10)
```

            self.state_size = 5

        padding = b'\x80'
        padding += b'\x00' * ((56 - (message_length + 1) % 64) % 64)
        padding += struct.pack('>Q', message_length * 8)
        return padding

        从已知哈希值（状态）计算长度扩展攻击的哈希

        def left_rotate(n, b):
            return ((n << b) | (n >> (32 - b))) & 0xFFFFFFFF

        # 对消息填充（考虑原始长度）
        total_len = original_len + len(msg)
        msg_padded = msg + self.sha1_pad(total_len)

        # 分块处理
        for chunk_start in range(0, len(msg_padded), self.block_size):
            chunk = msg_padded[chunk_start:chunk_start + self.block_size]
            w = list(struct.unpack('>16I', chunk)) + [0] * 64
            for i in range(16, 80):
                w[i] = left_rotate(w[i-3] ^ w[i-8] ^ w[i-14] ^ w[i-16], 1)

            a, b, c, d, e = h
            
            for i in range(80):
                if 0 <= i <= 19:
                    f = (b & c) | ((~b) & d)
                    k = 0x5A827999
                elif 20 <= i <= 39:
                    f = b ^ c ^ d
                    k = 0x6ED9EBA1
                elif 40 <= i <= 59:
                    f = (b & c) | (b & d) | (c & d)
                    k = 0x8F1BBCDC
                elif 60 <= i <= 79:
                    f = b ^ c ^ d
                    k = 0xCA62C1D6

                e = d
                d = c
                c = left_rotate(b, 30)
                b = a
                a = temp

def sha1_length_extension_attack(original_hash: str, original_msg_len: int, append_data: bytes, key_len: int):
    """
    SHA1 长度扩展攻击

    参数:
        original_hash: 原始 H(key || original_msg) 的 SHA1 值
        original_msg_len: original_msg 的长度（不含 key）
        append_data: 要追加的数据
        key_len: 密钥长度（未知，可能需要爆破）

    返回:
        (forged_data, forged_hash)
        forged_data = original_msg || padding || append_data
        forged_hash = SHA1(key || original_msg || padding || append_data)
    """
    ext = HashLengthExtension('sha1')
    state = HashLengthExtension.parse_hash_hex(original_hash, 'sha1')

    # 构造伪造的消息（包含原始填充）
    total_original_len = key_len + original_msg_len
    forged_data = append_data  # 实际上是 original_msg || pad || append_data
    # 注意：原始填充需要包含在 total_original_len 中计算

    forged_hash = ext._hash_sha1_from_state(
        h=state,
        msg=append_data,
        original_len=total_original_len + len(ext.sha1_pad(total_original_len))
    )

    return forged_hash.hex()

def find_php_magic_hash(hash_type='md5'):
    """
    寻找 PHP 的 Magic Hash：以 0e 开头且后面全是数字的哈希值
    PHP: "0e1234" == "0e5678" 因科学计数法比较为 True (0 == 0)
    """
    import hashlib
    import re

    found = []
    i = 0
    while len(found) < 5:
        test_str = str(i).encode()
        h = hashlib.new(hash_type, test_str).hexdigest()
        if re.match(r'^0e\d+$', h):
            found.append((test_str.decode(), h))
            print(f"[+] Found: {test_str.decode()} => {h}")
        i += 1
        if i > 10**8:
            break
    return found

def identify_hash_rounds(h: str) -> int:
    """
    识别哈希嵌套层数
    思路：从可能的初始值开始反复哈希，匹配目标值
    """
    import hashlib

    candidates = [b"admin", b"password", b"flag", b"123456", b"test"]

    for candidate in candidates:
        current = candidate
        for round_num in range(1, 10001):
            current = hashlib.md5(current).hexdigest().encode()
            if current.decode() == h:
                print(f"[+] Found after {round_num} rounds: {candidate.decode()}")
                return round_num, candidate.decode()

    return None, None

def crack_hash_chain(h: str, chain_len: int, charset: str, max_len: int) -> str:
    """
    逆向破解哈希链：H(H(...H(x)...)) = h
    暴力搜索输入
    """
    import hashlib
    import itertools

    for length in range(1, max_len + 1):
        for combo in itertools.product(charset, repeat=length):
            candidate = ''.join(combo).encode()
            current = candidate
            for _ in range(chain_len):
                current = hashlib.md5(current).hexdigest().encode()
            if current.decode() == h:
                return candidate.decode()
    return None

```python
import hmac
import hashlib

def hmac_oracle_timing_attack(verify_oracle, msg: bytes, known_prefix: bytes = b"", rounds: int = 30):
    """
    HMAC 时序攻击：逐字节猜测 HMAC
    要求 oracle 函数 verify_oracle(hmac_value) 返回 (bool, elapsed_time)
    """
    BS = 20  # SHA1 HMAC 输出 20 字节
    recovered = bytearray(known_prefix)

    for byte_pos in range(len(known_prefix), BS):
        best_time = 0
        best_byte = 0

        for guess in range(256):
            test_hmac = bytes(recovered) + bytes([guess]) + b'\x00' * (BS - byte_pos - 1)
            total_time = 0

            for _ in range(rounds):
                is_valid, elapsed = verify_oracle(test_hmac)
                total_time += elapsed

            avg_time = total_time / rounds
            if avg_time > best_time:
                best_time = avg_time
                best_byte = guess

        recovered.append(best_byte)
        print(f"[+] Byte {byte_pos}: 0x{best_byte:02x} -> {bytes(recovered).hex()}")

    return bytes(recovered)

## 4. 常见误区与注意事项

1. **HMAC 的关键**：`HMAC(key, msg) = H((key ⊕ opad) || H((key ⊕ ipad) || msg))`。双重哈希使长度扩展攻击对 HMAC 无效。但是 `H(key || msg)` 这种简单拼接极易受长度扩展攻击。
2. **MD5 和 SHA1 已不安全**：MD5 可在几秒内构造碰撞（chosen-prefix 碰撞）。SHA1 的 SHAttered 攻击（2017）构造了实际碰撞。
3. **SHA256 目前安全** (截至 2024)：但理论攻击持续进展，且 SHA256 仍受长度扩展攻击。使用 HMAC-SHA256 或 SHA-3 可规避。
4. **哈希值无法解密**：哈希是单向的，不可能从哈希值回推原文。CTF 中说"解密 MD5"实际上是指彩虹表/字典/暴力破解。
5. **加盐 ≠ 解决一切**：在哈希前加盐可防御彩虹表，但不能防御暴力破解。现代密码存储使用 argon2/bcrypt/scrypt（内存硬度）。
6. **哈希碰撞的实际利用**：生日攻击只能是"已知前缀碰撞"（攻击者不可控），chosen-prefix 碰撞（攻击者可控制两个前缀内容）才能在证书伪造等场景利用。
7. **Python hashlib 的限制**：`hashlib.md5(b"hello")` 不支持自定义初始状态（需手写实现长度扩展攻击）。

## 5. 实战示例

**场景**：Web 应用使用 `sha1("secret" + user_data)` 签名，签名正确才执行操作。攻击者截获 `user_data = "from=alice&to=bob&amount=100"` 及其签名，想要修改为 `to=mallory&amount=10000`。

        h=state,
        msg=append_data,
        original_len=original_total_len + len(padding)
    )

    return forged_data, forged_hash.hex()

# 演示
secret_len = 6  # "secret" 长度
original_data = b"from=alice&to=bob&amount=100"
append_data = b"&to=mallory&amount=10000"

# 合法签名（攻击者截获的）
real_sig = hashlib.sha1(b"secret" + original_data).hexdigest()

# 伪造
forged_data, forged_sig = attack_sha1_mac(real_sig, original_data, append_data, secret_len)

# 验证
expected = hashlib.sha1(b"secret" + forged_data).hexdigest()
print(f"[+] Attack {'successful' if forged_sig == expected else 'failed'}!")
print(f"[+] Forged signature matches: {forged_sig == expected}")
```

## 6. 相关知识点

- **SHA-3 (Keccak)**：基于海绵结构（Sponge Construction），不受长度扩展攻击
- **BLAKE2/BLAKE3**：快速哈希函数，基于 ChaCha 流密码
- **ripemd160**：比特币中使用的哈希函数
- **密码哈希 (PBKDF2, bcrypt, scrypt, argon2)**：用于密码存储的慢哈希函数
- **彩虹表 (Rainbow Table)**：预计算的哈希 -> 明文映射
- **Merkle Tree**：区块链中用于交易验证的哈希树
- **HMAC**：基于哈希的消息认证码（解决长度扩展问题）
- **Poly1305**：一次性的消息认证码（与 ChaCha20 配合）
- **哈希-DRBG**：基于哈希的确定性随机数生成器
- **FastColl/MD5 Collision**：Marc Stevens 的哈希碰撞工具
- **SHAttered**：Google/CWI 的 SHA1 碰撞演示项目
- **哈希函数代数**：Dobbertin、Wang Xiaoyun（王小云）、Biham 等人对 MD4/5 和 SHA0/1 的密码分析
