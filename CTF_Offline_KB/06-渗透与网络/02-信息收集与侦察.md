# 信息收集与侦察

## 1. 概述

信息收集（Reconnaissance）是渗透测试与CTF竞赛的第一阶段，也是决定后续攻击效率的关键步骤。完整准确的信息收集能够显著降低漏洞利用的试错成本。在Attack-Defense模式中，对目标网络拓扑、服务分布、版本信息的全面掌握，直接决定了攻击面的最大化利用。

本节涵盖主动扫描（Nmap/Masscan/Rustscan）、被动信息收集、DNS枚举、子域名发现、目录爆破以及离线环境下扫描工具的配置与使用。

## 2. 核心原理

### 2.1 TCP三次握手与扫描原理

Nmap支持多种扫描技术，其核心基于TCP协议栈的不同响应来判断端口状态：

| 扫描类型 | 参数 | 原理 | 优势 | 劣势 |
|---------|------|------|------|------|
| TCP SYN扫描 | `-sS` | 发送SYN，收到SYN/ACK则开放，RST则关闭 | 快速，不建立完整连接 | 需要root权限 |
| TCP Connect扫描 | `-sT` | 完成完整三次握手 | 无需root权限 | 较慢，日志易被发现 |
| UDP扫描 | `-sU` | 发送UDP包，ICMP不可达回应则关闭 | 发现UDP服务 | 极慢，需要速率控制 |
| ACK扫描 | `-sA` | 发送ACK包，RST响应则未过滤 | 探测防火墙规则 | 不能确认端口开放状态 |
| NULL/FIN/Xmas | `-sN/-sF/-sX` | 发送异常标志位 | 绕过简单防火墙 | Linux/Unix下效果有限 |

### 2.2 端口响应模型

```
状态机：
SYN_SENT → (SYN/ACK) → open
SYN_SENT → (RST) → closed
SYN_SENT → (ICMP unreachable) → filtered
SYN_SENT → (无响应/超时) → filtered
```

### 2.3 服务指纹识别原理

Nmap使用探针-响应匹配（probe-response matching）进行服务版本检测（`-sV`）：
1. 发送 `nmap-service-probes` 文件中定义的探针
2. 将收到的响应与 `nmap-service-probes` 中的正则表达式规则匹配
3. 根据匹配结果确定服务名、版本、操作系统等额外信息

OS检测（`-O`）则通过分析TCP/IP协议栈指纹（如初始序列号、IP ID生成算法、TCP选项等）来识别操作系统。

## 3. 关键工具与命令

### 3.1 Nmap高级用法

**基础扫描语法：**
```bash
# 完整扫描命令结构
nmap [扫描类型] [选项] [时间控制] {目标}

# 基本示例
nmap -sS -sV -O -p- --min-rate 1000 -T4 192.168.1.0/24
```

**扫描类型组合：**
```bash
# 完整综合扫描（CTF最常用模板）
nmap -sS -sV -sC -O -p- -T4 --min-rate 5000 \
     --open -oA full_scan 10.10.10.0/24

# 参数解释：
# -sS    : TCP SYN扫描（半开放）
# -sV    : 服务版本检测
# -sC    : 运行默认脚本扫描（相当于--script=default）
# -O     : 操作系统检测
# -p-    : 扫描全部65535个端口（-p 1-65535同义）
# -T4    : 时间模板（0-5，4为激进扫描）
# --min-rate 5000 : 最低发包速率（保证速度）
# --open : 仅显示开放端口（过滤关闭/过滤状态）
# -oA    : 保存为全部格式（.nmap .gnmap .xml）
```

**分阶段扫描策略（大规模网络优化）：**
```bash
# 阶段1：快速端口发现（仅SYN扫描，不检测版本）
nmap -sS -p- -T5 --min-rate 10000 --open -oA stage1_ports 10.0.0.0/16

# 阶段2：根据阶段1结果，对开放端口做深度扫描
# 提取开放端口列表
grep "open" stage1_ports.gnmap | awk -F'[ /]' '{for(i=1;i<=NF;i++)if($i~/open/)print $(i+1)}' | sort -u | paste -sd,

# 假设提取到端口 22,80,443,3306,8080
nmap -sV -sC -O -p 22,80,443,3306,8080 -oA stage2_services 192.168.1.0/24
```

**UDP扫描优化：**
```bash
# UDP扫描极慢，仅扫描常见UDP端口（出结果快）
nmap -sU --top-ports 100 --min-rate 2000 -T4 -oA udp_top100 10.10.10.5

# 常见UDP端口速查：
# 53 DNS, 67/68 DHCP, 69 TFTP, 123 NTP, 135 MSRPC
# 137-139 NetBIOS, 161/162 SNMP, 500 IKE, 514 Syslog
# 1900 UPnP, 5353 mDNS, 2049 NFS
```

**NSE (Nmap Script Engine) 脚本使用：**
```bash
# 漏洞扫描类脚本（CTF高频使用）
nmap --script=vuln -p 80,443 10.10.10.5

# 特定CVE检测
nmap --script=http-vuln-cve2017-5638 -p 8080 10.10.10.1-254

# SMB相关脚本
nmap --script=smb-os-discovery,smb-vuln-* -p 445 10.10.10.0/24

# 默认安全脚本（信息收集最全）
nmap --script=default,safe --script-timeout=30s 10.10.10.5

# 对所有服务运行对应类别的脚本
nmap --script="http-* and not (http-slowloris or http-brute)" -p 80,443,8080 \
     10.10.10.5
```

**防火墙/IDS规避技术：**
```bash
# 分片扫描（规避包检测）
nmap -f -sS -p 80 10.10.10.5

# MAC地址欺骗
nmap --spoof-mac Apple -sS -p- 10.10.10.5

# 诱饵扫描（混合虚假源IP）
nmap -D RND:10 -sS -p 80,443 10.10.10.5

# 源端口指定（利用允许的端口如53/80）
nmap --source-port 53 -sS -p- 10.10.10.5

# 随机化扫描顺序
nmap --randomize-hosts -sS -p- 10.10.10.0/24

# 速率限制规避
nmap --scan-delay 1s --max-retries 2 10.10.10.5
```

**输出格式与分析：**
```bash
# 生成多种输出格式
nmap -sS -sV -p- 10.10.10.5 -oA result  # 生成 result.nmap, result.gnmap, result.xml

# 转换为HTML报告（需要xsltproc）
xsltproc result.xml -o result.html

# grep提取开放端口
grep -oP '\d+/open' result.nmap | cut -d'/' -f1 | paste -sd,

# awk提取IP和开放端口列表
awk '/Nmap scan/{ip=$NF} /open/{print ip":"$1}' result.nmap

# 提取所有HTTP服务
grep -E "80/open|443/open|8080/open|8000/open|8443/open" result.gnmap
```

### 3.2 Masscan — 大规模快速端口扫描

Masscan使用自定义TCP/IP协议栈，能在5分钟内扫描整个互联网。在CTF中，对于大范围网络（/16甚至更大），Masscan是不可替代的。

```bash
# 安装
sudo apt install masscan
# 或从源码编译
git clone https://github.com/robertdavidgraham/masscan.git
cd masscan && make -j

# 基础用法：扫描单IP全部端口
masscan -p1-65535 --rate=10000 10.10.10.5

# 扫描整个C段
masscan -p1-65535 --rate=50000 10.10.10.0/24 -oJ masscan_output.json

# 仅扫描特定端口（Web常用）
masscan -p80,443,8000,8080,8443,9090,3000,5000,7000,8888 \
        --rate=20000 10.0.0.0/16 -oG masscan_web.gnmap

# 指定源IP和网卡
masscan -p1-65535 --rate=30000 --adapter=eth0 --source-ip=10.10.10.100 \
        10.10.10.0/24

# 输出为nmap兼容格式（支持后续nmap深度扫描）
masscan -p1-65535 --rate=10000 -oX masscan.xml 10.10.10.0/24 &
# 后续用nmap继续
nmap -sV -sC --script=vuln -iL masscan_live_hosts.txt

# CTF中Masscan→Nmap工作流
#!/bin/bash
SUBNET="10.10.0.0/16"
echo "[*] Masscan fast discovery..."
masscan -p1-65535 --rate=50000 -oJ masscan.json $SUBNET 2>/dev/null

# 提取开放端口并按IP分组
python3 << 'PYEOF'
import json
from collections import defaultdict

with open('masscan.json') as f:
    hosts = defaultdict(list)
    for line in f:
        if line.strip():
            d = json.loads(line)
            hosts[d['ip']].append(str(d['ports'][0]['port']))

for ip, ports in hosts.items():
    print(f"{ip}:{','.join(sorted(set(ports), key=int))}")
PYEOF

# 结果示例：10.10.10.5:22,80,443,3306,8080,27017
# 然后对每个IP运行nmap详细扫描
```

**Masscan速率控制经验值：**
| 网络规模 | 建议速率 | 预计完成时间 |
|---------|---------|-------------|
| 单IP | 10000 | <10秒 |
| /24 (256 IPs) | 30000 | ~3分钟 |
| /22 (1024 IPs) | 50000 | ~8分钟 |
| /20 (4096 IPs) | 100000 | ~15分钟 |
| /16 (65536 IPs) | 500000 | ~30分钟 |
| CTF大网 | 按需调整 | 注意不触发主办方限制 |

### 3.3 Rustscan — 新一代超快扫描器

Rustscan是Rust实现的端口扫描器，3秒内完成全端口扫描，并且可以与nmap无缝集成。

```bash
# 安装
# Docker方式
docker run -it --rm --name rustscan rustscan/rustscan:latest

# 或下载二进制
wget https://github.com/RustScan/RustScan/releases/latest/download/rustscan_amd64.deb
sudo dpkg -i rustscan_amd64.deb

# 基础扫描（默认3000线程，100%快速）
rustscan -a 10.10.10.5

# 全部端口+批量扫描
rustscan -a 10.10.10.0/24 --range 1-65535 -b 4000

# 与nmap联用（核心特性）——发现端口后自动调用nmap
rustscan -a 10.10.10.5 -- -sV -sC -O

# 自定义线程和超时
rustscan -a 10.10.10.5 -b 5000 -t 2000 --scan-order "Random"

# 仅输出IP和端口（方便后续处理）
rustscan -a 10.10.10.0/24 --greppable

# 脚本自动化：
#!/bin/bash
for ip in $(cat target_ips.txt); do
    echo "[+] Scanning $ip..."
    rustscan -a $ip --range 1-65535 -b 3000 -- -sV -sC -O -oA "scan_${ip//./_}"
done
```

**性能对比：**
| 扫描器 | 语言 | 全端口/单IP | 全端口/C段 | 特点 |
|--------|------|-----------|----------|------|
| Nmap | C/Lua | ~30秒(T5) | ~10分钟 | NSE脚本引擎，功能最全 |
| Masscan | C | ~3秒 | ~2分钟 | 专为互联网级设计 |
| Rustscan | Rust | ~3秒 | ~8分钟 | 自动Nmap联动，结果更丰富 |

### 3.4 被动信息收集（离线版）

在CTF断网场景，被动信息收集的"被动"体现在不直接向目标发送探测包，而是利用已有数据：

```bash
# 1. 利用DHCP服务器信息
cat /var/lib/dhcp/dhclient.leases  # DHCP租约信息
ip neigh  # ARP缓存表——已通信主机

# 2. ARP表分析（已交互的主机）
arp -a  # Linux
arp -a  # Windows cmd
Get-NetNeighbor  # Windows PowerShell

# 3. DNS缓存查询
# Linux (需要nscd或systemd-resolved)
systemd-resolve --statistics
# Windows
ipconfig /displaydns

# 4. 查看本机路由表（了解网络拓扑）
ip route show  # Linux
route print  # Windows

# 5. 监听网络流量（不发送任何包）
tcpdump -i eth0 -nn 'not port 22' -w passive.pcap
# 或
tshark -i eth0 -w capture.pcap

# 6. 分析已获取的流量
# 提取所有源IP/目标IP
tshark -r capture.pcap -T fields -e ip.src -e ip.dst | sort | uniq -c | sort -rn
# 提取所有DNS查询
tshark -r capture.pcap -Y "dns" -T fields -e dns.qry.name | sort | uniq
# 提取HTTP Host头
tshark -r capture.pcap -Y "http.host" -T fields -e http.host | sort | uniq
```

### 3.5 DNS枚举（离线/本地工具）

```bash
# DNS记录类型速查
# A记录    : IPv4地址
# AAAA记录 : IPv6地址
# CNAME    : 别名（Canonical Name）
# MX       : 邮件服务器
# NS       : 名称服务器
# PTR      : 反向解析（IP→域名）
# TXT      : 文本记录（可能含敏感信息）
# SOA      : 授权起始（域的主NS）
# SRV      : 服务位置

# dig使用（DNS查询首选工具）
dig A target.com                    # A记录查询
dig ANY target.com @8.8.8.8        # 全部记录（可能被限制）
dig MX target.com                   # 邮件服务器
dig NS target.com                   # 名称服务器
dig TXT target.com                  # TXT记录
dig AXFR target.com @ns1.target.com # 区域传送（如果允许）

# 反向DNS查询（IP→域名）
dig -x 10.10.10.5
host 10.10.10.5

# 暴力破解子域名（离线字典）
# 使用dnsenum
dnsenum --enum target.com -f /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt

# 使用gobuster的DNS模式
gobuster dns -d target.com -w /usr/share/seclists/Discovery/DNS/namelist.txt

# 使用fierce（半暴力DNS枚举）
fierce --domain target.com --subdomain-file /usr/share/wordlists/subdomains.txt

# 离线子域名工具准备清单
# 必备字典文件：
# /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt
# /usr/share/seclists/Discovery/DNS/namelist.txt
# /usr/share/seclists/Discovery/DNS/combined_subdomains.txt
# /usr/share/seclists/Discovery/DNS/deepmagic.com-prefixes-top50000.txt
```

## 4. 侦察自动化脚本

### 4.1 CTF侦察一键脚本

```bash
#!/bin/bash
# recon.sh - CTF侦察自动化脚本
# 用法: ./recon.sh targets.txt

TARGET_FILE="${1:-targets.txt}"
OUTPUT_DIR="recon_$(date +%Y%m%d_%H%M%S)"
THREADS=50

mkdir -p "$OUTPUT_DIR"

echo "[*] Starting reconnaissance on targets from $TARGET_FILE"
echo "[*] Output directory: $OUTPUT_DIR"

# Step 1: Rustscan快速端口发现
echo "[1/5] Fast port scanning with Rustscan..."
while read -r target; do
    rustscan -a "$target" --range 1-65535 -b 4000 --greppable \
        > "$OUTPUT_DIR/${target//./_}_ports.txt" 2>&1 &
done < "$TARGET_FILE"
wait

# Step 2: Nmap深度扫描（根据Rustscan结果）
echo "[2/5] Deep service scanning with Nmap..."
while read -r target; do
    # 提取开放端口
    ports=$(grep -oP '-> \K[0-9,]+' "$OUTPUT_DIR/${target//./_}_ports.txt" 2>/dev/null | tr ',' '\n' | sort -u | paste -sd,)
    if [ -n "$ports" ]; then
        nmap -sV -sC -O -p "$ports" -oA "$OUTPUT_DIR/${target//./_}_nmap" "$target" &
    fi
done < "$TARGET_FILE"
wait

# Step 3: HTTP服务发现与截图
echo "[3/5] HTTP service discovery..."
grep -rE "80/open|443/open|8080/open|8000/open|8443/open|9090/open" \
    "$OUTPUT_DIR" | grep -oP '\d+\.\d+\.\d+\.\d+' | sort -u > "$OUTPUT_DIR/http_hosts.txt"

# 对HTTP目标运行Nikto (如果可用)
which nikto &>/dev/null && {
    while read -r http_target; do
        port=$(grep "$http_target" "$OUTPUT_DIR"/*_nmap.nmap | grep -oP '\d+/open/tcp//http' | cut -d'/' -f1 | head -1)
        nikto -h "http://${http_target}:${port:-80}" -o "$OUTPUT_DIR/${http_target//./_}_nikto.txt" &
    done < "$OUTPUT_DIR/http_hosts.txt"
    wait
}

# Step 4: 目录/文件爆破
echo "[4/5] Directory brute-forcing..."
which gobuster &>/dev/null && {
    while read -r http_target; do
        gobuster dir -u "http://$http_target" \
            -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-medium.txt \
            -x php,txt,html,bak,zip,tar.gz,sql,conf,log,old \
            -t $THREADS \
            -o "$OUTPUT_DIR/${http_target//./_}_dirs.txt" &
    done < "$OUTPUT_DIR/http_hosts.txt"
    wait
}

# Step 5: 汇总报告
echo "[5/5] Generating summary..."
{
    echo "=== CTF Recon Summary ==="
    echo "Generated: $(date)"
    echo ""
    echo "--- Open Ports per Host ---"
    grep -rh "open" "$OUTPUT_DIR"/*_nmap.nmap 2>/dev/null | sort -t/ -k1 -u
    echo ""
    echo "--- HTTP Services ---"
    cat "$OUTPUT_DIR/http_hosts.txt" 2>/dev/null
    echo ""
    echo "--- Interesting Findings ---"
    grep -rhiE "(login|admin|phpmyadmin|shell|api|dev|test|staging|backup|old|config|\.git|\.env)" \
        "$OUTPUT_DIR"/*_dirs.txt 2>/dev/null | head -50
} > "$OUTPUT_DIR/summary.txt"

echo "[+] Recon complete! Summary: $OUTPUT_DIR/summary.txt"
```

## 5. 实战示例

### 5.1 场景：CTF A/D - 快速测绘比赛网络

**情况：** 比赛开始，给你分配了IP段 `10.0.0.0/18`（约16000个IP），需要在30分钟内完成对全网的端口扫描和关键服务识别。

```bash
# 0-5分钟：Masscan全端口快速扫
masscan -p1-65535 --rate=200000 --open -oJ masscan_all.json 10.0.0.0/18 2>/dev/null

# 5-10分钟：提取有效目标
python3 << 'PYEOF'
import json, os
from collections import defaultdict

hosts = defaultdict(set)
with open('masscan_all.json') as f:
    for line in f:
        if line.strip():
            d = json.loads(line)
            hosts[d['ip']].add(d['ports'][0]['port'])

# 优先排序：Web服务 > 数据库 > 其他
priority = {80,443,8080,8000,8443,9090,3000,5000}
for ip, ports in sorted(hosts.items(), 
    key=lambda x: len(priority & x[1]), reverse=True):
    print(f"{ip}:{','.join(map(str, sorted(ports)))}")
PYEOF

# 10-20分钟：对Top100目标做深度扫描
head -100 live_targets.txt | while read target; do
    ip=$(echo "$target" | cut -d: -f1)
    ports=$(echo "$target" | cut -d: -f2)
    nmap -sV -sC --script=vuln --script-timeout=20s \
         -p "$ports" -oA "deep/${ip//./_}" "$ip" &
done
wait

# 20-25分钟：提取所有Web服务做快速指纹
grep -rh "open" deep/ | grep -E "http|ssl/http" | cut -d'/' -f1 > web_services.txt

# 捕获HTTP响应头做服务识别
while read -r line; do
    ip=$(echo "$line" | awk '{print $NF}')
    port=$(echo "$line" | awk '{print $3}' | cut -d'/' -f1)
    curl -sI -m 3 "http://$ip:$port/" | head -20 > "http_headers/${ip}_${port}.txt" &
done < <(grep http deep/*.nmap)

# 25-30分钟：基于结果做优先级排序
# 优先攻击：已知漏洞版本、默认配置、暴露的管理界面
grep -ri "Apache/2.4.49\|Struts\|tomcat\|Jenkins\|phpMyAdmin\|WordPress\|Drupal\|nginx 1.2" deep/ > high_value.txt
```

### 5.2 场景：内网环境发现

```bash
# 已获得一台内网主机Shell后，进行内网侦察

# 1. 当前网络配置
ip addr show
ip route show
cat /etc/hosts
cat /etc/resolv.conf

# 2. ARP邻居发现（最有效的内网主机发现方式）
arp -a | grep -v incomplete

# 3. 无arp时的ICMP Ping扫描
for i in $(seq 1 254); do
```

## 6. 常见误区与注意事项

### 6.1 扫描误区

- **误区1：只扫描1-1000常用端口。** 很多CTF服务部署在高端口（31337、4444、5555、22222等），务必全端口扫描。
- **误区2：在UDP扫描上花太多时间。** UDP扫描很慢，优先用`--top-ports 100`或仅扫描已知UDP服务端口。
- **误区3：扫描速率过高被主办方封禁。** CTF A/D模式中有QoS策略，发包过多可能被限流。使用`--scan-delay`降低检测风险。
- **误区4：忽略SSL/TLS服务。** 注意识别非标准端口的HTTPS（8443、9443、4443等），它们同样需要TLS证书分析。

### 6.2 离线准备

- 务必在赛前下载好所有词典文件（SecLists、dirbuster、subdomains等）
- 准备好各扫描器的二进制文件（特别是Masscan，很多发行版默认不安装）
- 制作离线Docker镜像包含全套侦察工具
