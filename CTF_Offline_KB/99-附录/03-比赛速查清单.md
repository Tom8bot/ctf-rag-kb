# 比赛速查清单

## 1. 开赛前本地环境
- [ ] 浏览器 + Burp/代理可用
- [ ] Python 虚拟环境、pwntools、pycryptodome、sage（如有）
- [ ] gdb / gef / peda / pwndbg 可用
- [ ] 常见命令可用：file、strings、binwalk、exiftool、tshark、7z
- [ ] 字典：rockyou、dirs、params、payload 备好
- [ ] 知识库全文可全文检索

---

## 2. 每题通用流程
1. 建目录
2. 保存题目附件
3. 写 `note.md`
4. 做最短验证
5. 成功后写脚本自动化
6. 记录 flag 与复现

### 目录模板
```text
chall/
  note.md
  src/
  out/
  exp/
  attach/
```

---

## 3. Web 速查
- [ ] 是否有源码/备份/js/source map
- [ ] 是否存在 debug / test / swagger / graphql
- [ ] 是否检查 cookie/JWT/session
- [ ] 是否看过上传、导入、导出、下载、预览、Webhook
- [ ] 是否比较过管理员与普通用户接口差异
- [ ] 是否检查过 Host/XFF/Referer 等头部

## 4. Pwn 速查
- [ ] checksec
- [ ] offset
- [ ] PIE/libc/canary 泄露途径
- [ ] one_gadget 约束是否满足
- [ ] 栈对齐 ret 是否需要
- [ ] 远程与本地 libc 是否一致
- [ ] 交互题是否注意换行和菜单同步

## 5. Re 速查
- [ ] 字符串
- [ ] 导入函数
- [ ] main / 关键分支
- [ ] 常量与查表
- [ ] 是否存在壳/自解密
- [ ] 是否可以 patch 跳转

## 6. Crypto 速查
- [ ] 编码？
- [ ] 异或？
- [ ] 分组模式？
- [ ] RSA 参数是否有弱点？
- [ ] 随机数/nonce 是否可预测或复用？

## 7. Misc 速查
- [ ] 文件头尾
- [ ] 元数据
- [ ] 尾部追加
- [ ] 多层压缩
- [ ] 流量中的凭据 / 文件 / 命令
