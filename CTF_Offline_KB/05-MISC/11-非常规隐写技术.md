# 11 - 非常规隐写技术

## 1. 概述

非常规隐写（Unconventional Steganography）指那些不直接修改像素/音频采样值的隐秘信息嵌入方式。这些手法利用人类阅读习惯的盲区（如空格与Tab肉眼难以区分、零宽字符不可见、Base64编码可以有多余的填充位等），将flag隐藏在看似正常的文本、代码或文档中。

断网场景下核心工具：**Python（标准库+手动解析）**、**文本编辑器（VSCode/Notepad++显示不可见字符）**、**Hex编辑器**。

## 2. 核心原理

### 2.1 Base64隐写 (b64stego)

Base64编码有"无效比特位"的概念。回顾Base64编码原理：
```
3字节(24bit) -> 4组6bit -> 4个Base64字符
如果原文长度不是3字节的整数倍，需要填充：
  余1字节: 2组有效6bit + 4个无效(bits) = 编码为3字符+1个=
  余2字节: 3组有效6bit + 2个无效(bits) = 编码为3字符+1个=
```

关键：**填充前的无效比特位可以嵌入信息**，标准解码器会忽略这些位，但隐写分析工具可以提取。

```python
#!/usr/bin/env python3
"""Base64隐写提取"""
import base64

def extract_b64stego_line(line):
    """从单行Base64提取隐写比特"""
    line = line.strip()
    if not line:
        return ''
    
    # 计算等号数量
    eq_count = line.count('=')
    if eq_count == 0:
        return ''
    
    # 去掉等号
    b64_body = line.rstrip('=')
    
    # 解码
    decoded = base64.b64decode(line)
    
    # 计算原始二进制
    if eq_count == 1:
        # 原始为2字节, 最后一组Base64字符后4位是隐写位
        last_char = b64_body[-1]
        idx = base64.b64decode(last_char + 'A==')[0] >> 4  # 或者用translate
        # 简化方法: 直接用映射表
        b64_table = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/'
        idx = b64_table.index(last_char)
        stego_bits = format(idx & 0b1111, '04b')
        return stego_bits
    elif eq_count == 2:
        # 原始为1字节, 最后一组Base64字符后2位是隐写位
        last_char = b64_body[-1]
        b64_table = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/'
        idx = b64_table.index(last_char)
        stego_bits = format(idx & 0b11, '02b')
        return stego_bits
    return ''

def extract_b64stego(filepath):
    """从文件中提取Base64隐写"""
    bits = []
    with open(filepath, 'r') as f:
        for line in f:
            bits.append(extract_b64stego_line(line))
    
    bit_str = ''.join(bits)
    # 每8位拼接为1字节
    result = bytearray()
    for i in range(0, len(bit_str) - 7, 8):
        result.append(int(bit_str[i:i+8], 2))
    return bytes(result)
```

### 2.2 空格与Tab隐写 (Whitespace Steganography)

利用不可见字符（Space、Tab、换行）编码信息：

```
经典编码方案:
每行末尾的空格+Tab组合编码比特:
  Tab + Space = 0
  Space + Tab = 1
  ...

简单方案 (snow/stegsnow):
  行尾的Space(0x20) = bit 0
  行尾的Tab(0x09) = bit 1
  在每行末尾插入若干空格/Tab进行编码
```

**检测方法**:
```bash
# 显示不可见字符
cat -A file.txt          # Tab显示^I, 行尾显示$
cat -e file.txt           # 只显示行尾$
cat -t file.txt           # 只显示Tab和行尾

# hexdump查看行尾
xxd file.txt | grep -E '(20 0a|09 0a|20 20 0a|09 09 0a|20 09 0a|09 20 0a)'

# Python检测
def detect_whitespace_stego(filepath):
    with open(filepath, 'rb') as f:
        content = f.read()
    trailing = []
    for i, line in enumerate(content.split(b'\n')):
        if line.endswith(b' ') or line.endswith(b'\t'):
            trailing.append((i, line[-5:]))
    return trailing
```

**解码脚本**:
```python
def decode_trailing_ws(filepath):
    """解码行尾空格/Tab隐写"""
    bits = []
    with open(filepath, 'rb') as f:
        for line in f:
            # 获取行尾的空格/Tab序列(在\n之前)
            line = line.rstrip(b'\r\n')
            if line.endswith(b' ') or line.endswith(b'\t'):
                # 提取行尾连续的空格/Tab
                trailing = b''
                for ch in reversed(line):
                    if ch in (0x20, 0x09):
                        trailing = bytes([ch]) + trailing
                    else:
                        break
                # 解码: Space=0, Tab=1
                bits.extend(['0' if ch == 0x20 else '1' for ch in trailing])
    
    # 比特转字节
    bit_str = ''.join(bits)
    result = bytearray()
    for i in range(0, len(bit_str) - 7, 8):
        result.append(int(bit_str[i:i+8], 2))
    return bytes(result)
```

### 2.3 零宽字符隐写 (Zero-Width Characters)

Unicode中有多种不可见的零宽度字符：

| 字符 | Unicode | HTML实体 | 用途 |
|------|---------|---------|------|
| ZWSP (零宽空格) | U+200B | &#8203; | 零宽空格 |
| ZWNJ (零宽不连字) | U+200C | &#8204; | 零宽不连字 |
| ZWJ (零宽连字) | U+200D | &#8205; | 零宽连字 |
| LRM (左至右标记) | U+200E | &#8206; | 从左到右标记 |
| RLM (右至左标记) | U+200F | &#8207; | 从右到左标记 |
| LRE/RLE/PDF/LRO/RLO | U+202A-E | - | 双向文本控制 |

**编码方案**:
```
ZWSP + ZWNJ = 0
ZWSP + ZWJ  = 1
插入在文本任何位置，人眼完全不可见
```

**提取脚本**:
```python
def extract_zero_width(text):
    """提取零宽字符中的隐写信息"""
    zero_width_map = {
        '​': '00',  # ZWSP
        '‌': '01',  # ZWNJ  
        '‍': '10',  # ZWJ
        '‎': '00',  # LRM (映射同ZWSP)
        '‏': '11',  # RLM
    }
    
    bits = []
    for ch in text:
        if ch in zero_width_map:
            bits.append(zero_width_map[ch])
    
    bit_str = ''.join(bits)
    result = bytearray()
    for i in range(0, len(bit_str) - 7, 8):
        result.append(int(bit_str[i:i+8], 2))
    return bytes(result).decode('utf-8', errors='replace')

def detect_zero_width(text):
    """检测文本中是否有零宽字符"""
    zero_width_chars = {
        '​': 'ZWSP',
        '‌': 'ZWNJ',
        '‍': 'ZWJ',
        '‎': 'LRM',
        '‏': 'RLM',
        '‪': 'LRE',
        '‫': 'RLE',
        '‬': 'PDF',
        '‭': 'LRO',
        '‮': 'RLO',
    }
    detected = {}
    for ch in text:
        if ch in zero_width_chars:
            name = zero_width_chars[ch]
            detected[name] = detected.get(name, 0) + 1
    return detected
```

### 2.4 Unicode 不可见/同形字符隐写

**Unicode同形字符攻击 (Homoglyph Attack)**:
利用不同Unicode字符在视觉上相同但代码点不同的特点。
```
拉丁 small letter A: U+0061 (a)
西里尔 small letter A: U+0430 (а)  
→ 视觉上完全相同，但代码点不同
→ 如果明文是'a'而实际使用的字符是U+0430, 可以编码信息
```

**Unicode 控制字符编码**:
```
利用U+FEFF (BOM/ZW NBSP) 和 U+FFFE 在文本中插入作为比特标志
```

### 2.5 Whitespace 编程语言隐写

Whitespace是一种只使用Space (0x20)、Tab (0x09)、Line Feed (0x0A)三种字符的编程语言。在CTF中，"代码"可能藏在普通文本的行尾空白或行间空白。

```bash
# 提取Whitespace程序的不可见字符
cat file.txt | sed 's/[^ \t\n]//g' > program.ws
# 或者用Python
```

**Python Whitespace 解释器**:
```bash
# 需要提前安装
pip install whitespace
whitespace program.ws
```

### 2.6 文件拼接隐写 (File Concatenation)

将一个文件直接拼接在另一个文件末尾。特点：
- 文件格式解析器通常只读自己需要的数据，忽略尾随数据
- 如：PNG文件以IEND chunk结尾，IEND之后的数据被标准查看器忽略
- 但是`file`命令识别第一个文件的格式

检测方法：
```bash
binwalk -e concatenated_file
foremost -i concatenated_file -o output/
```

手动拼接和分离：
```bash
# 查看拼接点
hexdump -C file.png | tail -20        # 找到IEND位置
# 分离
dd if=file.png of=hidden.zip bs=1 skip=<IEND_end_offset>
```

### 3.3 自建综合检测脚本

```python
#!/usr/bin/env python3
"""综合隐写检测脚本"""
import sys
import re

def detect_all_stego(filepath):
    with open(filepath, 'rb') as f:
        raw = f.read()
    
    results = {}
    
    # 1. 零宽字符检测
    zw_patterns = [
        (b'\xe2\x80\x8b', 'ZWSP/U+200B'),
        (b'\xe2\x80\x8c', 'ZWNJ/U+200C'),
        (b'\xe2\x80\x8d', 'ZWJ/U+200D'),
        (b'\xe2\x80\x8e', 'LRM/U+200E'),
        (b'\xe2\x80\x8f', 'RLM/U+200F'),
    ]
    for pattern, name in zw_patterns:
        cnt = raw.count(pattern)
        if cnt > 0:
            results[name] = cnt
    
    # 2. 行尾空白检测
    trailing_space_lines = 0
    trailing_tab_lines = 0
    for line in raw.split(b'\n'):
        stripped = line.rstrip(b'\r\n')
        if stripped != line.rstrip(b'\r\n ') and not stripped.endswith(b' '):
            trailing_space_lines += 1
        if stripped != line.rstrip(b'\r\n\t') and not stripped.endswith(b'\t'):
            trailing_tab_lines += 1
    if trailing_space_lines > len(raw.split(b'\n')) * 0.3:
        results['Trailing Spaces'] = trailing_space_lines
    if trailing_tab_lines > 5:
        results['Trailing Tabs'] = trailing_tab_lines
    
    # 3. Base64行末尾等号数量分析
    b64_lines = []
    for line in raw.decode(errors='replace').split('\n'):
        line = line.strip()
        if re.match(r'^[A-Za-z0-9+/=]+$', line) and line.endswith('=') and len(line) > 10:
            b64_lines.append(line)
    if b64_lines:
        results['Base64 lines with padding'] = len(b64_lines)
    
    # 4. Unicode 同形字符检测
    # 搜索西里尔字母混在拉丁字母中
    homoglyph_patterns = [
        (b'\xd0\xb0', 'Cyrillic a (U+0430)'),
        (b'\xd0\xb5', 'Cyrillic e (U+0435)'),
        (b'\xd0\xbe', 'Cyrillic o (U+043E)'),
        (b'\xd1\x80', 'Cyrillic r (U+0440)'),
        (b'\xd1\x81', 'Cyrillic s (U+0441)'),
        (b'\xd1\x83', 'Cyrillic y (U+0443)'),
    ]
    for pattern, name in homoglyph_patterns:
        cnt = raw.count(pattern)
        if cnt > 0:
            results[name] = cnt
    
    return results
```

## 4. 常见误区与注意事项

### 误区1: 只看打印字符
许多选手拿到文本文件只读内容，忽略不可见字符。**务必用`cat -A`或hexdump检查。**

### 误区2: Base64只解码不分析
看到Base64就解码是对的，但**标准解码会丢弃隐写比特位**。如果解码结果有意义就用解码结果，如果解码结果是乱码，考虑Base64隐写。

### 误区3: 零宽字符无法感知
零宽字符在大多数编辑器中完全不可见。VSCode默认不显示，Notepad++需要在View->Show Symbol->Show All Characters才能看到。**建议用hexdump检测。**

### 误区4: 只检查文件开始位置
文件拼接隐写往往是文件末尾附加额外数据。**查看文件末尾（tail/hexdump末尾）同样重要。**

### 误区5: 忽视HTML/XML中的注释和CDATA
HTML页面的源码中，flag可能藏在注释(`<!-- --->`)、隐藏的div(`<div hidden>`)、或`<script>`中的无用变量。先`Ctrl+U`(查看源码)。

### 误区6: 只看不拆解
PNG后跟ZIP、JPEG后跟RAR等文件拼接用肉眼看不出来。**`binwalk`是必备第一步。**

## 5. 实战示例

### 示例1: Base64隐写

```
场景: 得到一个全是Base64编码行的文本文件

步骤:
1. cat file.txt
   TmFtZTogSm9obiBEb2UK
   QWd
   ZTog
   MzAgICAgICAgICAgICA=
2. 逐行解码:
   echo "TmFtZTogSm9obiBEb2UK" | base64 -d  → "Name: John Doe"
   echo "QWd" | base64 -d  → (乱码, 只有1字节时填充=太多)
3. 发现后面几行都带= → Base64隐写嫌疑
4. 使用Base64隐写提取脚本
5. 提取出隐藏比特: flag{b64_stegano_is_cool}
```

### 示例2: 行尾空格Tab编码

```
场景: 一段正常英文文本，但每行末尾有不同长度的空格/Tab

步骤:
1. cat -A file.txt
   部分输出:
   This is a normal sentence.      $
   The quick brown fox.    ^I^I  $
   (可以明显看到行尾的空格和Tab)
2. 使用snow或自己写脚本:
   snow -C file.txt  # 提取隐藏文本
3. flag{whitespace_steganography}
```

### 示例3: 零宽字符隐写

```
场景: 复制粘贴一段文字到其他地方时，字数统计异常（实际字数>显示字数）

步骤:
1. hexdump -C suspicious.txt
   发现大量 e2 80 8b (ZWSP) 和 e2 80 8c (ZWNJ)
2. 运行零宽字符提取脚本
3. ZWSP+ZWNJ = 0, ZWSP+ZWJ = 1
4. 解码得到: flag{invisible_but_existent}
```

### 示例4: Unicode同形字符

```
场景: 一个字母组成的"英文"单词，表面上看是flag但复制后解码错误

步骤:
1. hexdump -C word.txt
   一些'a'是 0x61 (拉丁a)
   一些'a'是 0xd0 0xb0 (西里尔а)
2. 把西里尔字母映射为1，拉丁字母映射为0
3. 得到比特流: 011001100110110001100001...
4. 解码: flag{homoglyph_attack}
```

### 示例5: 文件拼接（PNG+ZIP）

```
场景: file命令识别为PNG，但文件大小异常大

步骤:
1. binwalk suspicious.png
   DECIMAL  HEX        DESCRIPTION
   0        0x0        PNG image
   123456   0x1E240    Zip archive data
2. 定位IEND:
   hexdump -C suspicious.png | grep "49 45 4E 44"
   偏移: 0x50
3. 提取ZIP:
   dd if=suspicious.png of=hidden.zip bs=1 skip=$((0x50 + 4 + 4 + 4))
   (跳过IEND chunk: 4B长度 + 4B类型 + 0B数据 + 4B CRC)
4. unzip hidden.zip -> flag.txt
```

## 6. 相关知识点

### 6.1 PDF隐写
- 对象间的空白区域
- 增量更新（incremental update）中隐藏数据
- XObject字典中的额外流
- `pdf-parser.py` 或 `peepdf` 提取

### 6.2 Office文档隐写 (.docx/.xlsx/.pptx)
- OOXML格式本质是ZIP包（直接改名.zip解压）
- XML注释中隐藏数据
- 隐藏的Sheet/VBA代码
- 白色字体在白色背景上
- 极小字体

### 6.3 HTML/CSS隐写
- HTML注释 `<!-- flag{...} -->`
- CSS `display:none` 或 `visibility:hidden`
- CSS `color:white` 白字白底
- CSS `font-size:0px`
- `<input type="hidden" value="...">`
- `<meta>`标签

### 6.4 音频/视频中的莫尔斯码
音频中夹杂人工莫尔斯码（嘀嘀嘀嗒嗒嗒的声音）可能不在频谱图显示为文字，而是需要听或进行波形分析。

### 6.5 小参数模型辅助
1. **可疑字符序列的描述**: "文件末尾出现大量行尾Tab字符" -> 模型推断空格Tab隐写
2. **编码方案设计**: "我想在HTML中用零宽字符隐写，帮我设计编码和解码脚本"
3. **文件头异常分析**: "binwalk输出显示PNG+ZIP+RAR，这是什么情况" -> 模型解释多层拼接
4. **解码脚本生成**: 描述隐写特征后，让模型生成完整Python解码脚本
