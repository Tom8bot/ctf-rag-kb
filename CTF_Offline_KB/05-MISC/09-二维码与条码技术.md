# 09 - 二维码与条码技术

## 1. 概述

二维码（2D Barcode）在CTF MISC中是高频考点。题目形式多样：给出损坏/模糊的QR码需要修复、一个图片中含多个小型QR码、手绘（Paint）风格的QR码、二维码的反色/旋转/翻转、甚至是3D建模的QR码需要透视校正。

断网环境下核心工具：**zbarimg**（命令行QR/条码扫描）、**QRazyBox**（离线QR码修复工具）、**Python (qrcode / PIL / pyzbar)**、以及手工QR码修复能力。

## 2. 核心原理

### 2.1 QR Code 结构

QR码由功能图形区域和编码区域组成：

```
┌─────────────────────────────┐
│ ██████████  ██  ██  ██████████ │  ← Position Detection Pattern (3个角)
│ ██      ██      ██  ██      ██ │
│ ██  ██  ██  ██  ██  ██  ██  ██ │
│ ██      ██  ██      ██      ██ │
│ ██████████  ██  ██  ██████████ │  ← Timing Pattern (虚线)
│             ██  ██             │
│ ██  ██  ██      ██████  ██  ██ │
│   ██    ██  ████  ██    ██  ██ │
│ ██  ██  ██  ██    ██████      │
│   ██  ████  ██      ██  ██    │
│             ██  ████  ██      │
│ ██████████  ██    ██    ██████ │
│ ██      ██    ██  ██    ██  ██ │
│ ██  ██  ██  ██    ████        │
│ ██      ██  ██      ██        │
│ ██████████  ██  ██  ██  ████  │
└─────────────────────────────┘
```

关键组成：
1. **位置探测图形 (Position Detection Pattern)**: 三个角的"回"字形方块，用于定位
2. **定位图形 (Timing Pattern)**: 黑白交替的水平/垂直线条，连接三个角
3. **矫正图形 (Alignment Pattern)**: 版本2以上的QR码有，帮助校正变形
4. **格式信息 (Format Information)**: 编码纠错级别和掩码模式（15位，5+10 BCH编码）
5. **版本信息 (Version Information)**: 版本7以上QR码的版本号（18位，6+12 BCH编码）
6. **数据与纠错码**: 实际数据位和纠错位
7. **安静区 (Quiet Zone)**: QR码周围的空白，至少4个模块宽度

### 2.2 QR码版本与容量

| 版本 | 模块数 (N×N) | 最大数字 | 最大字母数字 | 最大字节 | 纠错级别 |
|------|-------------|---------|------------|---------|---------|
| 1    | 21 × 21     | 41      | 25         | 17      | L/M/Q/H |
| 2    | 25 × 25     | 77      | 47         | 32      | ...     |
| 10   | 57 × 57     | 652     | 395        | 271     | ...     |
| 40   | 177 × 177   | 7089    | 4296       | 2953    | ...     |

**纠错级别**:
- L (Low): 恢复约7%的码字
- M (Medium): 恢复约15%
- Q (Quartile): 恢复约25%
- H (High): 恢复约30%

### 2.3 QR码数据编码模式

```
模式指示符:
  0001: 数字 (Numeric), 每3个字符用10bit编码
  0010: 字母数字 (Alphanumeric), 每2个字符用11bit编码
  0100: 8位字节 (Byte), 每个字符8bit
  1000: 汉字 (Kanji), 每字符13bit
  0011: 结构化追加 (Structured Append)
  0101: FNC1 (用于GS1标准)
  0111: ECI (Extended Channel Interpretation)
```

### 2.4 掩码 (Masking)

QR码使用8种掩码模式，将数据位与掩码图案进行XOR，以平衡黑白模块比例，避免出现大块同色区域。

```
掩码公式:
  000: (row + col) % 2 == 0
  001: row % 2 == 0
  010: col % 3 == 0
  011: (row + col) % 3 == 0
  100: ((row // 2) + (col // 3)) % 2 == 0
  101: (row * col) % 2 + (row * col) % 3 == 0
  110: ((row * col) % 2 + (row * col) % 3) % 2 == 0
  111: ((row + col) % 2 + (row * col) % 3) % 2 == 0
```

### 2.5 其他条码格式

**Data Matrix**:
- 由正方形/矩形模块组成L形边界（finder pattern）+ 交替的时钟轨道
- 容量取决于尺寸（10×10到144×144），ECC200使用Reed-Solomon纠错
- 常用于工业零件标记

**PDF417**:
- 堆叠式线性条码（stacked linear barcode）
- 由3~90行组成
- 起止模式+左右行指示符+数据区域
- 支持约1850个文本字符

**Aztec Code**:
- 中心有靶心状的finder pattern（同心正方块）
- 正方形，不需要安静区
- 常用于登机牌、电子票

**MaxiCode (UPS)**:
- 中心有公牛眼图案（同心圆）
- 六边形模块排列
- 主要用于包裹追踪

**条形码 (1D Barcode)**:
- **Code39**: 字母数字，每个字符由5条黑4条白组成，3宽6窄
- **Code128**: 高密度字母数字，广泛用于物流
- **EAN-13/UPC-A**: 零售商品条形码
- **Codabar / Interleaved 2 of 5**: 图书馆/仓库

## 3. 关键工具与命令

### 3.1 zbarimg (命令行扫码)

```bash
# 安装: apt-get install zbar-tools
# 扫描单张图片
zbarimg qrcode.png
# 输出: QR-Code:flag{read_qr_success}

zbarimg --set "*.enable=1" barcode.png

zbarimg --raw qrcode.png

# 扫描多个文件
zbarimg *.png *.jpg

# 详细输出(含位置)
zbarimg -v qrcode.png

# 多页PDF中的条码
zbarimg document.pdf
```

### 3.3 Python二维码生成与解析

```python
# === 二维码生成 ===
import qrcode

# 基本生成
qr = qrcode.QRCode(
    version=2,  # 1-40, None=自动
    error_correction=qrcode.constants.ERROR_CORRECT_H,  # H=30%
    box_size=10,
    border=4,
)
qr.add_data('flag{test_qr}')
qr.make(fit=True)
img = qr.make_image(fill_color='black', back_color='white')
img.save('output.png')

# === 二维码解析 ===
from pyzbar.pyzbar import decode
from PIL import Image

# 基础解析
results = decode(Image.open('qrcode.png'))
for r in results:
    print(f'Type: {r.type}')
    print(f'Data: {r.data.decode()}')
    print(f'Position: {r.rect}')  # (left, top, width, height)

# 批量扫描
import os
for f in os.listdir('qrs/'):
    if f.endswith(('.png', '.jpg')):
        results = decode(Image.open(f'qrs/{f}'))
        for r in results:
            print(f'{f}: {r.data.decode()}')
```

### 3.5 Python预处理脚本

```python
from PIL import Image, ImageFilter, ImageOps
import numpy as np

def preprocess_qr(img_path, output_path):
    """QR码图像预处理流水线"""
    img = Image.open(img_path)
    
    # 1. 转为灰度
    img = img.convert('L')
    
    # 2. 自适应直方图均衡 (CLAHE) - 改善局部对比度
    # (PIL无内建CLAHE，可用OpenCV或自写)
    
    # 3. 中值滤波去噪
    img = img.filter(ImageFilter.MedianFilter(3))
    
    # 4. Otsu阈值二值化
    array = np.array(img)
    threshold = otsu_threshold(array)
    img = img.point(lambda p: 255 if p > threshold else 0)
    
    # 5. 形态学操作 (可选: 闭运算填补小洞)
    # 这里省略，需要scipy或自写
    
    # 6. 反转 (如果QR码是白底黑块但zbar要求黑底白块)
    # zbar支持两者，一般无需反转
    
    img.save(output_path)
    print(f'Saved preprocessed: {output_path}')

def otsu_threshold(data):
    """Otsu二值化阈值计算"""
    bins = np.bincount(data.ravel(), minlength=256)
    total = data.size
    sum_all = np.dot(np.arange(256), bins)
    sum_b = 0
    w_b = 0
    max_var = 0
    threshold = 128
    for t in range(256):
        w_b += bins[t]
        if w_b == 0:
            continue
        w_f = total - w_b
        if w_f == 0:
            break
        sum_b += t * bins[t]
        m_b = sum_b / w_b
        m_f = (sum_all - sum_b) / w_f
        var_between = w_b * w_f * (m_b - m_f) ** 2
        if var_between > max_var:
            max_var = var_between
            threshold = t
    return threshold
```

## 4. 常见误区与注意事项

### 误区1: 忘记试反色
QR码可以是白底黑模块，也可以是黑底白模块。zbarimg默认支持两者，但某些处理中可能需要反转。**`convert -negate` 是第一尝试。**

### 误区2: 忽略纠错能力
QR码有H级纠错（约30%恢復能力）。即使QR码部分损坏不超过30%，理论上仍可解码。**不要因为看起来损坏就放弃。**

### 误区3: 注意模块对齐
手绘/broken QR码的模块边界可能不清晰。zbarimg对网格对齐要求高，此时需要QRazyBox手动指定模块间距。

### 误区4: 多QR码混扫
一张图中可能包含多个QR码（如3x3排列的9个QR码）。zbar默认可能只扫到第一个。**需要裁剪或使用`--set`参数。**

### 误区5: 二维码的"安静区"被裁
QR码需要周围至少4个模块宽的安静区(空白)。如果图片裁剪过紧，zbar可能拒绝识别。**添加白边 (`-border XX`) 解决。**

### 误区6: 忽视非QR码格式
CTF中不仅有QR码，还有Data Matrix、PDF417、Aztec Code等。如果zbar检测不到，尝试指定类型或使用其他专用工具。

## 6. 相关知识点

### 6.1 QR码结构化追加 (Structured Append)

一个数据被分割成最多16个QR码。每个码的数据以结构化追加模式指示符开头，前4bit是当前码的序号，后4bit是总码数。扫描器需要按顺序拼接。

### 6.2 QR码中的二进制数据

QR码的Byte模式可以直接存储二进制数据（不限于UTF-8文本）。zbarimg输出的可能是乱码（二进制尝试被解释为UTF-8）。使用`zbarimg --raw -Sbinary`或pyzbar的`.data`属性获取原始字节。

### 6.3 二维码中的Base64/加密数据

常见CTF模式：QR码扫描结果是Base64编码的字符串，或者是加密后的flag。需要进一步的解码/解密步骤。

### 6.4 色彩反转/艺术QR码

现代QR码设计可使用彩色（彩色QR码的模块用彩色代替黑色）。扫描器对颜色的处理是看亮度和对比度，不是颜色本身。但如果配色不当，可能导致某个颜色被识别为错误的黑/白。

### 6.5 小参数模型辅助

1. **损坏QR码分析**: "QR码右上角缺了一大块，左下角完好" -> 模型评估纠错是否能恢复，建议修复策略
2. **QR码格式识别**: 给出条码截图描述给模型，让其判断条码类型
3. **解码结果分析**: 扫描输出是乱码或可疑字符串，让模型判断下一步操作(解码/解密)
4. **手写脚本**: "帮我写脚本批量裁剪图片中的QR码区域并逐个扫描"
