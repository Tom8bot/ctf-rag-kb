# Web 题型索引

## 1. 按现象定位文档

### 1.1 SQL 注入迹象
- 单引号导致报错或响应变化
- `order by`、`union`、数据库关键字有效
- 页面根据条件真假返回长度不同
- 延时有效

→ 看：`01-SQL注入.md`

### 1.2 模板 / 前端注入迹象
- `{{7*7}}` / `${7*7}` / `<%= %>` / `{% %}`
- 回显可控 HTML / JS / DOM 拼接
- 前端读取 `location.hash` / `innerHTML` / `document.write`

→ 看：`02-SSTI_XSS_模板与前端漏洞.md`

### 1.3 文件、协议、对象类题目
- 文件上传、文件解析、下载、include、xml、yaml、pickle、phar
- URL 抓取、头像拉取、Webhook、回源、内网探测

→ 看：`03-文件上传_文件包含_SSRF_XXE_反序列化.md`

### 1.4 认证、越权、框架逻辑
- 登录、注册、重置密码、验证码、JWT、OAuth
- IDOR、水平/垂直越权、接口绕过、缓存与 host 头
- 看源码审计时遇到 PHP / Flask / Spring / Node

→ 看：`04-认证鉴权_逻辑漏洞_框架审计.md`

---

## 2. Web 做题基本顺序
1. 看源码、robots.txt、js、注释、接口。
2. 抓所有请求，记录参数、header、cookie、鉴权逻辑。
3. 先做低成本测试：引号、模板算术、文件名、路径、JWT 解码。
4. 再做高收益点：上传、模板、反序列化、权限绕过。
5. 确认是否有二次触发、后台任务、日志污染、缓存。

---

## 3. 高频误判
- 以为是 SQLi，实际是模板拼接
- 以为是 XSS，实际是浏览器端编码问题
- 以为文件上传没用，实际是解析链或二次包含
- 以为没有 SSRF，实际在 PDF / 图片处理 / webhook / 头像下载处
- 以为鉴权安全，实际是前端校验或接口忘记鉴权
