# 第二版增强知识库

> 目标：在原始离线 CTF 知识库基础上，补充更偏向实战、绕过、版本差异、题型识别与通用利用框架的内容，帮助小模型在离线、小上下文、弱推理条件下更高效地命中解题路径。

## 设计原则

1. **优先通用解法，不堆砌低价值枚举。**
2. **优先题型识别特征、最短验证路径、通用利用骨架。**
3. **优先写可复用模板、脚本框架、绕过框架。**
4. **尽量兼容不同版本、不同语言、不同防护。**
5. **兼顾人类阅读与小模型检索。**

## 本目录结构

- `01-WEB增强/`：SSTI 引擎差异、JWT、GraphQL、Node/PHP/Java 常见审计面、请求走私、缓存投毒、原型链、模板链、反序列化扩展
- `02-PWN增强/`：glibc 版本差异、ret2dlresolve、seccomp/sandbox、ORW、tcache/largebin、IO_FILE、内核利用提示
- `03-RE增强/`：OLLVM、虚拟机壳、WASM、Frida、自动化 patch、符号执行与约束简化
- `04-CRYPTO增强/`：ECC、Coppersmith/LLL、签名攻击、格攻击、LFSR、Mersenne Twister、复杂 Oracle
- `05-MISC增强/`：Office/PDF、Volatility、磁盘/内存/日志取证、二维码/条码/音频/图像更深技巧
- `06-渗透与网络增强/`：AD、委派、Kerberos、容器/K8s、云、隧道、流量转发、协议层利用
- `99-索引与映射/`：关键词反查、现象到题型、比赛优先级、最小脚本模板

## 阅读顺序建议

### 如果你是比赛中快速检索
1. 先看 `99-索引与映射/现象到题型映射.md`
2. 再看对应专题的“识别特征/最短验证/通用利用框架”
3. 最后看“绕过与排障”

### 如果你是赛前系统复习
1. 先按原知识库大纲复习
2. 再按本目录逐章补齐高级题型
3. 用附录中的 checklist 和模板进行压缩记忆

## 小模型使用建议

- 检索时尽量带上：**现象 + 技术栈 + 限制条件 + 目标**。
- 提问模板建议：
  - `这题是 Flask/Jinja2，过滤了 {{ . _ [ ]，目标 RCE，给我最短可行链。`
  - `这题是 glibc 2.31，只有 UAF 和 show，给出堆利用优先级。`
  - `这题像 RSA 但 e 很大、已知部分明文，优先考虑哪些攻击。`

## 第二版增强重点

- 不再只讲“是什么”，而更强调：
  - **怎么一眼识别**
  - **怎么最短验证**
  - **怎么快速绕过**
  - **怎么在版本差异中选路线**
  - **怎么在信息不全时做假设分支**
