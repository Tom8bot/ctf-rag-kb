# 题型到知识点映射

## 1. Web

### 1.1 看到这些现象，优先想到 SQL 注入
- 单引号 / 双引号 / 反引号导致报错
- `order by`、`union`、数据库关键字带来响应差异
- 布尔真假导致页面长度不同
- 指定 payload 会延时
- 参数参与排序、搜索、过滤、分页

### 1.2 看到这些现象，优先想到 SSTI
- `{{7*7}}`、`${7*7}`、`<%=7*7%>` 有结果
- 报错里出现 template / jinja / twig / freemarker / velocity
- 可控字符串出现在服务端渲染结果而非原样输出

### 1.3 看到这些现象，优先想到 XSS
- 输入被放入 HTML / 属性 / JS 字符串 / DOM sink
- 页面前端脚本里有 `innerHTML` / `document.write` / `eval`
- 片段只在浏览器端拼接和执行

### 1.4 看到这些现象，优先想到文件链漏洞
- 上传后缀检查严格但内容可控
- 文件可写但访问路径奇怪
- 下载接口、模板 include、日志读取、图片处理、PDF 生成
- 参数看起来像路径、URL、模板名、文件名

### 1.5 看到这些现象，优先想到鉴权逻辑
- API 与前端状态不一致
- 可通过改 id 访问他人资源
- 登录、注册、验证码、重置密码流程复杂
- JWT / OAuth / session / role 信息在客户端明显可见

---

## 2. Pwn

### 2.1 栈题
- 长输入导致崩溃
- RIP/EIP 可控
- `gets/scanf/read/fgets/strcpy/strcat` 等危险函数
- checksec 显示无 canary / 无 PIE / NX 关闭

### 2.2 格式化字符串
- `printf(buf)` / `%p` / `%s` / `%n` 生效
- 可泄露栈、libc、返回地址、canary

### 2.3 堆题
- 菜单题：add/edit/delete/show
- UAF、double free、off-by-one/off-by-null
- glibc 版本信息给出 / libc 附带

### 2.4 沙箱题
- seccomp / syscall 受限
- 只能 open/read/write / 或禁止 execve
- 常走 ORW、SROP、mprotect、ret2dlresolve

---

## 3. RE

### 3.1 算法校验题
- 程序要求输入 flag，然后进行一串运算 compare
- 常见：xor、加减、移位、轮转、矩阵、表替换、TEA、RC4、自定义 VM

### 3.2 壳 / 反调试
- 运行即退出、检测 ptrace、时间、PEB、硬件断点
- 字符串极少、导入少、节区异常、熵高

### 3.3 脚本 / 安卓 / JS
- pyc、jsfuck、eval、webpack、dex、so、native 方法

---

## 4. Crypto

### 4.1 编码 / 脑洞题
- 字符集明显、长度规则、像 base / hex / uu / url / html entity

### 4.2 异或题
- 明显二进制、可打印度低、重复模式、已知前缀 `flag{`

### 4.3 RSA 题
- 给 `n,e,c` 或额外给 `p,q,dp,dq,phi`、hint、多个密文
- 重点检查：共模、共因子、小 e、广播、近素数、部分泄露、oracle

### 4.4 分组模式题
- 固定分组长度、重复块、padding、IV / nonce、加密 oracle

---

## 5. Misc

### 5.1 隐写题
- 给图片/音频/视频/文档；肉眼正常但元数据、LSB、尾部、色道异常

### 5.2 取证题
- pcap、日志、内存、注册表、磁盘、浏览器缓存、命令历史

### 5.3 压缩包题
- 多层嵌套、伪加密、明文攻击、CRC、文件头、分卷、图片藏 zip

---

## 6. 渗透与网络
- 服务指纹与默认口令
- 配置泄露、目录遍历、RCE、文件写入
- Linux 提权、内网横向、AD 枚举、API 权限控制

---

## 7. 决策树
```text
参数一改就报错/变长 -> SQLi / 模板 / 逻辑
上传可控文件 -> 上传 / 解析链 / 包含 / phar
二进制崩溃 -> 栈 / fmt / 堆
看到大量模运算 -> RSA / 数论
给图像或 pcap -> Misc / 取证
给 IP 和端口 -> 枚举服务 -> 已知洞 / 默认配置 / 权限提升
```
