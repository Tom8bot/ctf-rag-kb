# 流量分析 / 内存取证 / OSINT

---

## 1. 流量分析

## 1.1 开局
- 先看总体协议分布
- 找 HTTP / DNS / FTP / SMB / SMTP / TLS / ICMP
- 找异常主机、异常域名、异常文件传输

### 最小命令
```bash
tshark -r file.pcap | head
tshark -r file.pcap -q -z io,phs
strings file.pcap | less
```

## 1.2 HTTP
- 请求路径、参数、cookie、上传文件、下载对象
- Host、User-Agent、Authorization
- 导出对象看源码、木马、flag 文件

## 1.3 DNS
- 可见子域名、数据外带、TXT 记录、长子域
- 是否有 base32/base64 编码痕迹

## 1.4 FTP/SMB/SMTP
- 用户名密码
- 传输文件
- 邮件正文/附件

## 1.5 TLS/HTTPS
- 证书信息
- SNI / JA3（如果题目给）
- 若同时给服务端 key，可能可解密

## 1.6 提取对象思维
- 文件传输类协议一定想“有没有可导出的文件”
- 登录类协议一定想“有没有凭据”
- 命令类协议一定想“有没有执行痕迹”

---

## 2. 内存取证

## 2.1 常见目标
- 当前进程
- 命令行
- 网络连接
- 注入代码
- 浏览器痕迹
- 剪贴板/屏幕残留
- 明文密码/flag

## 2.2 Volatility 思维
先回答：
1. 这是 Windows / Linux / Mac 哪类内存？
2. 目标是恶意进程、命令、文件还是凭据？

### 高频插件方向
- 进程列表
- 命令行
- 网络连接
- dll/module
- 文件对象
- strings + 进程关联

## 2.3 最小策略
- 看进程树
- 找异常父子进程
- 找命令行
- 找网络连接
- 找被注入模块/可疑内存段
- 对可疑进程做字符串提取

---

## 3. 日志 / 主机取证
- bash_history
- auth.log / secure
- web access.log / error.log
- cron
- systemd journal
- Windows 事件日志
- 浏览器历史、下载记录、cookie

### 核心问题
- 谁在什么时候做了什么？
- 从哪进来？执行了什么命令？访问了哪些文件？

---

## 4. OSINT

## 4.1 题型方向
- 域名/邮箱/用户名/社交账号关联
- 图片地点识别
- 文档作者信息
- GitHub / 泄露仓库 / 提交记录
- 网站历史快照

## 4.2 离线环境思路
断网时 OSINT 题能力有限，但仍能做：
- 看附件元数据
- 看图片 EXIF
- 看文档作者、编辑软件、时间线
- 看本地给出的网页快照/缓存/日志

---

## 5. 最短作战模板

```text
pcap：先协议分布 -> 找登录/文件传输/异常域名 -> 导对象/提凭据
内存：先进程树/命令行/网络 -> 再搜字符串和可疑模块
OSINT：优先挖本地附件元数据和历史痕迹
```
