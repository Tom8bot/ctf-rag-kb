# 隐写 / 压缩 / 文件格式 / 取证

---

## 1. 开局总流程

```text
file -> strings -> exiftool -> binwalk -> 看头尾 -> 看元数据 -> 看是否追加/嵌套/伪装 -> 再做专项工具分析
```

---

## 2. 图片题

## 2.1 高频检查
- `file image`
- `exiftool image`
- `strings image | less`
- `binwalk image`
- 看是否有尾部追加数据

## 2.2 常见隐写方向
- LSB
- 色道异常（RGB/alpha）
- 调色板索引
- 尺寸异常
- 尾部拼接 zip/rar/txt
- 元数据注释
- 分块顺序异常（PNG chunk）

## 2.3 PNG 特别注意
- 头固定：`89 50 4E 47 0D 0A 1A 0A`
- 结束块 `IEND`
- IEND 后仍有数据 -> 尾部追加
- chunk 里可能藏文本 `tEXt/iTXt/zTXt`
- 宽高/CRC 异常可能有考点

## 2.4 JPG 特别注意
- EXIF
- 注释段
- steghide 常见
- 尾部追加压缩包

## 2.5 GIF/BMP
- 调色板、帧、像素低位
- BMP 没压缩时更适合 LSB

## 4. 压缩包题

## 4.1 开局检查
```bash
zipinfo file.zip
7z l file.zip
binwalk file.zip
strings file.zip | less
```

## 4.2 常见题型
- 多层嵌套
- 伪加密
- 明文攻击
- ZIP CRC 爆破
- 分卷
- 文件名注释藏信息
- 图片里藏 zip

## 4.3 伪加密识别
- 看压缩软件是否报告加密
- 但实际数据区未加密，只是标志位被置位

## 4.4 ZIP CRC 爆破思维
### 条件
- 已知压缩后文件的 CRC32 和长度
- 明文空间较小

### 用法
- 爆破短内容
- 恢复口令/文件内容的部分信息

## 5. 文件格式基础

### 5.1 必看头尾
- PNG
- ZIP
- PDF
- ELF
- PE
- SQLite
- 7z

### 5.2 伪装文件
- 后缀是 jpg，实际是 zip
- 双文件拼接
- polyglot

### 5.3 常见修复思路
- 补文件头
- 改宽高
- 修 chunk/section 长度
- 截断尾部噪声

## 6. 文档题

### 6.1 PDF
- `pdfinfo`
- `strings`
- 看注释、对象流、JS、隐藏层、附件

### 6.2 Office
- docx/xlsx/pptx 本质 zip
- 解压后看 xml / media / comments / custom props / macros

### 6.3 宏文档
- VBA 宏、隐藏表单、自动执行入口

---

## 7. 基础取证思维

### 7.1 先判断题目要你找什么
- flag 在文件内容里
- 在元数据里
- 在删除文件里
- 在日志/浏览记录里
- 在内存或流量里

### 7.2 取证不是盲搜，是按“数据留下的位置”去找
```text
用户操作 -> 会留下哪些文件/日志/缓存/历史/元数据？
```

---

## 8. 最短作战模板

```text
图片：先 file/strings/exiftool/binwalk，再看尾部、LSB、色道
压缩包：先列表、伪加密、多层嵌套、CRC、注释
文档：先解包/拆对象流，找注释、附件、宏、隐藏文本
```
