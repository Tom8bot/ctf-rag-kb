# 量子密码与后量子密码基础概念

## 1. 概述

量子计算对现代密码学构成根本性威胁。Shor 算法（1994）可在多项式时间内分解大整数和计算离散对数，直接破解 RSA 和 ECC。Grover 算法（1996）将暴力搜索复杂度从 O(N) 降到 O(√N)，使对称密码的安全强度减半。

NIST 后量子密码标准化进程（2016-2024）选择了以下标准：
- **CRYSTALS-Kyber**（密钥封装，基于 Module-LWE）
- **CRYSTALS-Dilithium**（数字签名，基于 Module-LWE/SIS）
- **Falcon**（数字签名，基于 NTRU 格）
- **SPHINCS+**（无状态哈希签名）

CTF 中此方向的题目开始增多，主要考察：
- 量子算法的基础理解
- 后量子密码方案中的参数弱点
- QKD（量子密钥分发）协议的分析
- 格参数选择不当导致的攻击

## 2. 核心原理（含数学推导）

### 2.1 Shor 算法核心

Shor 算法将因子分解问题转化为周期查找问题：

1. 随机选 a（1 < a < N），计算 gcd(a, N)
2. 若 gcd != 1，已完成分解
3. 否则寻找函数 f(x) = a^x mod N 的周期 r
4. 若 r 为偶数且 a^{r/2} != -1 mod N：
   `gcd(a^{r/2} - 1, N)` 和 `gcd(a^{r/2} + 1, N)` 是 N 的非平凡因子

**量子傅里叶变换 (QFT)** 是 Shor 算法的核心子程序：
```
QFT|j> = 1/sqrt(N) Σ_{k=0}^{N-1} e^{2πi*jk/N} |k>
```

时间复杂度：O((log N)^3)（量子运算），而经典算法最优为亚指数。

### 2.2 Grover 算法核心

Grover 算法用于在无结构搜索空间中加速查找。

给定 oracle 函数 f: {0,1}^n -> {0,1} 满足 f(x*) = 1 的 x* 唯一，经典需要 O(2^n) 次 oracle 查询，Grover 仅需 O(2^{n/2})。

核心操作 = 迭代应用 Grover 算子 G = H^(⊗n) * (2|0><0| - I) * H^(⊗n) * O_f

迭代次数 `k ≈ π/4 * sqrt(2^n)`

**对密码学的影响**：将 AES-128 的暴力破解复杂度从 2^128 降到 2^64（等效于 AES-64），因此建议使用 AES-256 抵抗量子计算。

### 2.3 QKD — BB84 协议

Bennett-Brassard 1984 (BB84)：

1. Alice 随机生成比特串 a_i 和基选择串 b_i (0=Z基|0,1>, 1=X基|+,->)
2. Alice 发送单个光子，编码为：b=0时a=0 -> |0>, a=1 -> |1>；b=1时a=0 -> |+>, a=1 -> |->
3. Bob 随机选基 b_i' 测量
4. Alice 和 Bob 公开比较基选择，保留基相同的位作为原始密钥
5. 部分位用于误差估计，检测窃听
6. 通过错误校正和隐私放大生成最终密钥

安全保证：任何窃听行为都会引入可检测的错误（海森堡不确定性原理 + 不可克隆定理）。

### 2.4 后量子密码的五大方向

1. **基于格 (Lattice-based)**：LWE, Ring-LWE, Module-LWE — Kyber, Dilithium, Falcon
2. **基于编码 (Code-based)**：McEliece 密码 — Classic McEliece
3. **多变量 (Multivariate)**：UOV, Rainbow — 解多变元二次方程组
4. **基于哈希 (Hash-based)**：Merkle 签名, SPHINCS+ — 仅安全性依赖哈希
5. **基于同源 (Isogeny-based)**：SIKE (已被完全破解), CSIDH

### 3.1 Shor 算法的经典模拟

```python
import gmpy2
import math
import random
from collections import Counter

def shor_algorithm_classical(N: int, a: int = None) -> tuple:
    """
    用经典方式模拟 Shor 算法的数学结构
    （量子部分无法在经典计算机上高效运行，但数学结构可模拟）

    参数:
        N: 要分解的整数
        a: 随机基数（可选，None 为自动选择）
    返回:
        (p, q) 或 None
    """
    if N % 2 == 0:
        return 2, N // 2

    if a is None:
        a = random.randint(2, N - 2)

    # 步骤1: 检查 gcd
    g = math.gcd(a, N)
    if g > 1:
        return g, N // g

    # 步骤2: 找周期 r 使得 a^r ≡ 1 mod N
    # 在量子计算机上使用 QFT 高效完成，这里用经典暴力搜索
    def find_period(a, N, max_r=1000000):
        for r in range(1, max_r):
            if pow(a, r, N) == 1:
                return r
        return None

    r = find_period(a, N)

    if r is None or r % 2 != 0:
        return None

    # 步骤3: 计算因子
    x = pow(a, r // 2, N)
    if (x + 1) % N == 0:
        return None

    p = math.gcd(x - 1, N)
    q = math.gcd(x + 1, N)

    if p * q == N and p > 1 and q > 1:
        return p, q
    return None

def factor_using_shor_method(N: int, attempts: int = 100):
    """
    使用 Shor 方法尝试分解 N（经典模拟，小 N 有效）
    注意：大 N 的周期查找在经典计算机上不可行
    """
    for i in range(attempts):
        a = random.randint(2, N - 2)
        result = shor_algorithm_classical(N, a)
        if result:
            p, q = result
            print(f"[+] N = {N} = {p} * {q} (found with a={a})")
            return p, q
    print(f"[-] Failed to factor {N} in {attempts} attempts")
    return None

# 示例
factor_using_shor_method(15)  # 经典易分解
factor_using_shor_method(21)
```

### 3.2 Grover 算法的经典模拟

```python
import math
import hashlib

def grover_search_simulation(target_hash: str, prefix: str = "flag", charset: str = "abcdefghijklmnopqrstuvwxyz0123456789", max_len: int = 4):
    """
    模拟 Grover 搜索（经典暴力搜索的平方根加速概念）

    参数:
        target_hash: 目标 MD5/SHA256 哈希值
        prefix: 输入前缀
        charset: 字符集
        max_len: 后缀最大长度
    返回:
        找到的原始字符串
    """
    import itertools

    total_space = sum(len(charset)**l for l in range(1, max_len + 1))
    print(f"[*] Total search space size: {total_space}")
    print(f"[*] Classical search: O(N) = {total_space} queries")
    print(f"[*] Grover search:    O(sqrt(N)) = {int(math.sqrt(total_space))} queries" if False else "")
    print(f"[*] Note: Cannot actually run Grover's on classical computer. Running brute force...")

    count = 0
    for length in range(1, max_len + 1):
        for combo in itertools.product(charset, repeat=length):
            count += 1
            candidate = prefix + ''.join(combo)
            h = hashlib.md5(candidate.encode()).hexdigest()
            if h == target_hash:
                print(f"[+] Found after {count} attempts: {candidate}")
                return candidate

    print("[-] Not found")
    return None

def grover_estimate_complexity(N: int) -> dict:
    """
    估算 Grover 算法对不同密码系统的实际影响
    """
    estimates = {
        'alg_name': [],
        'classical_bits': [],
        'grover_bits': [],
        'recommendation': [],
    }

    systems = [
        ('AES-128', 128, lambda n: 2**(n/2)),
        ('AES-192', 192, lambda n: 2**(n/2)),
        ('AES-256', 256, lambda n: 2**(n/2)),
        ('SHA-256 preimage', 256, lambda n: 2**(n/2)),
        ('SHA-256 collision', 128, lambda n: 2**(n/3)),  # 碰撞攻击可用量子算法但仅立方根加速
    ]

    for name, classical, complexity in systems:
        grover_bits = math.log2(complexity(classical))
        estimates['alg_name'].append(name)
        estimates['classical_bits'].append(classical)
        estimates['grover_bits'].append(int(grover_bits))
        if int(grover_bits) < 112:
            estimates['recommendation'].append('UNSAFE')
        elif int(grover_bits) < 128:
            estimates['recommendation'].append('MARGINAL')
        else:
            estimates['recommendation'].append('SAFE')

    return estimates

# 运行估算
estimates = grover_estimate_complexity(128)

for i in range(len(estimates['alg_name'])):
```

### 3.3 BB84 QKD 协议模拟

```python
import random
import secrets

class BB84Simulation:
    """BB84 QKD 协议的经典模拟"""

    def __init__(self, n_bits=256):
        self.n_bits = n_bits

    def simulate(self, eavesdropper=False):
        """
        运行 BB84 协议

        参数:
            eavesdropper: 是否有窃听者 Eve
        """
        # Alice 生成随机比特串和基选择
        alice_bits = [secrets.randbits(1) for _ in range(self.n_bits)]
        alice_bases = [secrets.randbits(1) for _ in range(self.n_bits)]
        # base=0 -> Z基 (|0>, |1>), base=1 -> X基 (|+>, |->)

        # 量子信道传输 (模拟)
        bob_bases = [secrets.randbits(1) for _ in range(self.n_bits)]

        # Eve 的攻击（若存在）
        eve_bases = []
        eve_measurements = []
        if eavesdropper:
            eve_bases = [secrets.randbits(1) for _ in range(self.n_bits)]
            # Eve 截获光子并测量（用自己随机选的基）
            eve_measurements = []
            for i in range(self.n_bits):
                if eve_bases[i] == alice_bases[i]:
                    eve_measurements.append(alice_bits[i])
                else:
                    eve_measurements.append(secrets.randbits(1))
            # Eve 根据自己测量结果发送新光子给 Bob（重传）

        # Bob 测量
        bob_measurements = []
        for i in range(self.n_bits):
            if eavesdropper:
                # 收到的是 Eve 重发的光子
                measured_bit = eve_measurements[i] if bob_bases[i] == eve_bases[i] else secrets.randbits(1)
            else:
                measured_bit = alice_bits[i] if bob_bases[i] == alice_bases[i] else secrets.randbits(1)
            bob_measurements.append(measured_bit)

        # 基比对（公共信道）
        matching_indices = [i for i in range(self.n_bits) if alice_bases[i] == bob_bases[i]]

        alice_sifted = [alice_bits[i] for i in matching_indices]
        bob_sifted = [bob_measurements[i] for i in matching_indices]

        # 误差率计算
        errors = sum(1 for a, b in zip(alice_sifted, bob_sifted) if a != b)
        error_rate = errors / len(matching_indices) if matching_indices else 1.0

        # 没有 Eve 时误差率应接近 0
        # 有 Eve 时误差率应接近 25%（Eve 随机基导致 50% 猜对基，猜错基时 50% 产生错误）
        # Eve 的错误引入率 = (1/2)*(1/2) = 25%

        result = {
            'raw_key_length': len(matching_indices),
            'errors': errors,
            'error_rate': error_rate,
            'eve_detected': error_rate > 0.05,  # 通常 5% 阈值
            'alice_sifted': alice_sifted,
            'bob_sifted': bob_sifted,
        }

        return result

    def demo(self):
        """演示有无窃听者的区别"""
        print("=" * 50)
        print("BB84 QKD Simulation")
        print("=" * 50)

        # 无窃听
        result_no_eve = self.simulate(eavesdropper=False)
        print(f"\n[Scenario 1: No Eavesdropper]")
        print(f"  Raw key bits: {result_no_eve['raw_key_length']}")
        print(f"  Error rate: {result_no_eve['error_rate']:.4f}")
        print(f"  Eve detected: {result_no_eve['eve_detected']}")

        # 有窃听
        result_with_eve = self.simulate(eavesdropper=True)
        print(f"\n[Scenario 2: With Eavesdropper (Eve)]")
        print(f"  Raw key bits: {result_with_eve['raw_key_length']}")
        print(f"  Error rate: {result_with_eve['error_rate']:.4f}")
        print(f"  Eve detected: {result_with_eve['eve_detected']}")

BB84Simulation(n_bits=1024).demo()
```

### 3.4 后量子密码 LWE 公钥加密简化

```python
import numpy as np
import secrets

class SimpleLWE:
    """
    简化的 LWE 公钥加密（教育用途，非生产安全）
    参数选择远低于安全要求
    """

    def __init__(self, n=256, q=3329, noise_std=2.0):
        """
        参数:
            n: 维数（安全级别: n >= 512 for 128-bit）
            q: 模数（常用 3329 for Kyber）
            noise_std: 噪声标准差
        """
        self.n = n
        self.q = q
        self.noise_std = noise_std

    def keygen(self):
        """密钥生成"""
        # 私钥 s ∈ Z_q^n（小系数）
        s = np.array([secrets.randbelow(3) - 1 for _ in range(self.n)], dtype=np.int64)

        # 公钥 A ∈ Z_q^{n×n}, b = A*s + e mod q
        A = np.array([[secrets.randbelow(self.q) for _ in range(self.n)] for _ in range(self.n)], dtype=np.int64)

        # 噪声 e
        e = np.array([self._sample_noise() for _ in range(self.n)], dtype=np.int64)

        # b = A*s + e mod q
        b = (A @ s + e) % self.q

        self.sk = s
        self.pk = (A, b)
        return (A, b), s

    def encrypt(self, pk, m_bit: int) -> tuple:
        """
        加密 1 个比特
        m_bit ∈ {0, 1}
        """
        A, b = pk
        # 随机向量 r（小系数）
        r = np.array([secrets.randbelow(3) - 1 for _ in range(self.n)], dtype=np.int64)

        # c1 = A^T * r mod q
        c1 = (A.T @ r) % self.q

        # c2 = b·r + ⌊q/2⌋*m mod q
        c2 = (np.dot(b, r) + (self.q // 2) * m_bit) % self.q

        return (c1, int(c2))

    def decrypt(self, sk, ct: tuple) -> int:
        """解密"""
        c1, c2 = ct
        s = sk

        # dec = c2 - c1·s mod q
        dec = (c2 - np.dot(c1, s)) % self.q

        # 判断：更靠近 0 还是 q/2
        if dec < self.q // 4 or dec > 3 * self.q // 4:
            return 0
        else:
            return 1

    def _sample_noise(self) -> int:
        """从离散高斯分布采样噪声（近似）"""
        # 简化：使用中心二项分布（Kyber 使用）
        noise = 0
        for _ in range(4):
            noise += secrets.randbits(1)
            noise -= secrets.randbits(1)
        return noise

# 演示
def demo_lwe():
    lwe = SimpleLWE(n=128, q=3329)  # 小参数仅演示
    pk, sk = lwe.keygen()
    print("[+] LWE Keygen complete")

    # 加密两个比特
    m1 = 0
    m2 = 1
    ct1 = lwe.encrypt(pk, m1)
    ct2 = lwe.encrypt(pk, m2)

    # 解密
    dec1 = lwe.decrypt(sk, ct1)
    dec2 = lwe.decrypt(sk, ct2)

    print(f"[+] m1={m1}, decrypted={dec1} -> {'OK' if m1 == dec1 else 'FAIL'}")
    print(f"[+] m2={m2}, decrypted={dec2} -> {'OK' if m2 == dec2 else 'FAIL'}")

demo_lwe()
```

## 4. 常见误区与注意事项

1. **量子计算机尚不存在**：目前最大的商用量子计算机仅约 1000 qubit（IBM 2023），且噪声较大。破解 RSA-2048 需要约 4000 个逻辑 qubit（数百万个物理 qubit）。
2. **Grover 不能暴力破解所有密码**：Grover 仅对无结构的搜索有效。AES 有代数结构，但从量子角度看仍有效地呈现无结构（故常引用 O(√N) 加速）。
3. **QKD 需要已认证的经典信道**：QKD 的主信道是量子态的，但基比对和错误校正仍需经典已认证信道。若无认证，中间人攻击仍可行。
4. **后量子 ≠ 免疫所有量子攻击**：PQC 是基于"当前没有已知的高效量子算法可解这些数学问题"（如 LWE、SIS 等）。但未来可能发现更高效的量子算法。
5. **SIKE 被破解**：SIKE（基于超奇异同源的密钥交换）在 NIST Round 4 中被完全破解（Castryck-Decru 2022），说明了后量子密码研究的动态性。
6. **LWE 的参数选择**：错误的 LWE 参数（如错误分布方差过大、维度过低）可能导致经典格攻击成功。
7. **混合密码系统**：当前最佳实践是"混合"：同时使用经典 ECDH + 后量子 KEM（Kyber），如 TLS 1.3 的 hybrid key exchange。

## 6. 相关知识点

- **NIST PQC 竞赛**：Round 1 (2017)、Round 2 (2019)、Round 3 (2020)、Final (2022)、Round 4 (ongoing)
- **Kyber**：基于 Module-LWE 的 KEM（IND-CCA2 安全、ML-KEM-768 标准）
- **Dilithium**：基于 Module-LWE/SIS 的数字签名（ML-DSA-44/65/87）

- **GeMSS**：被破解的多变量签名方案
- **PICNIC**：基于 MPC-in-the-head 的零知识证明签名（未入选）
- **Quantum Random Oracle Model (QROM)**：后量子安全证明的标准模型
- **Open Quantum Safe (OQS)**：后量子密码开源实现库（liboqs）
- **QKD 网络**：中国的京沪干线（2000km QKD 网络）
