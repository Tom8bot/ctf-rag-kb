# 02 - 音频与视频隐写

## 1. 概述

音频隐写（Audio Steganography）在CTF MISC中虽然出题频率低于图片隐写，但复杂度往往更高。挑战者需要分析波形、频谱、相位、时频域等多维特征。常见手法包括：频谱图嵌入文本/图像、LSB替换、回声隐藏、相位编码、扩频隐写、DTMF拨号音编码、SSTV（慢扫描电视）图像传输。

断网场景下的核心工具链：**Audacity**（图形化频谱/波形分析）、**Sonic Visualiser**（专业声学分析）、**SoX**（音频处理）、**Python (scipy/numpy/librosa)**。

## 2. 核心原理

### 2.1 数字音频基础

```
采样率 (Sample Rate): 每秒采样次数，常见44.1kHz（CD音质）、48kHz
位深度 (Bit Depth): 每个采样的比特数，常见16bit、24bit
声道数 (Channels): 1(单声道) / 2(立体声)
采样值范围: -2^(bit_depth-1) 到 2^(bit_depth-1)-1
```

WAV文件结构：
```
[RIFF Header 44字节]
  - ChunkID: "RIFF" (4B)
  - ChunkSize: 文件总大小-8 (4B)
  - Format: "WAVE" (4B)
  - Subchunk1ID: "fmt " (4B)
  - Subchunk1Size: 16 (4B)
  - AudioFormat: 1 = PCM (2B)
  - NumChannels: 1或2 (2B)
  - SampleRate: 44100等 (4B)
  - ByteRate: 每秒钟字节数 (4B)
  - BlockAlign: 每帧字节数 (2B)
  - BitsPerSample: 16等 (2B)
  - Subchunk2ID: "data" (4B)
  - Subchunk2Size: 数据长度 (4B)
[数据部分]
```

### 2.2 频谱隐写原理

短时傅里叶变换（Short-Time Fourier Transform, STFT）将时域信号转换为频域：

```
STFT: x[n] -> X[ω, τ]
其中 ω = 频率, τ = 时间窗口
```

频谱图（Spectrogram）就是|X[ω, τ]|^2的可视化。出题人在特定频率/时间位置嵌入能量，这些能量在频谱图上形成可视的文字或编码图案。

常见频谱隐写模式：
- **频率键控（FSK）**：用两个频率表示0和1
- **频段文本**：直接在频谱图中写字（Sonic Visualiser / Audacity 频谱视图可见）
- **DTMF双音多频**：用两个频率组合编码0-9、A-D、*、#

### 2.3 LSB音频隐写

与图片LSB类似，将每个采样值的LSB位替换为秘密信息。16bit音频每个采样有2字节LSB空间（每声道）。

容量估算：`44100 Hz × 2 channels × 1 bit/sample = 88200 bit/s ≈ 11 KB/s`

如果采样率为44100，一个10秒的立体声WAV可嵌入约110KB数据。

### 2.4 回声隐藏（Echo Hiding）

在原始信号上叠加延迟信号（回声），通过回声的延迟时间编码信息：
- 延迟1ms = bit 0
- 延迟2ms = bit 1
使用倒谱分析（Cepstrum Analysis）可检测和提取。

### 2.5 SSTV（慢扫描电视）

SSTV（Slow Scan Television）通过音频信号传输图像（如NASA卫星、国际空间站使用）。在CTF中，SSTV音频常以WAV/MP3格式给出，需要解码成图像来查看flag。

常见SSTV模式：
| 模式   | 传输时间    | 分辨率    | 色彩     |
|--------|-------------|-----------|----------|
| Scottie 1 | 110s    | 320x256   | RGB      |
| Scottie 2 | 71s     | 320x256   | RGB      |
| Martin 1  | 114s    | 320x256   | RGB      |
| Martin 2  | 58s     | 320x256   | RGB      |
| Robot 36  | 36s     | 320x240   | YUV      |
| PD120     | 120s    | 640x496   | RGB      |

### 2.6 MP3帧结构

MP3文件由一系列帧组成，每帧前4字节为同步头：
```
帧同步头 (32bit):
  AAAAAAAA AAABBCCD EEEEFFGH IIJJKLMM
  A: 0xFFE (11bit sync, 全1)
  B: MPEG版本 (2bit)  00=MPEG2.5 01=保留 10=MPEG2 11=MPEG1
  C: Layer (2bit)     01=Layer3 10=Layer2 11=Layer1
  D: 保护位 (1bit)    0=CRC16
  E: 比特率索引 (4bit)
  F: 采样率索引 (2bit)
  G: 填充位 (1bit)
  H: 私有位 (1bit)
  ...
```

MP3隐写可在以下位置嵌入数据：
- ID3v1标签（文件末尾128字节）
- ID3v2标签（文件开头，可变长）
- 每帧的私有位（private bit, 1b/frame）
- 每帧的Ancillary data（辅助数据区）
- 帧间填充区域

### 3.4 Python音频处理脚本

**LSB音频提取脚本（WAV）**:
```python
import struct
import wave

def extract_lsb_wav(wav_path, output_path, bit_plane=0, channels=None):
    """
    从WAV文件的LSB提取隐藏数据
    bit_plane: 0=LSB, 1=第二低位, ...
    channels: None(所有通道), 0(左声道), 1(右声道)
    """
    with wave.open(wav_path, 'rb') as w:
        n_channels = w.getnchannels()
        sampwidth = w.getsampwidth()
        n_frames = w.getnframes()
        frames = w.readframes(n_frames)
    
    # 解包采样值
    fmt = {1: 'B', 2: '<h', 4: '<i'}[sampwidth]
    samples = struct.unpack(fmt * n_channels * n_frames, frames[:n_frames * n_channels * sampwidth])
    
    bits = []
    for i, s in enumerate(samples):
        ch = i % n_channels
        if channels is not None and ch not in (channels if isinstance(channels, tuple) else (channels,)):
            continue
        bits.append((s >> bit_plane) & 1)
    
    byte_arr = bytearray()
    for i in range(0, len(bits) - 7, 8):
        byte_arr.append(sum(bits[i+j] << (7-j) for j in range(8)))
    
    with open(output_path, 'wb') as f:
        f.write(bytes(byte_arr))
    print(f'Extracted {len(byte_arr)} bytes -> {output_path}')
```

**DTMF解码脚本**:
```python
import numpy as np
from scipy.signal import find_peaks
from scipy.io import wavfile

# DTMF频率表
DTMF_TABLE = {
    (697, 1209): '1', (697, 1336): '2', (697, 1477): '3', (697, 1633): 'A',
    (770, 1209): '4', (770, 1336): '5', (770, 1477): '6', (770, 1633): 'B',
    (852, 1209): '7', (852, 1336): '8', (852, 1477): '9', (852, 1633): 'C',
    (941, 1209): '*', (941, 1336): '0', (941, 1477): '#', (941, 1633): 'D',
}

def decode_dtmf(wav_path, segment_duration=0.05):
    """
    解码DTMF音频信号
    segment_duration: 每段分析窗口(秒), DTMF最短50ms
    """
    rate, data = wavfile.read(wav_path)
    if data.ndim > 1:
        data = data.mean(axis=1)  # 转为单声道
    
    results = []
    seg_samples = int(rate * segment_duration)
    
    for start in range(0, len(data) - seg_samples, seg_samples // 2):  # 50%重叠
        segment = data[start:start + seg_samples]
        spectrum = np.abs(np.fft.rfft(segment * np.hanning(len(segment))))
        freqs = np.fft.rfftfreq(len(segment), 1/rate)
        
        # 找峰值频率
        peaks_idx, _ = find_peaks(spectrum, height=np.max(spectrum) * 0.3)
        peak_freqs = freqs[peaks_idx]
        
        # 匹配DTMF表格
        for (f1, f2), key in DTMF_TABLE.items():
            if any(abs(pf - f1) < 20 for pf in peak_freqs) and \
               any(abs(pf - f2) < 20 for pf in peak_freqs):
                results.append(key)
                break
    # 去重相邻相同按键
    return ''.join(r for i, r in enumerate(results) if i == 0 or r != results[i-1])
```

## 4. 常见误区与注意事项

### 误区1: 只看波形不看频谱
波形图只能看到振幅信息，频率域信息完全丢失。**频谱图是第一优先级检查项。**

### 误区2: 频谱图参数不当
Audacity频谱图默认参数可能无法显示隐藏信息。务必调整：Window Size (推荐1024-8192), Window Type (Hanning), Scale (dB vs Linear), 频率范围。

### 误区3: 忽略超声波和次声波
人耳可听频率范围为20Hz-20kHz，但WAV可储存更高频率的超声波（如Nyquist频率的一半 = 采样率/2）。用频谱图检查20kHz+范围。

### 误区4: 忽视声道差异
左右声道可能包含不同信息，或一个声道藏有数据。务必分离声道分别检查。

### 误区5: SSTV参数未尝试多模式
SSTV有多种编码模式（Scottie、Martin、Robot、PD等），解码器不会自动识别。需要尝试不同模式或使用信号特征推测。

### 误区6: 倒放不容忽视
音频倒放可能揭示隐藏的语音信息。**Effect -> Reverse在Audacity中一键操作，做一下不亏。**

## 6. 相关知识点

### 6.1 相位编码（Phase Coding）
将秘密信息编码到频域各分量的相位中。人耳对相位变化不敏感，检测需要相位谱分析。`scipy.signal.spectrogram`可获取相位。

### 6.2 扩频隐写（Spread Spectrum Steganography）
将窄带秘密信号分布在宽带载波上，类似CDMA通信原理。抗噪能力强，但需要原始载波对比。

### 6.3 双声道互减为零法
如果左右声道波形完全相同但相位相反（反相），单声道相加后为零（无声）。但如果反相不完全，残差即为隐藏信号。Audacity中Mix and Render可同时播放两声道。

### 6.4 音频隐写检测特征
- 直方图异常：LSB嵌入会改变采样值分布，使相邻值出现频率趋近
- 倒谱异常：回声隐藏会使倒谱出现离散尖峰
- 噪声水平：正常音频的高频段有特征分布，人工嵌入信息可能增加高频噪声

### 6.5 视频隐写简介
- **帧间隐写**：在视频某帧插入包含flag的图像
- **运动矢量隐写**：修改编码宏块的运动矢量LSB
- **容器级隐写**：MKV/MP4字幕轨、章节标记中嵌入数据
- 工具：`ffmpeg`分离每帧 `ffmpeg -i video.mp4 frame_%04d.png`

### 6.6 小参数模型辅助
1. **描述频谱图形状给模型**：如"频谱图中频率3k-4kHz范围内有规律的横条纹"，模型可推断编码方案
2. **音频性质判别**：如10秒WAV大小4MB却无声，让模型分析可能原因
3. **编码序列识别**：从DTMF/FSK提取出的数字序列，可让模型设计解码逻辑の脚本
