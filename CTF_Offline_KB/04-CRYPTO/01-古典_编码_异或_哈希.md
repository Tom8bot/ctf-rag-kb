# 古典密码 / 编码 / XOR / 哈希

---

## 1. 开局识别流程

```text
先看字符集 -> 看长度 -> 看是否分组 -> 看是否重复模式 -> 看是否有已知前缀 -> 再判断编码/异或/古典/哈希
```

### 1.1 字符集判断
- `[0-9a-fA-F]`：hex
- `[A-Za-z0-9+/=]`：base64
- `[A-Z2-7=]`：base32
- 明显字母表偏移：古典替换/移位
- 可打印度低：二进制、xor、压缩、加密

### 1.2 已知前缀
CTF 高频：
- `flag{`
- `ctf{`
- `0x`
- `http`
- 文件头：PNG、ZIP、PDF、ELF

---

## 2. 编码题

## 2.1 常见编码
- hex
- base64 / base32 / base58 / base85
- URL 编码
- HTML entity
- uuencode / quoted-printable
- 栅栏 / rail fence / rot13（偏古典）

## 2.2 判断技巧
- base64 长度常为 4 的倍数
- base32 多大写和 `=`
- 十六进制长度是 2 的倍数
- 多层编码常表现为“解一层后还是可疑编码串”

## 2.3 多层编码处理
### 通用策略
1. 先尝试最像的一层
2. 每解一层都检查：是否变得更像文本/文件头/flag 格式
3. 防止过度解码

### 小模型要点
不要拿到一串就盲目套十几层。  
每一步都问：**这一步结果更合理了吗？**

## 3. 古典密码

## 3.1 Caesar / Rot
- 固定偏移
- 频率结构保留
- 先爆 26 种

## 3.2 Vigenere
- 周期性 key
- 可用 Kasiski / 重合指数估 key 长
- CTF 也常直接已知 key 或 key 很短

## 3.3 Playfair / Hill / 栅栏 / 置换
- 更偏题感，不要死背，先识别是否是“字符重排”还是“字符替换”

### 通用思维
- **替换类**：字符集合基本不变，顺序和频率模式在
- **置换类**：字符内容不变，位置变了

## 4. XOR

## 4.1 单字节 XOR
### 特征
- 密文可打印度低
- 用一个字节异或整个串
- 爆破 256 很容易

### 最小脚本
```python
import string
c = bytes.fromhex('...')
for k in range(256):
    p = bytes([x ^ k for x in c])
    if sum(chr(i) in string.printable for i in p) > len(c)*0.9:
        print(k, p)
```

## 4.2 重复 key XOR
### 特征
- key 周期重复
- 已知前缀可拖出 key
- 不同位置同周期字节有相关性

### 常见方法
- 猜 key 长
- 按列拆分
- 每列当单字节 XOR 解

### key 长判断
- 归一化汉明距离
- 重复块/相似性

## 4.3 已知前缀拖拽
若明文开头可能是 `flag{`：
```python
key_prefix = xor(cipher[:5], b'flag{')
```
再检查 key 是否周期重复。

## 4.4 多次 one-time pad 重用
### 特征
- 多个密文由同一 keystream 异或得到
- `c1 ^ c2 = p1 ^ p2`

### 解法
- 密文两两异或
- 猜空格、已知词、flag 格式
- crib dragging

## 5. Hash 题

## 5.1 识别
- 32 hex：可能 MD5
- 40 hex：SHA1
- 64 hex：SHA256
- 但 CTF 中长度不能绝对说明算法

## 5.2 常见题型
- 纯爆破（弱口令、短字符串）
- 长度扩展攻击
- 弱比较 / 0e
- 哈希碰撞题（更多偏脑洞）
- 自定义 hash 逆向

## 5.3 长度扩展攻击
### 适用前提
- 结构是 `hash(secret || data)`
- 算法是 MD5 / SHA1 / SHA256 这类 Merkle–Damgård 结构
- 已知原始 hash 和 data，未知 secret 长度范围

### 目标
构造 `data || pad || append` 对应的新合法 hash。

### 不适用
- `hash(data || secret)`
- HMAC

## 5.4 PHP 弱比较 0e
### 条件
- 使用 `==` 比较 hash 字符串
- 两边都形如科学计数法 0e...

### 典型理解
`"0e123" == "0e456"` 在弱类型下都变 0。

## 6. 自定义加密 / 混淆

### 高频组成件
- xor
- 加减
- rotate
- swap
- index-based permutation
- base 编码

### 解法
- 拆成每一步
- 判断是否可逆
- 不可逆处爆破小范围

## 7. 文件头与已知明文攻击

### 常见文件头
- PNG: `89 50 4E 47 0D 0A 1A 0A`
- ZIP: `50 4B 03 04`
- PDF: `%PDF`
- ELF: `7f 45 4c 46`

### 用途
- XOR key 恢复
- 流密码 keystream 恢复
- 判断解密是否正确

## 8. 最短作战模板

```text
1. 先识别编码和字符集
2. 再看是否像 xor / 古典 / hash
3. XOR 优先试单字节、重复 key、已知前缀
4. 多层题每一步都检查“结果是否更合理”
5. 哈希题先问：爆破？长度扩展？弱比较？自定义？
```
