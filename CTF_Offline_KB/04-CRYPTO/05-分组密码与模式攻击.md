# 分组密码与模式攻击

## 1. 概述

分组密码（Block Cipher）是现代对称加密的基石。AES 和 DES 是最常见的分组密码，它们在固定大小的数据块（AES: 128bit, DES: 64bit）上加密。

但由于明文长度不一，需要**分组密码工作模式**（ECB, CBC, CTR, GCM 等）。**密码模式和实现漏洞**是 CTF 攻击的主要切入点，而非破解密码算法本身。

核心攻击面：
- **ECB**：确定性，可识别相同明文块（ECB Cut-and-Paste）
- **CBC**：IV 可预测、字节翻转攻击、Padding Oracle Attack
- **CTR**：nonce 重用导致流密码密钥重用
- **GCM**：nonce 重用的灾难性后果

## 2. 核心原理（含数学推导）

### 2.1 分组密码工作模式的形式化

**ECB (Electronic Codebook)**：
`C_i = E_K(P_i)` （每块独立加密，相同明文产生相同密文）

**CBC (Cipher Block Chaining)**：
`C_0 = IV`
`C_i = E_K(P_i ⊕ C_{i-1})`
解密：`P_i = D_K(C_i) ⊕ C_{i-1}`

**CTR (Counter)**：
`C_i = P_i ⊕ E_K(Nonce || Counter_i)`

**OFB (Output Feedback)**：
`O_0 = IV`
`O_i = E_K(O_{i-1})`
`C_i = P_i ⊕ O_i`

### 2.2 CBC 字节翻转攻击原理

由解密公式 `P_i = D_K(C_i) ⊕ C_{i-1}`：

翻转 `C_{i-1}` 的某一位，会精确翻转解密后 `P_i` 的对应位！
- 因为 `D_K(C_i)` 不受 `C_{i-1}` 的影响（C_i 不变）
- XOR 的性质：翻转 `C_{i-1}` 的第 j bit，则 `P_i` 的第 j bit 翻转

攻击者可以精确控制 `P_i` 的任意字节（通过翻转 `C_{i-1}` 的对应字节）。

**代价**：`C_{i-1}` 被破坏，解密后 `P_{i-1}` 是乱码（垃圾数据）。

### 2.3 Padding Oracle Attack 原理

PKCS#7 填充：
- 缺 1 字节填充 `0x01`
- 缺 2 字节填充 `0x02 0x02`
- 缺 N 字节填充 `0x0N * N`
- 缺 0 字节则填充整个块（16 个 `0x10`）

Padding Oracle Attack 的核心：利用服务器是否返回"填充错误"来判断猜测是否正确。

对于 CBC 模式的最后一个块：
1. 伪造 `C_{i-1}`，猜测最后 1 字节使 `P_i` 的最后 1 字节为 `0x01`
2. 若服务器返回"OK"（填充正确），说明猜测正确
3. 由此推算出 `D_K(C_i)` 的最后 1 字节
4. 通过 `P_i = D_K(C_i) ⊕ C_{i-1}` 恢复明文

### 2.4 字节翻转攻击的数学推导

CBC 解密第 i 块：`P_i = D_K(C_i) ⊕ C_{i-1}`

设我们想将 `P_i` 变为 `P_i'`：
`P_i' = D_K(C_i) ⊕ C_{i-1}'`
`C_{i-1}' = P_i' ⊕ D_K(C_i) = P_i' ⊕ (P_i ⊕ C_{i-1})`
`C_{i-1}' = P_i ⊕ P_i' ⊕ C_{i-1}`

因此，要修改 `P_i` 为 `P_i'`，只需将 `C_{i-1}` 替换为 `C_{i-1} ⊕ P_i ⊕ P_i'`

### 3.1 ECB Cut-and-Paste 攻击

```python
from Crypto.Cipher import AES
from Crypto.Util.Padding import pad, unpad
import os

def ecb_cut_and_paste_example():
    """
    ECB Cut-and-Paste 攻击演示
    场景：服务器将 (user_data + admin_flag) 一起加密
    攻击者通过拼接密文块伪造 admin 身份
    """
    key = os.urandom(16)
    cipher = AES.new(key, AES.MODE_ECB)

    # 正常加密格式: email=xxx&uid=xxx&role=user
    # 我们想要 role=admin

    # 步骤1: 获取 email 足够长的合法密文，使得 "role=" 独占一个块
    # 提交 email = "A"*10 + "admin" + padding（使 "admin" 对齐块边界）
    # 这样第三块就是 E_K("admin" + padding)

    # 步骤2: 注册一个用户，获取加密后的 role=user 块
    # 提交 email 使 "user" 在单独块

    # 步骤3: 将含有 "admin" 的块替换到含有 "user" 的块位置

    # 构造
    # email = "A"*(blocksize - len("email=")) + "admin" + pad(b"", blocksize)
    BS = 16
    craft_email = b"A" * (BS - len(b"email=")) + b"admin" + b"\x0b" * 11
    # 提交后：
    # 块0: "email=AAAAAAAAAA"
    # 块1: "admin\x0b\x0b\x0b\x0b\x0b\x0b\x0b\x0b\x0b\x0b\x0b"
    # 块2: "&uid=xxx&role=user"  (可能再分块)

    # 如果知道 role 的位置：
    # 将块1 (admin块) 替换到 role 的位置

    # AES-ECB 加密
    payload = b"email=" + craft_email + b"&uid=10&role=user"
    ct = cipher.encrypt(pad(payload, BS))

    # Cut-and-Paste: 将第二个密文块替换到 role 位置
    admin_block = ct[BS:2*BS]
    crafted_ct = ct[:4*BS] + admin_block  # 假设 role 在第5块
    print(f"[+] Crafted ciphertext (cut-and-paste): {crafted_ct.hex()}")

    return crafted_ct
```

### 3.2 CBC 字节翻转攻击完整实现

```python
from Crypto.Cipher import AES
from Crypto.Util.Padding import pad, unpad
import os

def cbc_bit_flip_attack(ciphertext: bytes, iv: bytes, key: bytes, known_plaintext: str, target_text: str, block_offset: int = 0):
    """
    CBC 字节翻转攻击
    修改密文使解密后的明文某处变为目标文本

    参数:
        ciphertext: 原始密文
        iv: 原始 IV
        key: 加密密钥（若未知，需要 oracle）
        known_plaintext: 已知的原始明文
        target_text: 想要的目标文本
        block_offset: 目标文本所在的块偏移（0-based）
    """
    BS = 16
    target_bytes = target_text.encode()
    known_bytes = known_plaintext[block_offset*BS:block_offset*BS+len(target_text)].encode()

    assert len(target_bytes) == len(known_bytes), "目标文本和原始文本长度必须一致"

    # 计算异或差异
    xor_diff = bytes(a ^ b for a, b in zip(known_bytes, target_bytes))

    # 修改前一个块（若是第0块则修改IV）
    if block_offset == 0:
        # 修改 IV
        new_iv = bytes(iv[i] ^ xor_diff[i] for i in range(len(xor_diff))) + iv[len(xor_diff):]
        cipher = AES.new(key, AES.MODE_CBC, iv=new_iv)
        return new_iv, ciphertext
    else:
        # 修改前一个密文块
        prev_block_start = (block_offset - 1) * BS
        new_ct = bytearray(ciphertext)
        for i in range(len(xor_diff)):
            new_ct[prev_block_start + i] ^= xor_diff[i]
        return iv, bytes(new_ct)

# 使用示例
def cbc_bit_flip_demo():
    key = os.urandom(16)
    iv = os.urandom(16)

    plaintext = b"flag=user;admin=False;session=1234"
    cipher = AES.new(key, AES.MODE_CBC, iv=iv)
    ct = cipher.encrypt(pad(plaintext, 16))

    # 目标：将 "admin=False" 改为 "admin=True_"
    # "False" 在第二个块（块1），修改第一个密文块（块0）
    target = "True_"   # 长度5
    offset_in_block = plaintext.index(b"False")
    block_num = offset_in_block // 16

    # 修改前一个块中对应位置的字节
    xor_diff = bytes(a ^ b for a, b in zip(b"False", b"True_"))
    prev_block_start = max(0, (block_num - 1) * 16)

    new_ct = bytearray(ct)
    for i in range(len(xor_diff)):
        new_ct[prev_block_start + offset_in_block % 16 + i] ^= xor_diff[i]

    # 解密验证（前一个块会被破坏）
    cipher2 = AES.new(key, AES.MODE_CBC, iv=iv)
    decrypted = unpad(cipher2.decrypt(bytes(new_ct)), 16)
    print(f"[+] Modified plaintext: {decrypted}")
    # 输出中  部分 "admin=True" 且前一块为乱码

cbc_bit_flip_demo()
```

### 3.3 Padding Oracle Attack 完整实现

```python
from pwn import *
import os

def padding_oracle_attack_block(ciphertext: bytes, iv: bytes, oracle_func, block_idx: int = 0) -> bytes:
    """
    Padding Oracle Attack 解密单个密文块

    参数:
        ciphertext: 完整密文（含 IV）
        iv: 初始向量
        oracle_func: Oracle 函数，输入 bytes 返回 True/False (填充正确/错误)
        block_idx: 要解密的块索引

    返回: 解密后的明文块
    """
    BS = 16

    # 将密文分成块
    blocks = [ciphertext[i:i+BS] for i in range(0, len(ciphertext), BS)]

    if block_idx == 0:
        prev_block = iv
    else:
        prev_block = blocks[block_idx - 1]

    target_block = blocks[block_idx]
    decrypted = bytearray(BS)
    test_iv = bytearray(BS)

    # 从最后一个字节到第一个字节逐个破解
    for pad_byte in range(1, BS + 1):
        # 设置已知解密字节对应的测试 IV（确保填充正确）
        for k in range(1, pad_byte):
            test_iv[BS - k] = decrypted[BS - k] ^ pad_byte

        # 暴力猜解当前字节
        found = False
        for guess in range(256):
            test_iv[BS - pad_byte] = guess
            test_payload = bytes(test_iv) + target_block

            if oracle_func(test_payload):
                # 填充正确，推算明文字节
                decrypted[BS - pad_byte] = guess ^ pad_byte
                found = True

                # 验证：对于 pad_byte=1，修改前一字节确认不是误报
                if pad_byte == 1:
                    test_iv[BS - 2] ^= 1
                    if not oracle_func(bytes(test_iv) + target_block):
                        # 确实是真 padding
                        test_iv[BS - 2] ^= 1
                    else:
                        found = False
                break

        if not found:
            print(f"[-] Failed to find byte {pad_byte}")
            return None

        print(f"[+] Block {block_idx}, byte {-pad_byte}: 0x{decrypted[BS - pad_byte]:02x} ({chr(decrypted[BS - pad_byte]) if 32 <= decrypted[BS - pad_byte] < 127 else '?'})")

    # 解密结果 = D_K(target_block) ⊕ prev_block
    plaintext = bytes(a ^ b for a, b in zip(decrypted, prev_block))
    return plaintext

def padding_oracle_decrypt_all(ciphertext: bytes, iv: bytes, oracle_func) -> bytes:
    """
    使用 Padding Oracle 解密全部密文
    """
    BS = 16
    blocks = [ciphertext[i:i+BS] for i in range(0, len(ciphertext), BS)]
    plaintext = b""

    for i in range(len(blocks)):
        pt_block = padding_oracle_attack_block(
            ciphertext=ciphertext,
            iv=iv,
            oracle_func=oracle_func,
            block_idx=i
        )
        if pt_block:
            plaintext += pt_block
            print(f"[+] Block {i}: {pt_block}")

    return plaintext

# 本地 Oracle 示例
def local_oracle(ciphertext_with_iv: bytes) -> bool:
    """本地 Padding Oracle（CBC 模式）"""
    key = b"0123456789abcdef"  # 模拟的密钥（攻击者不知道）
    BS = 16
    iv = ciphertext_with_iv[:BS]
    ct = ciphertext_with_iv[BS:]

    try:
        cipher = AES.new(key, AES.MODE_CBC, iv=iv)
        decrypted = cipher.decrypt(ct)
        unpad(decrypted, BS)  # 若填充错误会抛出异常
        return True
    except ValueError:
        return False
```

### 3.4 CTR nonce 重用攻击

```python
def ctr_nonce_reuse_attack(c1: bytes, c2: bytes, p1: bytes) -> bytes:
    """
    CTR 模式下 nonce 重用攻击
    已知一组密文-明文对，恢复另一组明文
    """
    # c1 = p1 ⊕ keystream
    # c2 = p2 ⊕ keystream
    # => p2 = c1 ⊕ c2 ⊕ p1
    keystream_len = min(len(c1), len(c2), len(p1))
    p2 = bytes(c1[i] ^ c2[i] ^ p1[i] for i in range(keystream_len))
    return p2

def ctr_crib_drag(c1: bytes, c2: bytes, crib: bytes, position: int = 0) -> str:
    """
    CTR crib dragging（已知部分明文拖拽）
    尝试在密文中寻找 crib 的匹配位置
    """
    for offset in range(len(c1) - len(crib) + 1):
        candidate = bytes(
            c1[offset + i] ^ c2[offset + i] ^ crib[i]
            for i in range(len(crib))
        )
        try:
            text = candidate.decode('ascii')
            if all(c.isprintable() for c in text):
                print(f"[+] Offset {offset}: {text}")
                return text
        except:
            continue
    return None
```

### 3.6 AES 加密/解密（feat. 模式识别）

```python
from Crypto.Cipher import AES
from Crypto.Util.Padding import pad, unpad

def detect_ecb(ciphertext: bytes, block_size: int = 16) -> bool:
    """
    检测密文是否由 ECB 模式生成
    ECB 特征：相同明文块产生相同密文块
    """
    blocks = [ciphertext[i:i+block_size] for i in range(0, len(ciphertext), block_size)]
    return len(blocks) != len(set(blocks))  # 有重复块则很可能是 ECB

def detect_block_size(oracle_encrypt) -> int:
    """
    探测分组密码的块大小
    不断增加输入直到密文长度跳变
    """
    base_len = len(oracle_encrypt(b""))
    for i in range(1, 64):
        test_len = len(oracle_encrypt(b"A" * i))
        if test_len > base_len:
            return test_len - base_len
    return 16  # 默认 16

def solve_aes_ecb_byte_by_byte(oracle_encrypt, block_size: int = 16) -> bytes:
    """
    逐字节破解 ECB 加密的未知字符串
    当 oracle 将用户输入和未知字符串拼接后加密时
    """
    # 1. 确定未知字符串的长度
    base_len = len(oracle_encrypt(b""))
    unknown_len = None
    for i in range(1, block_size + 1):
        test_len = len(oracle_encrypt(b"A" * i))
        if test_len > base_len:
            unknown_len = base_len - i
            break
    if unknown_len is None:
        unknown_len = base_len - block_size

    # 2. 逐字节恢复
    recovered = b""
    for byte_pos in range(unknown_len):
        block_idx = byte_pos // block_size
        byte_in_block = byte_pos % block_size

        # 构造前缀使目标字节到达块的最后一个位置
        prefix_len = block_size - byte_in_block - 1
        prefix = b"A" * prefix_len

        # 获取目标的当前密文映射
        target_ct = oracle_encrypt(prefix)
        target_block_start = block_idx * block_size
        target_block = target_ct[target_block_start:target_block_start + block_size]

        # 暴力猜解
        for guess in range(256):
            guess_prefix = prefix + recovered + bytes([guess])
            guess_ct = oracle_encrypt(guess_prefix)
            guess_block = guess_ct[:block_size]
            if guess_block == target_block:
                recovered += bytes([guess])
                print(f"[+] Recovered byte {byte_pos}: 0x{guess:02x} '{chr(guess) if 32 <= guess < 127 else '?'}' -> {recovered}")
                break
        else:
            print(f"[-] Failed to recover byte at position {byte_pos}")
            break

    return recovered
```

## 4. 常见误区与注意事项

1. **分组模式不是加密算法**：ECB/CBC/CTR 是工作模式，AES/DES 是密码算法，不要混淆。
2. **IV 的生成**：CBC 的 IV 必须是随机且不可预测的。IV 可预测（如计数器）会导致类似于 ECB 的信息泄露。
3. **Padding Oracle 的攻击复杂度**：最差情况 256*BS 次 oracle 查询解密一个块，实际可通过优化减少。
4. **CTR 的 nonce 必须唯一**：nonce + counter 的组合不能重复使用，否则等同于 OTP 重用。
5. **CBC 字节翻转的代价**：修改 `C_{i-1}` 可以控制 `P_i`，但会完全破坏 `P_{i-1}` 的内容。
6. **PKCS#7 vs PKCS#1**：PKCS#7 用于对称加密填充，PKCS#1 用于 RSA 填充，它们是不同的标准。
7. **GCM 的 nonce 重用 = 灾难**：不仅泄露 keystream，还可能泄露认证密钥 H（可伪造任意消息的认证标签）。
8. **Python 的 Crypto 库**：`pycryptodome` 不强制用户正确使用模式（不会自动生成安全 IV），需手动处理。

## 5. 实战示例

**场景**：服务器使用 AES-CBC 加密用户输入的 token，token 格式为 `{"user":"guest","role":"user"}`。攻击目标是伪造 token 使角色变为 admin。

```python
import requests
import json
import base64
from Crypto.Util.Padding import pad

def forge_admin_token(encrypt_oracle, decrypt_oracle=None):
    """使用 CBC 字节翻转将 'user' 改为 'admin'"""
    BS = 16

    # 1. 获取合法 token
    guest_token_pt = b'{"user":"guest","role":"user"}'
    guest_token_ct = encrypt_oracle(guest_token_pt)

    # 2. 计算需要修改的位置
    target = b"admin"
    original = b"user"

    # 在 JSON 中，user 在 role 值中
    import re
    match = re.search(b'"role":"(.+?)"', guest_token_pt)
    role_start = match.start(1)
    block_num = role_start // BS
    offset_in_block = role_start % BS

    # 3. 修改前一个密文块
    prev_block_start = max(0, (block_num - 1) * BS)
    new_ct = bytearray(guest_token_ct)

    for i in range(len(target)):
        if offset_in_block + i < BS:
            new_ct[prev_block_start + offset_in_block + i] ^= (original[i] ^ target[i])

    return bytes(new_ct)
```

## 6. 相关知识点

- **DES/3DES**：56 位密钥，可通过暴力破解/中途相遇攻击
- **Feistel 网络**：DES 采用的对称结构（加解密结构相同，只需逆序轮密钥）
- **AES 结构**：SubBytes -> ShiftRows -> MixColumns -> AddRoundKey（SPN 结构）
- **AES 攻击**：Square 攻击、不可能差分攻击、相关密钥攻击（理论层面）
- **GCM 认证加密**：CTR 加密 + GHASH 认证，nonce 重用导致认证密钥泄露
- **CCM 模式**：CBC-MAC + CTR（另一认证加密方案）
- **密钥编排**：AES 和 DES 的密钥扩展方案（逆向时需要理解）
- **白盒密码 (WBC)**：在开放环境中保护密钥的实现（CHES CTF 常见）
- **轻量级密码**：PRESENT、Simon、Speck（IoT CTF 常见）
- **S-Box 性质**：AES S-Box 基于 GF(2^8) 逆 + 仿射变换，理解 S-Box 的差分性质
