# 常见算法逆向与识别

## 1. 概述

CTF逆向题目中，至少有40%涉及密码学算法——通常是对标准算法进行变种改编（参数魔改、轮数调整、自定义S-Box等）。如果能够快速识别出使用了哪个算法，分析效率将大幅提升。本章汇集了常见算法（包括加密、哈希、压缩、编码）的汇编级特征，帮助在IDA反汇编或反编译视图中快速定位和识别算法。

算法识别的核心方法有三种：
1. **常量特征**：算法中固定使用的魔数、初始化向量、S-Box、查询表
2. **结构特征**：特定算法的操作模式（字节替换、移位、XOR多层次组合）
3. **函数签名**：动态或静态链接的标准库函数名

## 2. 常用加密算法特征

### 2.1 AES（高级加密标准）

**核心特征**：
- S-Box（256字节置换表，16x16字节矩阵）
- 逆S-Box（解密时使用，与S-Box一一对应反查）
- Rcon（轮常量数组）：`[0x01, 0x02, 0x04, 0x08, 0x10, 0x20, 0x40, 0x80, 0x1B, 0x36]`
- MixColumns矩阵：`{0x02, 0x03, 0x01, 0x01}` 循环排列
- 标准块大小16字节，密钥长度16/24/32字节（AES-128/192/256）

**S-Box前16字节（偏移0x00-0x0F）**：
```
63 7C 77 7B F2 6B 6F C5 30 01 67 2B FE D7 AB 76
```

**反编译特征**（KeyExpansion子模式）：
```c
// 轮密钥扩展中的核心操作
v = _rotl(v, 8);       // RotWord: 左循环移位8位
v = sbox[v >> 24] ^ sbox[(v >> 16) & 0xFF] ^
    sbox[(v >> 8) & 0xFF] ^ sbox[v & 0xFF];  // SubWord: S-Box替换
v ^= rcon[round];       // 与轮常量XOR
```

**定位方法**：搜索 `findcrypt` 插件（IDA插件）自动扫描，或手动搜S-Box首字节 `0x63 0x7C 0x77 0x7B`。

**常见变种**：
- 替换S-Box（魔改AES最常见变种）-> 关注S-Box是否仍是12比特代数度（仿射变换）
- 减少轮数（AES-128标准10轮，CTF中可能改为4-5轮以降低密钥搜索空间）

### 2.2 DES/TDES（数据加密标准）

**核心特征**：
- **8个S-Box**（每个4x16表，共512字节）
- **初始置换IP表**（64元素的位置换表）
- **PC-1/PC-2置换表**（密钥扩展用）
- 块大小8字节，密钥长度8字节（有效56位）
- DES的S-Box不是随机生成的，具有特定结构（非线性度、差分均匀性等）

**DES S1 Box（S-Box 1）前两行**：
```
14  4 13  1  2 15 11  8  3 10  6 12  5  9  0  7
 0 15  7  4 14  2 13  1 10  6 12 11  9  5  3  8
```

**反编译特征**：
```c
// DES Feistel网络核心：扩展置换 -> XOR轮密钥 -> 8个S-Box查表 -> P置换
expanded = ((block << 1) | (block >> 31)) & ~0x...;  // 扩展置换
xored = expanded ^ round_key;
for (i = 0; i < 8; i++) {
    sbox_input = (xored >> (42 - i*6)) & 0x3F;  // 每6位一组
    output |= sbox[i][row][col] << ((7-i)*4);    // 4位输出
}
// P置换 (32 bits permutation)
```

### 2.3 RC4（流密码）

**核心特征**：
- 初始化256字节状态数组（S数组）：`for i in 0..255: S[i] = i`
- KSA（密钥调度算法）：用密钥打乱S数组
- PRGA（伪随机生成算法）：输出密钥流
- 无需复杂的查找表，核心操作只有XOR和交换

**反编译特征**（非常独特，一眼能认出）：
```c
// RC4 KSA特征：256次循环中的两个swap操作
for (int i = 0; i < 256; i++) {
    j = (j + S[i] + key[i % keylen]) & 0xFF;
    swap(S[i], S[j]);  // 经典的交换
}

// RC4 PRGA特征：
int i = 0, j = 0;
while (data_len) {
    i = (i + 1) & 0xFF;
    j = (j + S[i]) & 0xFF;
    swap(S[i], S[j]);
    keystream_byte = S[(S[i] + S[j]) & 0xFF];
    *output++ = *input++ ^ keystream_byte;
}
```

**识别关键**：连续的256字节初始化（S[i] = i），然后是一个以 `& 0xFF` 为约束的双重swap循环。

### 2.4 TEA/XTEA/XXTEA系列

**核心特征**：
- **Delta常量**：`0x9E3779B9`（黄金分割相关，TEA系列标志性常量）
- 极为简洁的Feistel网络结构（64位块，128位密钥）
- 核心操作仅包括加法、XOR和移位

**标准TEA加密循环**：
```c
// TEA: 32轮Feistel
uint32_t delta = 0x9E3779B9;
uint32_t sum = 0;
for (int i = 0; i < 32; i++) {
    sum += delta;
    v0 += ((v1 << 4) + k0) ^ (v1 + sum) ^ ((v1 >> 5) + k1);
    v1 += ((v0 << 4) + k2) ^ (v0 + sum) ^ ((v0 >> 5) + k3);
}
```

**XTEA变种特征**：
```c
uint32_t delta = 0x9E3779B9;
uint32_t sum = 0;
for (int i = 0; i < 32; i++) {
    v0 += (((v1 << 4) ^ (v1 >> 5)) + v1) ^ (sum + k[sum & 3]);
    sum += delta;
    v1 += (((v0 << 4) ^ (v0 >> 5)) + v0) ^ (sum + k[(sum >> 11) & 3]);
}
```

**识别关键**：搜索 `0x9E3779B9`，看到就是TEA家族。

### 2.5 ChaCha20（现代流密码）

**核心特征**：
- 常量 `"expand 32-byte k"`（ASCII字符串，4x DWORD为 `0x61707865, 0x3320646e, 0x79622d32, 0x6b206574`）
- Quarter Round操作：4次加法-异或-循环移位的组合
- 20轮（10次双轮），每轮包含8个Quarter Round

**反编译特征**：
```c
// Quarter Round模式（重复8次，每条线上4个操作）
a += b; d ^= a; d = ROTL(d, 16);
c += d; b ^= c; b = ROTL(b, 12);
a += b; d ^= a; d = ROTL(d, 8);
c += d; b ^= c; b = ROTL(b, 7);
```

### 2.6 Salsa20（ChaCha20的原型）

类似ChaCha20但旋转常量不同（ChaCha: 16,12,8,7; Salsa20: 7,9,13,18）。常量字符串为 `"expand 32-byte k"` 相同。

### 2.7 SM4（中国国密分组密码）

**核心特征**：
- S-Box：256字节（与AES不同，但结构类似）
- FK常量：`[0xA3B1BAC6, 0x56AA3350, 0x677D9197, 0xB27022DC]`
- CK常量：32个固定轮常量
- 块大小16字节，密钥16字节

```c
// SM4 轮函数中的线性变换
B = S(a0 ^ a1 ^ a2 ^ a3 ^ rk);  // S-Box替换
// 线性变换L
B ^= (B << 13 | B >> (32-13));
B ^= (B << 23 | B >> (32-23));
```

**定位方法**：搜索CK常量的第一个DWORD `0x00070E15`。

## 3. 哈希算法特征

### 3.1 MD5

**核心特征**：
- 初始化IV：`A=0x67452301, B=0xEFCDAB89, C=0x98BADCFE, D=0x10325476`
- **64个K常量**（正弦函数生成）：`0xD76AA478, 0xE8C7B756, 0x242070DB, 0xC1BDCEEE...`
- 64轮操作，每轮结构：`F + A + K[i] + M[g]` 然后旋转
- 块大小64字节

**反编译特征**：
```c
// MD5核心步骤
// 4轮中每轮16步，每步的结构相同，只是F函数和移位量不同
a = b + ROTL(a + F(b, c, d) + X[k] + T[i], s);
// 或使用FF/GG/HH/II宏的4次调用模式
FF(a, b, c, d, x[0], 7, 0xd76aa478);
FF(d, a, b, c, x[1], 12, 0xe8c7b756);
// ...
```

**识别关键**：搜索4个初始化IV或K常量的前几个值。

### 3.2 SHA-1

**核心特征**：
- 初始化：`H0=0x67452301, H1=0xEFCDAB89, H2=0x98BADCFE, H3=0x10325476, H4=0xC3D2E1F0`
- K常量：`K0=0x5A827999, K1=0x6ED9EBA1, K2=0x8F1BACD8, K3=0xCA62C1D6`
- 80轮操作

**识别关键**：前4个IV与MD5相同（因为是MD5的前身），加上第5个H4，以及特征K常量。

### 3.3 SHA-256

**核心特征**：
- 8个初始化值（前8个素数平方根的小数部分）
  - `0x6A09E667, 0xBB67AE85, 0x3C6EF372, 0xA54FF53A, 0x510E527F, 0x9B05688C, 0x1F83D9AB, 0x5BE0CD19`
- 64个K常量（前64个素数立方根的小数部分）
  - `K[0]=0x428A2F98`
- 64轮操作

**反编译特征**：
```c
// SHA-256核心轮函数
S0 = ROTR(a, 2) ^ ROTR(a, 13) ^ ROTR(a, 22);
S1 = ROTR(e, 6) ^ ROTR(e, 11) ^ ROTR(e, 25);
ch = (e & f) ^ (~e & g);
maj = (a & b) ^ (a & c) ^ (b & c);
temp1 = h + S1 + ch + K[t] + W[t];
temp2 = S0 + maj;
h = g; g = f; f = e;
e = d + temp1;
d = c; c = b; b = a;
a = temp1 + temp2;
```

### 3.4 SM3（中国国密哈希）

**核心特征**：
- 初始化IV：`0x7380166F, 0x4914B2B9, 0x172442D7, 0xDA8A0600, 0xA96F30BC, 0x163138AA, 0xE38DEE4D, 0xB0FB0E4E`
- T常量：`0x79CC4519`（前16轮），`0x7A879D8A`（后48轮）
- 压缩函数包含置换函数P0和P1

## 4. 编码算法特征

### 4.1 Base64

**核心特征**：
- 字母表：`"ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/"`
- 将3字节编码为4字符
- 解码时将4字符还原为3字节
- 特征操作：从4个字符中提取6位数据，重组成3字节

**反编译特征**：
```c
// Base64解码的核心移位操作
// 从4个ASCII字符中提取6位，拼接为3个8位字节
byte0 = (c0 << 2) | (c1 >> 4);
byte1 = (c1 << 4) | (c2 >> 2);
byte2 = (c2 << 6) | c3;
```

**魔改Base64识别**：
- 自定义字母表（常见于CTF）：搜索一个64字符的ASCII字符串（字母+数字+符号），且长度恰好为64
- 围绕这个字母表的二进制搜索（二分查找）确认解码逻辑

### 4.2 自定义编码

CTF中常见：对Base64做位置置换（字母表重排）、与密钥XOR后再做Base64、定长编码等。识别要点是搜索字符串常量（字母表）和查找移位/重组操作。

## 5. 压缩算法特征

### 5.1 Zlib/Deflate

**核心特征**：
- 头字节：`0x78 0x9C`（默认压缩级别）、`0x78 0x01`、`0x78 0xDA`
- 调用 `inflate()` 或 `deflate()` 函数
- 涉及Huffman树的构建（大量位操作）

### 5.2 LZMA

**核心特征**：
- 5字节属性头：`5D 00 00 00 00`
- 7z SDK的函数特征（LzmaDec_DecodeToBuf）

## 7. 自定义流密码与分组密码识别方法

当标准算法特征（常量、S-Box）都找不到时，需要使用通用方法：

**熵分析**：
```python
# 在IDA中检查某个全局数组的熵
# 高熵数组 -> 可能是S-Box或查找表
# 低熵数组 -> 可能是置换表（如IP表、P置换）
import math
def calc_entropy(data):
    freq = {}
    for b in data:
        freq[b] = freq.get(b, 0) + 1
    ent = 0
    for count in freq.values():
        p = count / len(data)
        ent -= p * math.log2(p)
    return ent
# S-Box熵通常接近8（256字节完全随机）
```

**T图分析**：
- 观察函数调用图，寻找"循环结构"（加密的轮函数就是一串重复的操作序列）
- 寻找"输入->多轮变换->输出"的管道结构

## 8. 常见误区与注意事项

- **误区**：看到S-Box就认定是AES。很多算法（SM4、Camellia、ARIA等）也有S-Box。要配合观察轮结构、块大小和密钥长度。
- **误区**：Delta常量 0x9E3779B9 不一定就是TEA。XXTEA、XTEA也用同一个delta，且许多非标准变种也沿用这个值。
- **注意**：Mersenne Twister（MT19937）伪随机数生成器也有特征常量矩阵（如 `0x9908B0DF`），不要和加密算法搞混。
- **注意**：CTF题目经常"魔改"算法——只改个小参数（如TEA的轮数从32改为16），但核心结构不变。识别出家族后，对参数逐一分析即可还原。
