# Office / PDF / 日志 / 内存取证 速查

> 目标：补齐 Misc 中经常被忽略但比赛很实用的“文件与取证”部分。

---

## 1. Office 文档

## 1.1 先分类型
- docx/xlsx/pptx：本质是 zip
- xls/doc 老格式：复合文档/老二进制结构
- 含宏：VBA / XLM 宏 / 外部模板引用

## 1.2 解题顺序
1. 先 `file` 和解压
2. 看文档内部 XML、关系文件、媒体资源
3. 检查宏、隐藏工作表、注释、修订记录
4. 看自定义属性、作者、时间线、嵌入对象

### 高频藏数据位置
- 文档属性
- comments
- hidden sheet / very hidden
- sharedStrings.xml
- 自定义 XML
- 宏代码
- 图片/附件内二次嵌套

---

## 2. PDF

## 2.1 高频检查点
- metadata
- objects / streams
- embedded files
- JavaScript
- 注释、表单、隐藏层
- 增量更新（版本追加）

## 2.2 解题顺序
1. exif/metadata
2. strings / pdf-parser / qpdf 思路
3. 看对象流和嵌入文件
4. 注意是否有多次更新历史

---

## 3. 日志分析

### 高频目标
- 从 Web/系统日志中提取：
  - 攻击路径
  - 时间线
  - 用户行为
  - 敏感参数
  - 注入/命令执行痕迹

### 核心方法
1. 先按时间排序
2. 再按 IP / user-agent / session 聚类
3. 再找异常状态码、长度、路径模式
4. 关联文件写入、进程、网络连接时间线

---

## 4. 内存取证

### 最先想拿什么
- 进程列表
- 网络连接
- 命令行参数
- 注入模块
- 可疑字符串
- 密钥/口令/flag 残留

### 核心顺序
1. 确认镜像类型和 profile/符号
2. 看进程、父子关系、异常路径
3. 看网络连接
4. 看命令行、环境变量
5. dump 可疑进程/内存区
6. strings / yara / grep 二次分析

---

## 5. 统一方法论

这些题的核心不是工具名，而是：
- **容器结构**：zip、pdf object、内存段、日志行
- **时间线**：创建、修改、执行、连接
- **二次嵌套**：文档里套文档、流里套文件、内存里藏配置

---

## 6. 误区
- 只看文件表面，不解包
- 不查 metadata
- 内存题只跑一个插件就结束
- 日志题不做时间线和聚类
